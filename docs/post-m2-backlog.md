## 恢复与交付检查

每个恢复任务完成时登记实际内容版本、对应 R 用例证据、源规则差异及 A01–A18 回归结果。先展开该入口所有产物、效果和保存字段，再启用交互；不能只把“后续开放”提示改成按钮。

从 M2 存档升级时保留余额、任务进度、已领奖节点及永久解锁，新增状态按一次性迁移规则初始化。扩池不能直接重抽正在进行的旧局：兼容时保留该局原内容与随机合同直到结束、仅新局采用新池；做不到兼容则保留旧记录并明确版本限制，不静默用新池解释旧 PRNG 状态。迁移与回退按 A13/A16 验证。

所有影响普通主线玩法的扩充都执行[内容版本与 A10 重验合同](m2-configuration.md#通关证据与内容版本)，归档全部预登记种子的结果。R01–R10 是本登记中的后续验收入口，不代表 M2 已增加对应游戏功能；M2-10 的完成条件是交付这份可追踪登记，后续批次再逐项关闭。
