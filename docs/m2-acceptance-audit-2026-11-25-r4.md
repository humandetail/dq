## Spec：具体设定偏差

### F1 · P2：近战塔被画成发射远程弹道

`src/m2-scene.ts:323–333` 对所有塔的 `lastAttackTarget` 统一绘制 150ms 飞行线，没有检查武器类别或真实飞行速度，导致小小及其他近战塔看起来都在射击。

小小 H021 的原始 `units_unitweapons.json` 与当前 `weapons.json` 一致：启用武器 1，`normal`、弹速 0、射程 750、缓冲 250。`match.ts:2405` 对 normal 直接结算命中。因此，**750 射程来自本塔防设定；近战攻击类别没有被改成远程，错误在统一弹道表现**。修复应区分近战动作／命中特效和真实远程弹道，不能直接套用其他游戏的短射程。

### F2 · P2：小小战棍缺少手动施放入口

`src/m2.ts:478–479` 仅为 `heroSpells` 中的技能提供施放按钮，`hero-spells.ts` 不包含 A068/A149；`match.ts:1318–1320` 对相应命令也会返回 missing。战棍的现有调用仅在 `startWeapon` 的自动攻击流程（1753 行）。学会战棍后，玩家无法按主动技能时机手动施放，也不能在没有普攻目标时主动开启。

依据：[战棍规则](rules/self-buff-batch-01.md#A068-战棍)、[自动施法规则](rules/autocast.md)及计划 A01 的技能施放操作要求。应接入同一技能的手动命令、耗蓝、冷却与状态处理，避免复制另一套效果。

### F3 · P1：小小“长大”永久攻击被剥级退款，模型成长也未接入

`src/m2-scene.ts:375–376` 始终传固定 `visuals.size`，学习 A069 后没有按 `0.5+0.2L` 更新模型尺寸，G059 的额外比例也未从技能状态应用。

此外，`match.ts:2375` 将长大攻击贡献写为 `ranks.A069 * 90`；`hero.ts:75–78` 剥级会撤销已学等级。已决 Q46 要求独立保存永久累计贡献 G，每次实际学习 +90，降级不退款，换型／恢复不重放。因此只按当前等级计算不能保持该规则。应分别保存累计攻击贡献与模型缩放，核对突破后失去资格再升级的剥级情景。

依据：[A069 长大](rules/hero-aura-family-next.md)、[Q46 永久贡献](rules/weapon-field-source-notes.md#Q46-已确认A069-专用可放大贡献)。

受控英雄 API 已复现：新建 H021，合法升级到 25，依次学习 A067/A068/T000/A069 各六级；此时剩 1 点，长大贡献 540。失去资格后取得经验跨 26 级，退回 20 级、A069 降至二级，当前公式贡献变为 180，错误扣除 360；按规则应保留 540。自然属性降级变化另算。本用例没有伪造技能等级，但属于受控 API 证据，不冒充正常经济或浏览器操作。见 [原始状态](evidence/m2-audit-2026-11-25-r4/tiny-growth.json)。
