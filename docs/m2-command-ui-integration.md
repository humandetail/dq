# M2 指挥界面接入

2026-11-26。入口为 `m2.html`；运行 `npm run dev -- --port 4186` 后访问 http://127.0.0.1:4186/m2.html 。

## 实现

- 正式页面接入战场、顶部资源、英雄快捷选择、底部属性／六格物品／十二格命令。使用真实 Match、Action、内容索引与场景模型。
- 中央窗口容纳普通商店、特殊商店、72 条合成配方、完整本期内容索引以及原有成长和对局入口。商品选择、搜索和购买连接原经济事务；配方按原拾取规则自动合成。
- 接入场景左键选择、Shift 多选、框选、Tab 当前对象、Ctrl＋数字编队、数字召回和连按定位、头像双击定位、命令与物品快捷键。
- 中键平移、Shift＋中键旋转／俯仰、滚轮缩放、按钮复位；右键用于取消、工人移动／拾取、固定塔集火和灵兽指令。
- 工人移动复用点到点寻路；建造、拾取及交接继续复用原有接近目标和事务逻辑。
- 主动技能右键切换自动模式；支持自动使用的主动装备 Alt＋右键切换。模式记录在单位 autoModes 内，随真实对局存档保存，新局采用默认行为。原技能、装备的冷却、消耗与目标规则继续由引擎裁决。
- 瞄准不暂停自动行为；无效目标保留选择。中央窗口屏蔽战场快捷键，空格仍可暂停，输入框内空格正常输入；Esc 按窗口、操作、学习页、选择的次序取消。
- 常驻血条、真实伤害飘字；飘字事件保留独立的短时事件集合，原 recentHits 历史长度与行为保持原样。
- 英雄或携带装备单位回收前确认返还金额和装备处理规则。原有抽卡、天赋、波次奖励、资格、神庙、皮肤和特殊施法入口保留在中央对局窗口。

## 手机界面首版

**实现状态**：`/m2.html` 已增加手机竖屏和横屏布局。触屏可轻点选中、建造或选取施法目标，单指拖动可平移镜头。用「下令」选择工人的移动／拾取或选中单位的攻击目标，用「更多」操作装备交接及技能、装备的自动模式。商店、合成、图鉴和对局面板在手机视口全屏显示。使用特制橙色卡片后，对局面板直接滚到开局英雄选项。商店仅在所选商品匹配搜索时显示购买入口，并在窗口内显示交易反馈。

**验收状态**：`npm run check` 通过（490 项测试）。`M3_VERIFY=1 node checks/m2-command-ui.mjs` 桌面回归通过。同一命令加 `M2_MOBILE_VERIFY=1` 连续三次通过，覆盖 320、390、430 CSS 像素宽竖屏和 844×390 横屏，以及触屏平移、建塔、拾取、施法、自动模式、交接、购买和刷新续局。另用干净浏览器档案验证了从特制橙色卡片进入并完成开局英雄选择。F3/R10 真机与全模式验收待执行。
