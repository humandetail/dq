# A07 玩家英雄死亡与复活边界

83 卡／45 候选的正常记录覆盖 P001–P013 各自真实取得最高档前置塔，以及首个有效资格下的 21 级。受控检查覆盖前置塔／资格持有者零生命时失效、同一实体快照还原后保留资格 ID 和随机状态、前置回收、后续剥级及装备再次准入。受控检查恢复了显式生命状态，未触发实际玩家死亡事件。 [正常索引](verified-chains.json) · [受控结果](controlled-final.log)

原死亡回调先处理杀手入口，只为玩家 0–3 的非幻象原生英雄在原位置调用同一实体的 `ReviveHeroLoc(..., false)`，随后移除 N032、恢复原生移动种类。规则采用满有效生命、至多 100 魔法，保留 ID、资格、物品、技能、等级与在途引用，仍需处理旧生命代和专用效果清理。原回调未重新调用建成分派。 [原死亡分支](../../../../reference/map-6.25/main.disasm#L168394) · [塔生命周期](../../../rules/tower-lifecycle.md) · [资格](../../../rules/qualification-lifecycle.md)

当前适用玩法没有已核证的玩家塔致死入口。55 波、24 挑战模板与相关敌方辅助都没有启用的普通武器；主线敌方反击涉及嘲讽、弱化和控制，N514、N522、N528、N581、N710 的原生伤害字段未填写，规则采用零直接伤害。正常自损入口 A115、A117、i330 均有生命阈值或最低生命，A225 按基础属性接口裁剪存活生命。运行时实际死亡分派处理怪物，未有通用玩家英雄死亡事件。 [敌方武器核对](../../../m3-work-state.md#敌方武器准入复核) · [主线反击](../../../rules/npc-mainline-abilities-01.md) · [后段反击](../../../rules/late-enemy-effects.md) · [挑战反击](../../../rules/challenge-enemy-effects.md) · [生命及属性接口](../../../rules/hero-attribute-interface.md)

该事件的验收仍待。最小后续依赖是范围内经来源核定的真实致死伤害入口及对应受体，或正式范围中明确批准可用于验收的既有真实死亡档案。届时应由该入口执行同一实体同步复活、旧生命代和未提交动作清理，并验证恢复和再算资格不消费抽签。其余正常资格、事务和存档工作可独立执行。
