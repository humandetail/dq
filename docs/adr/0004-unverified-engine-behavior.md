# 为未证实的引擎细节建立明确的 Web 规则

原地图包含大量由魔兽引擎执行的行为，用户确认没有可用原版验证环境（Q23），并接受对查阅图鉴、脚本和公开资料后仍无法确定的少量底层细节制定明确、可测试的 Web 规则（Q24）。图鉴明文、已核脚本和既有冲突裁决继续优先；缺口优先依据官方资料补齐，并在 [Web 基准规则](../rules/web-baseline.md) 逐项区分证据、选择与验证例子，不宣称原版实测，也不以此跳过尚未阅读的脚本。

这使移植可以继续推进，代价是部分取整、事件顺序等结果可能与原客户端不同；这些规则会影响存档和战斗结果，后续修改应升级规则版本并明确旧存档的适用版本。
