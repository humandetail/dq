# 取消原平台地图等级门槛

原地图从平台读取地图等级，该等级影响新手礼包、透支点上限与部分解锁，而平台的升级算法不在地图逻辑内。用户选择取消地图等级门槛、直接开放对应资格，放弃为 Web 版设计本地地图等级成长或让玩家手动模拟等级。移植时去除地图等级这一条件，保留金币和积分费用、局内人口、英雄等级、变强资格等其他规则；具体受影响的条目逐项从原图核对。这使单人 Web 体验无需原平台成长记录，同时改变了原版依赖地图等级逐步开放资格的节奏。

后续 Q18、Q19 分别决定直接开放付费/赞助权益及普通积分/碎片对应的 18 项永久内容，因此这 18 项不再收取兑换费用。其余局内成本和资格条件仍保留。后续裁决见 [主设计记录](../web-port-design.md)，不能仅按本 ADR 的早期费用描述恢复已取消的门槛。
