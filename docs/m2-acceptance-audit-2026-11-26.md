# M2 接手前验收 · 2026-11-26

## 结论与边界

当前本地工作树为 **m2-core-15**。接受 core-14/15 的阶段性修复，**M2 整体仍未完成，不满足最终交付条件**。本轮审查包含未提交修改；没有修改游戏代码。新开发者以本报告、当前代码及最终规则接手，不应再按第四轮报告重复修复已经完成的条目。

本轮重新执行基础检查和浏览器专项，核对已有整局证据与源码／构建一致性；没有重新执行全部 A01–A18、全部五种子或硬件性能测试。性能继续暂时放行，F1–F3 保持原范围。

### 清单可信度需要提高

当前 `m2-runtime-coverage.json` 顶层状态统计如下（指每行剩余行为，不是完整模块完成率）：

- 玩家技能116条：116条“已实现待验”。
- 敌方技能47条：25条“已实现待验”、22条“未实现”。
- 物品202条：185条“已实现待验”、17条“未实现”。

**不能将22+17直接解释为39个完全不存在的功能，也不能将“已实现待验”当作行为已完整。** 生成器主要用入口映射及组件映射登记状态。例如 i206 在清单中无入口、标记未实现，但 `match.ts#canSeeEnemy` 已有 `nearbyEquipment(...["i206"],1100)` 的探隐处理。应核完整规则与目标资格后补实际入口和测试；不能仅改状态，也不能重复造实现。

22个敌方待核ID：N518、N519、N536、N573、N582–N584、N706–N712、T013–T018、T044、T045。

17个物品待核ID：i148、i206、i235、i258、i259、i260、i264、i312、i313、i314、i399、i718–i723。

其余条目的完整分支同样需要关闭。新开发者须将笼统“完整组合待验”拆为可执行行为清单，保留已有通过子项，区分缺实现、缺映射和缺证据。

本轮代码抽查确认i330/i332仍缺主动/自动点燃、每秒自损与700范围物理伤害、低血自动关闭完整生命周期；对照`docs/rules/item-final-batch-01.md`。i310已有局部携带检查，但辅助能力授予、移出撤销及换型事务未完整。因此剩余工作包含实际功能实现，不只是补测试。

运行清单尚无Q18–Q22权益/任务逐项验收矩阵和全模型动作矩阵，应纳入统一执行台账，不能仅按技能与物品顶层行数判断完成。
