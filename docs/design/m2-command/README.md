# M2 指挥界面设计

这是一版独立、可交互的桌面设计原型。它没有替换正式 M2 页面，也没有发布到公开试玩地址。

## 查看

在仓库根目录执行 `npm run dev -- --port 4186`，打开 <http://127.0.0.1:4186/docs/design/m2-command/>。

同一入口支持 `?state=shop`、`?state=craft`、`?state=codex`、`?state=learn`、`?state=worker` 和 `?state=multi`。这些是方便评审的初始状态，不是独立页面。

## 设计方向

**让战场占据注意力，让每个指令始终出现在熟悉的位置。**

- 品类：桌面实时塔防指挥界面，主要任务是观察战况、选择单位、成长与装备管理、施法和下令。
- 参考：用户提供的 Warcraft III 截图。借鉴对象选择、底部上下文命令和材质语言；按用户要求移除小地图、缩薄边框、把商店等管理功能集中到中央窗口。
- 战场使用现有 M2 的真实地形、已登记模型、贴图和动画；界面使用深绿灰黑的金属表面，金色用于资源和选中，绿色用于生命，蓝色用于魔法。
- 主状态保留战场、全量血条、全量飘字。底部左侧属性、中间六格物品、右侧十二格命令。管理状态由中央窗口成为视觉主体。
- 桌面目标视口为 1440×900，另检查 1280×800；手机完整适配仍在后续范围。

## 已确认的操作规则

| 部分 | 规则 |
| --- | --- |
| 对象选择 | 左键选择，点空地保留选择，点敌人查看敌方信息；Esc 在没有其他操作时取消选择 |
| 多选与编队 | 框选、Shift 多选、Ctrl＋数字编队，数字选择编队；Tab 切换组内当前对象 |
| 指令归属 | 升级、技能和装备操作作用于当前对象；共同指令由组内能够执行的单位响应 |
| 镜头 | 中键拖动平移；Shift＋中键旋转和俯仰；滚轮缩放；保留复位按钮 |
| 定位 | 单击头像或按一次编队键仅选择，双击头像或快速连按编队键定位镜头 |
| 工人 | 右键地面移动，右键物品拾取；自动寻路，执行建造和交接 |
| 攻击 | 右键敌人指定集火；固定塔不移动；目标死亡或超出固定塔射程时恢复索敌；灵兽追击目标失效后就地接敌 |
| 选点 | 左键指令后点目标；无效目标保留选点、提示原因、不消费、不自动改选；右键或 Esc 先取消操作 |
| 技能模式 | 左键施放、右键切换自动／手动；瞄准不停止自动行为，可以被自动施法抢先；模式逐单位逐技能设置，随本局存档恢复，新局用默认模式 |
| 学习 | 进入命令区学习页，分配后返回；显示等级以及当前级→下一级收益；被动技能不画成可施放按钮 |
| 物品 | 左键使用，右键拿起后点单位或头像交接；右键或 Esc 取消；Alt＋右键切换原本支持自动使用的主动道具；被动装备不增加开关 |
| 快捷键 | 命令 QWER／ASDF／ZXCV；六格物品 Alt＋Q/W/E/A/S/D；空格暂停／继续 |
| 中央窗口 | 商店、合成、图鉴共用页签窗口；战斗继续；屏蔽战场命令和技能快捷键，保留暂停；输入框中的空格正常输入，Esc 优先关窗口 |
| 回收 | 英雄或携带装备单位需要确认，明确单位、返还内容及装备去向；普通空塔直接回收 |
| 战斗表现 | 所有单位血条常驻，全量伤害数字飘出；用排布错位缓解重叠，不删掉事件 |

## 原型已覆盖与边界

已覆盖：英雄／工人／敌方选择、组内切换、框选与编队、镜头操作、主动和被动技能的区别、学习页和等级反馈、技能与主动道具的模式切换、局部设置刷新读回与保存失败反馈、物品转交、商店搜索／分类／购买／满包失败、中央页签、暂停和取消优先级、回收确认。

原型用独立数据展示界面。顶部资源、波次、单位属性、战斗轨迹、飘字和施法演出是设计场景，不是正式对局证明。商品名与列出的六件商品价格取自当前 M2；小小三项技能及学习收益依据本地规则。合成页只展示邪念法杖的一条真实配方，图鉴展示当前场景对象，不代表全部 202 个物品的完整界面实现。

设计原型没有实现完整战斗、资格限制、自动施法队列、完整经济、所有目标距离判定和正式存档迁移。升级入口只给出说明，施法演出不代表真实伤害结算；工人交接在原型中直接反馈，正式接入必须保留既有寻路、距离和交付事务。

正式实现需增加固定塔通用集火指令、逐技能／道具自动模式和相关状态保存，并把新交互接到现有 M2 事务。这里没有更改 `src/`、正式页面或游戏存档。原型设置单独保存在 `td3-ui-design-autocast-v1`，不会读写 M2 的 IndexedDB。

## 动效与减法

命令短促按下并立即反馈；底部面板首次短距离进入；中央窗口以 240ms 轻微位移进入，页签指示随切换移动；伤害由命中位置弹出后上浮淡出。支持减少动态效果设置。

删去原侧栏中重复展开的全单位操作；移除小地图、顶部重复徽标及中央窗口与页签重复的标题。保留状态、物品身份和操作必要提示。辅助键位与血蓝条数字属于高密度游戏读数，不作为长段正文使用。

## 评审与验证

独立视觉评审一轮，静态评分 **8/10**。随后修复密集飘字排布、重复标识、命令键位底色、技能等级可见性和表面层次；没有把修正后的页面冒称重新获评更高分。

独立 UX 走查一轮，实际完成“选择小小→学技能→比较山崩→分配技能点”。根据“学习前无法判断收益”的反馈，补充小小三技能的当前级／下一级对照；山崩 3→4 级显示名义伤害 420→650，普通目标眩晕 0.8→1 秒。

独立评审标识为 `/root/ui_visual_review` 和 `/root/ui_ux_review`。初次 UX 代理错误使用了用户的原生 Chrome，已停止；其后取证、走查与自动检查全部使用隔离无头浏览器。不会自动打开设计页面或切换用户窗口。

最终验证与证据见 `validation.md`。完整录屏因环境缺少 ffmpeg 未生成；工具保留动作关键帧，交互另经真实浏览器操作和自动检查。这个限制不影响查看设计稿，但不能把关键帧称作完整录屏。
