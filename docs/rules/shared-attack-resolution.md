# 普通攻击准入、命中与在途武器

本接口将已有 W01–W03 武器、T01–T03 计时及 B03–B05 接成可执行的普通攻击链。局部武器已有明确例外时以其专项为准。源字段、图鉴覆盖与 Q24 的原生行为选择单独保留。[机器表](shared-attack-resolution.json) · [武器](weapon-field-source-notes.md) · [计时](attack-timing.md) · [事件](web-baseline.md)

## 选武器、索敌和提交

- 先应用当前模板和明确的对象增量，按 weapsOn 的第1／2位确定启用槽。图鉴及已证实实际模板启用位均缺失时采用 Q24 零启用，不从留存的攻击字段补成有武器。实体脚本明确启用的入口另执行。角色种类和目标掩码匹配后，优先槽1，再槽2。只用一个攻击起手/前摇与冷却，换目标不以切槽跳过已开始的冷却。对象武器类型决定普通 `ranged` 标记和交付方式，伤害包保留武器攻击类别与实际 NORMAL 伤害类别。角色的原生近战标记仍供读它的脚本独立使用。
- 自动索敌仅在允许自动攻击的实际命令状态运行，优先保留仍合法的当前目标，否则在实际 acquire 内按 B04 取首名可见合法敌方或敌对中立。不可移动和原地坚守者还要求候选当前在武器可起手射程内。可追击者在当前路径接口接近，进入射程后才起手。地图路线显式 MOVE 继续原命令，不被通用自动索敌改成沿路攻击。普通手动攻击可依明确命令关系许可选择友方或有效物件；自动索敌不选择它们。
- 起手条件要求来源已建成、存在、存活、可攻击，有启用武器、冷却已开；允许既有实际攻击载体，不给纯视觉或建筑施工体补攻击。单位目标须存在、存活、已建成，并通过当前敌我许可、地面／空中／建筑／守卫等武器掩码。目标类来自有效模板及分类，模型、飞高特效和碰撞半径不改变目标类。普通隐身已被观察者揭露才符合可见资格，隐藏实体、Aloc 目标、无敌一律拒绝。普通物理武器可打魔免，虚无不能普通攻击；按 MAGIC 武器类别准入可打虚无而不打魔免。已有专项明确的法球、免疫及物件分支仍先取其规则。对物件命中仅走世界物件入口，不造普通单位伤害事件。[定向可见与侦查](item-utility-batch-01.md) · [地图类别](combat-and-skills.md) · [暴雪分类说明](https://classic.battle.net/war3/basics/spellbasics.shtml)
- 以二维中心距离检查最小／最大闭区间。最小字段缺失的适用 Web 值为0。自动索敌范围独立于普通攻击射程；射程装备沿实际 state22 和 acquire 设置。起手只用攻击距离，成功起手才产生一次 ATTACKED 回调和冷却。冷却与前摇并行。发射前再检查状态、目标、可见及原选槽的当前资格，一般最大距离可加该槽的非负 RngBuff 作为起手后容差；该值不增加起手范围。炮击和龙形态等专项明确在发射仍检查基本最大距离，继续用其专项。最小距离在两处都检查。[已定炮击](creep-line-and-artillery.md) · [龙形态](dragon-attack-passives.md) · [ATTACKED](hero-attack-extensions.md)
- 死亡、删除、暂停、缴械和实际硬控、有效替换命令、失去当前候选或已选武器资格，会取消尚未提交的前摇。前摇取消保留已经登记的冷却和已经执行的 ATTACKED 结果。纯沉默、仅移动锁、单独播放动画或改变攻速不等于取消武器攻击。暂停和硬控期间不开始新攻击，已启动的冷却沿正常战斗时间推进，解除后仍按剩余门槛。未成功接受的其他命令不取消攻击。攻击允许状态由各控制适配器提供，不拿任意 Buff 存在代替。已提交后后摇可按 T02 截断，已发弹保留。[眩晕共享](avalanche-native-effect.md) · [地形和移动](pathing-and-placement.md)

## 快照与普通命中

1. 发射时保存真实来源 ID、所选槽、当次骰子及 W01 武器原始额、攻击类别、投射配置、生命周期各项及已核来源候选的能力/等级/实例。尚未发射的前摇按 T03 保留进度并复查新模板是否合法；武器槽仍合法时，本次 P/B 快照仍按既有同实体规则，发射载荷用当时实际可提交的数据。发射后旧弹不重新取新模板、装备面板攻击、候选技能等级或弹速。B03 内本来读取实际 S/O/T、当时装备、模式的分派继续按实时读数。炮击明确在发射就算主命中/暴击的局部例外保持。[同实体换型](skin-and-transformation.md) · [炮击](creep-line-and-artillery.md)
2. 到达后先检受体身份、生命代次和实际有效性、免疫、敌我许可、捕获武器所需目标类。目标在飞行期间死亡、失去实体或复活为下一生命代，不回绑旧弹。有效普通隐形本身可被已发锁定弹追踪；隐藏、变为无敌、类型不合或武器免疫仍阻断落地。离开发射射程不另判一次失效。普通位移和同实体变身沿真实目标 ID；技能若有专属断弹入口按该入口。普通攻击不消费 N535。
3. 合格主目标按已有 A027、原生候选 ASCII、物品实例等顺序执行各自一次随机，保持成功倍率取最大和已有固定奖励顺序。必中分支优先于普通落空，成功后跳过后续闪避/致盲/高地抽样；照常检有效性与伤害免疫。I215、I185/I251/I284、A078、T061、T201 已核资格继续有效，T168 为空标记。仅显式标准普通武器入口可享受各主目标奖励，普通事件标记不会把法术或范围子伤害变成主武器命中。已经明确主副箭、弹跳、毒、重击和火炮附效各走自己的先后。普通无强制必中且判定落空的单体没有 B03 武器事件。炮击旁观者溅射以其专项为准。[原生暴击](native-critical-family.md) · [遗物必中](item-relic-hit.md) · [装备与 A027](skill-coup-de-grace.md) · [猴王](skill-jingu-and-tidebringer.md)
4. 普通落空按目标原生闪避、攻击来源有效的武器失准、上坡惩罚三组依次抽样。每组先取同组实际最大有效百分比，独立整数1–100，小于等于阈值产生落空。已有失败组仍执行后续非零组的抽样，概率0不抽。缺少实际提供者时该组为0。范围同一包内明确的旁观者不自动按自身再抽。N533 的原脚本零伤及 N525 的后背伤害处理属于 B03，在原来位置执行；普通必中不会跳过。目标的原生闪避以撞击时的实际覆盖为准，来源致盲与是否上坡在源提交时快照。普通远程 Missile 家族地面向更高地形层攻击，Q24 采用25%。读 w3e 所在128格的西南顶点 cliff level，飞行参与者和抬升视觉不受此层判定。地图未设 ChanceToMiss。[暴雪上坡数值](https://classic.battle.net/war3/basics/combat.shtml) · [地图 Misc](../../reference/map-6.25/war3mapMisc.txt) · [地形网格](battlefield.md) · [B03 脚本分派](damage-pipeline.md)

## 投射物和源的生死

- `normal` 在提交点同步解析单体。已核 missile/msplash/mbounce 及 artillery 使用各自实际弹速和形态。读取角色 Profile 对应项再合并 w3u ua1z/ua2z 速度与 umh1/umh2 追踪。十个已启用而缺次槽速度的图鉴单位各自有一个明确的正速度，本地采用同对象值，记录次槽原缺省。缺追踪字段的普通锁定弹选追踪；明确0的非追踪弹使用固定发射点和当时目标点确定水平飞行时间。普通单体弹按提交时锁定的单位，在该时刻执行其受体检查，未经证明的视觉直线偏差不另加一次闪避。范围武器的固定点或最后接触位置由投射配置决定。[对象元数据](https://raw.githubusercontent.com/actboy168/YDWE/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/UnitMetaData.slk#L1034)
- Q24 追踪投射物以二维位置计算。从发射位置出发，先排不超过1/32秒且不超过当前距离除弹速的下一次追踪事件。事件按 B05 读取目标实际位置，用时间间隔乘弹速作为本步长度，到得了立即接触，未到则向该点推进并重排。正间隔依 B05 量化为至少1微秒，零距离走同刻一次完成。目标变为无效时，已核溅射可以用最后位置，单体没有改选入口。可视弧度、发射/冲击高度只用于动画，不额外造遮挡、墙碰撞或扫过相邻单位命中。炮击固定点与 Attack Ground、月刃逐跳、龙形态范围、直线伤害和召唤规则沿原已选接口。[炮击](creep-line-and-artillery.md) · [月刃](hero-attack-extensions.md) · [龙形态](dragon-attack-passives.md) · [弹射](creep-skill-family-next.md)
- 同实体换皮／变身保留在途弹，原发送者普通死亡、眩晕或移动不召回已发弹。自然寿命死亡的句柄至少保留至已发弹结算，按已定召唤规则处理实际归属。显式移除实际来源取消尚未到达的武器弹；替换实体不接管旧弹。源在飞行期间受控，效果只影响新攻击及未提交前摇。目标临时失去普通视野、超距或换皮不会重播 ATTACKED、花费、冻结 B05 或重抽已经形成的候选。存档保留武器代号、投射段和目标生命代次、实际来源、位置、飞行时钟、固定点或目标、快照和各 RNG 阶段；恢复不补发。[守卫独立寿命](ward-summons.md) · [风暴与武器回收](exorcism.md) · [T03](attack-timing.md)

### 无显式溅射目标掩码的近卫防御塔

n159–n163 第一槽为 msplash，源速度750、非追踪、圆环30／90／200，内／中／外倍率1／.4／.2。一级至Max均启用槽1，槽2的圆环和目标掩码不映射到槽1。实际第1槽溅射掩码缺省，Q24 选敌方地面单位及建筑／机械，可指定的物件和守卫不作为旁观者，空中不进入本槽。落点固定在施放时目标中心。原主目标仍在外圈且有效时按它的本次普通判定，若闪避则该发没有范围伤害。主目标已移出外圈或在途失效时，落点仍按无主目标型抽样的武器原始额做范围伤害。合法主目标只受一笔，原生主目标固定奖励不扩散；旁观者用圆环倍率且不重抽本发的命中。普通溅射先以 B04 快照再逐目标复验当前存在／生命、免疫及位置。天灾防御塔的实际 missile 槽不继承这些圆环。[近卫塔源字段](../../reference/map-6.25/units_unitweapons.json#L31150) · [范围武器既定接口](dragon-attack-passives.md)

## Q78 九个模板的最小射程

H032、E010–E015、G032、G033 原 minRange=9,999,999，图鉴最大800、同时列攻击区间和间隔。原地图没有这九个对象的 uamn 覆盖，原模块没有写最小射程，炼金专属提示写变形缩短间隔，两个斧王皮肤专属单位说明没有禁普攻条款。原字段会得到空合法区间。Q78 确认这九个模板使用最小0、最大800，其他武器条件保持。n153–n158 的实际最小250继续使用已有规则。

运行 python3 tools/audit-shared-attack-resolution.py --check 复核图鉴单位索引、275 个明确启用武器槽、三项闪避字段、地形层、10 个次槽速度缺省，以及必中不越准入、正阈值和来源在途死亡边界。
