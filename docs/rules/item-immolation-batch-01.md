## Web 周期规则

- 共用已核的 Apig 发射资格、伤害类型及治疗和伤害事件时钟。持有实际启用能力、存活、未隐藏、有效且非幻象的单位参与。入包在 PICKUP 前登记来源，出包在 DROP 前撤回，死亡、禁用与删除立即移除资格。普通沉默、眩晕和暂停本身不停止被动。
- Q24 用一个 B029 周期，每局首次有有效来源后1秒结算，随后每隔1秒。无有效来源时撤销待续周期，重新启用后等待1秒；有效来源交接时保留周期相位。形成稳定目标次序后，在每个目标提交前重查当前来源及目标。源与目标二维中心距离≤900，合格目标为原地面、敌方或非同盟中立、有机单位。排除魔免、无敌、Aloc 和隐藏，允许普通隐身。没有视野、路径或足迹附加要求。
- 每个受体在单次周期选有效覆盖中数值最大的一个挂载，平手按稳定来源 ID。两个强度和位置相同的来源只提交一次；较强来源移出或被先前目标的事件杀死时，后续有效目标可取仍覆盖自己的次强来源。离圈不会留下后续灼烧。ID 为 Bpig 的普通塔献祭仍走其原独立周期。来源位置与周期登记需要一并保存。
- 每名命中的目标由选定实际来源发一笔 false,false,NORMAL/MAGIC，走完整 B03、不额外触发普通攻击或施法，也不消费 N535 或扣蓝。唯一规则覆盖全部五档，不改辉耀的平砍、琥珀净瓶的独立 I270 封印及其自动使用。[普通塔献祭](creep-buffs-orbs-and-immolation.md#献祭-n127n131周期法术伤害没有普通攻击) · [范围与 B03](native-area-damage.md) · [归属顺序](item-damage-dispatch.md)

运行 python3 tools/audit-item-immolation.py --check 从共享索引枚举挂载、比较两书与原字段并复查同档平手和最强来源撤回后的回落。五个挂载组件规则已就绪，琥珀净瓶的封印和自动使用各自保留待核。
