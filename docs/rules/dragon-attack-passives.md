# 龙形态攻击被动：A011/A012/A014/A015

本批基准 **`dragon-attack-passives-v1`**，覆盖四个图鉴 ID、12行，辅助效果 A013，以及12个实际龙形态的武器/挂载与必要脚本片段。[JSON](dragon-attack-passives.json)保存完整字段与来源，[验证工具](../../tools/audit_dragon_attack_passives.py)可 `--write` / `--check`再生。原图、图鉴和快照未改；没有运行 Warcraft。原字段、已核公共规则与 Q24 局部原生选择分开。

**这四项没有已确认的数值冲突。** 毒的“20%减速”由原字段补足为攻击减速20%；蓝龙图鉴40%由原全局字段确定为移速减速，另有攻击减速60%。全局攻击分量复用已采纳的 `weapon-attribute-interface-v1`。A010/A239 完整主动变身、世界物体生命/防御仍是明确外部依赖，不计入本批完成。

[A013](../../reference/map-6.25/units_abilitydata.json#L13909)才是 Afrb、Bfro、普通3秒/英雄2秒、地空目标；没有独立慢速 DataA/B。原 [war3mapMisc 第26/27行](../../reference/map-6.25/war3mapMisc.txt#L26)明确 `FrostAttackSpeedDecrease=.6`、`FrostMoveSpeedDecrease=.4`；[编辑器标签](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/UI/WorldEditStrings.txt#L6753)对应减少量，不是剩余倍率。[原作者能力记录](https://github.com/Cokemonkey11/wc3-ability-doc/blob/main/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md#L2936)说明 Afrb 读取全局寒冷常量；记录的测试版本1.28.5不是本地图匹配客户端证明。

四项和 A013 均无 w3a 增量；主 Lua 字节码/JASS 没有这些 ID 的精确字符串或 FourCC 分派，不存在被本页忽略的同名专用技能模块。不是据“无脚本”判断没效果，而是依据实际原生能力与单位武器挂载。[既有 MPQ 全哈希检查](skill-lizard-frenzy-and-gold.md)已证明原地图没有 war3map.w3h；各 Buff 表仅 alias，补充提示见 [Bpoi](../../reference/map-6.25/units_commonabilitystrings.txt#L2291)、[Bpsd](../../reference/map-6.25/units_commonabilitystrings.txt#L2312)、[Bfro](../../reference/map-6.25/units_commonabilitystrings.txt#L2146)。Bpsd 是毒，**不是眩晕 BPSE**。

**本页的形态交接边界（Q24）：** 当完整主动变身模块实际提交类型时，按当前模板替换模板来源的被动，保留同一逻辑实体/所有者及伤害来源。已发攻击保存当次形态/被动快照；已施加毒/寒冷继续按自身相位/期限，不能因变回人形就统一删除，也不因再次变龙重播伤害或多添一层同来源毒。主动变身的准入、前摇、取消、持续/返回形态、属性与生命重基准尚由 A010/A239 的独立审计负责；这里没有把皮肤 Acha 的全部事务擅自当成 AEme实现。

## 毒性攻击：复用已定 Aven，补英雄时长

[官方毒规则](https://classic.battle.net/war3/basics/spellbasics.shtml)支持普通毒不可魔法驱散、魔免有效而虚无无效；同一来源重复攻击不增加 DPS，不同来源可叠加，毒本体留2HP。沿用[已核普通塔 Aven](creep-buffs-orbs-and-immolation.md)与 B03 入口位置；作者旧版本笔记的1HP和 Buff 内部分派不足以推翻此处已选官方2HP基准。以下键/相位是 Q24 明确选择，不冒称重建了客户端 Buff 内部实现。

1. 成功普通武器**主命中**触发。攻击发射时实际 A011/A012 启用、来源非幻象；按本次弹体快照施效，不把后来任意 `attack=true` 脚本包或其他范围受害者再当成一次普通攻击。原主攻击保留，不增加蓝耗、CD、RNG、SPELL_EFFECT、N535 或第二个 ATTACKED。
2. 目标须普通攻击合法敌方地空有机、非建筑/机械/守卫，排除隐藏/Aloc/无敌/虚无，魔免允许。在本次主伤害原生减免/地图回调前登记毒；如果主攻击杀死目标，清它的毒。命中后护甲/地图将普通伤害改0不撤销已登记的毒。
3. 持续在施加时判定：native HERO 或有效 Arsk取3秒，其余5秒；不使用自定义 UnitIsHero/N534/SAPPER 代替。后续获得抗性不回写已存到期。每个逻辑施法者/目标一条注册 Aven感染，A011/A012与已核 N093/N095 共用这条键；同实体换形后刷新更新 DPS/到期但保留1秒相位。不同施法者独立，包括相同单位类型；异常同源同时持多个已注册 Aven只取最高 DPS一次，平手按ID排序。
4. 初次施加后1秒首 tick，此后每秒。局部调度包含到期端点 tick，再清理；同刻已先入队的死亡/显式移除可取消未执行 tick。无刷新时普通200/400原始总额，英雄120/240；这些不是减免后的生命承诺。同一来源换档变弱也可将后续 DPS更新为40。
5. 每条 tick 由实际原 S 发 `false,false,NORMAL/NORMAL` 物理包，非武器攻击、非暴击基数。在原生减免后/地图回调前取 `min(max(0,reduced),max(0,HP−2))`；零额不发事件，低于2HP不治疗。**后续地图增伤仍能致死**，不在最终提交强行留2HP。各来源分别完整执行 B03，不把所有毒合成一次事件，也不因两个 Buff ID 就重复打一份 DPS。
6. DataD1不含攻速叠加位，本地注册 Aven 的攻速下降取最大值（本组均.2），向攻击 R减.2；缺 DataC在本范围明确选移速下降0，不能把提示“20%减速”直接写成20%移速。源死亡但句柄有效继续，源删除取消；来源移除技能或变回人形不取消已提交毒。

普通魔法/负面驱散不清毒；明确移除 Bpoi清注册感染及关联缓速，明确移除 Bpsd仅清本毒缓速/状态直到下次刷新，不删除 DOT。目标死亡/删除或不再满足类型/物理受体条件清除；新魔免本身不清。沿用已有毒接口，不因这个新 ID 重写其他未核毒技能的行为。

## 蓝龙寒冷：40%移速与60%攻速，包含武器溅射

[暴雪冰霜巨龙说明](https://classic.battle.net/war3/undead/units/frostwyrm.shtml)明确其攻击附范围寒冷，并把停止建筑活动的 Freezing Breath分成另一技能。当前蓝龙只挂 **Afrb(A013)**，没挂 Afrz，所以没有建筑冻结、BPSE、眩晕或主动打断。原生详细叠加/驱散/魔免与目标提交时序不能由名称证明，以下是本范围 Q24 选择：

- 攻击发射时来源实际 A013有效、非幻象；在成功普通武器的每个合法受害者上、其伤害包前施加寒冷，包括本武器的溅射受害者。不会因一个伤害事件的 attack 标记而对任意技能/反弹再附寒冷。没有第二份伤害、耗蓝/CD/随机/N535或技能施放事件。
- 敌方地空非建筑/守卫，包括机械，排除隐藏/Aloc/无敌/虚无；局部按物理攻击附效允许魔免，不把这个选择扩大为 Q45 的 AHca 冷箭魔免规则。普通攻击可以伤建筑，但本 A013寒冷不使建筑减速或停摆。范围受害者普通隐形不排除。
- 移动速度乘 .6，攻击 R减.6；不是“剩60%攻速”或瞬时打断。施加时 native HERO/有效 Arsk为2秒，其余3秒。单A013槽重复命中刷新到 `现在+对应持续`，不累加百分比或时长。既有 BPSE 可以独立同时存在，寒冷不清除/延长BPSE。
- 对本 A013 与已决 Q45 冷箭，仅此两组采用独立来源/到期槽，保留各自原刷新规则，实际移动/攻击减速分别取仍有效槽的最大值。Bfro是合并可见状态，不是重复计算的第三份寒冷。普通驱散只清 Q45可驱散槽，不清本 A013物理寒冷；明确原始 Bfro移除则清这两组注册寒冷槽。A013到期后仍未到期的冷箭继续生效，不被一起清掉。其他 Frost Nova/Frost Armor/装备冷效不由此自动纳入。
- A013显式效果移除、目标死亡/删除/到期或不再合格时清除；新魔免不单独清除。来源死亡/删除/换形不撤销已经提交的寒冷。移动和攻速变化交给现有空间/攻击时序接口；不倒退攻击进度、不给已发弹道改速。

60%攻击减速来自地图明确常量，40%移速与图鉴完全相符；不是从标准蓝龙10秒或标准游戏冷效50%/25%套来的值。

## 武器：绿龙单体，红/蓝龙 msplash

全部12形态[武器记录](../../reference/map-6.25/units_unitweapons.json#L20004)仅槽1开启、类别 HERO，射程1200、攻击前摇.26/后摇.64；[弹体 profile](../../reference/map-6.25/units_campaignunitstrings.txt#L1)逐个明确900速度、追踪1。基础间隔除E006/E028为.9外均1.2，按 attack-timing-v1 缩放。castpt=.3是施法字段，不能替换攻击前摇.26。原始 dmgplus/dice/sides逐形态保存；原始武器金额 R 与 S18/S19 读取/写入复用已采纳的[攻击属性接口 W01–W03](weapon-field-source-notes.md#L79)。R 使用贡献通道和本次一次骰子和，不能由整数 getter 拼出，也不能只把模板字段算术当最终攻击力。本页在原发射时点捕获 R，形态提交怎样改变模板/属性通道仍由完整 AEme 事务处理。

| 绿龙1/2 | missile | 存在休眠圆环，但不启用溅射 | 仅主目标 |

槽2虽然记 chaos/missile，但 `weapsOn=1`，不能额外发射。所有形态实际 `movetp=hover,targType=ground`；飞龙模型和高度150不把它自动变空军。两套皮肤的武器/能力数据相同，模型大小不参与命中半径。

以下是 **msplash 的局部 Q24 规则**，与[炮击](creep-line-and-artillery.md)共用单次原始攻击/逐受害者事件接口，但不复制其 Attack Ground、250最小射程、友军溅射或未命中规则：

1. 源正常提交普通攻击，快照 R武器原始额、形态武器与附效、稳定S。源最小射程字段缺失，本范围选0；发射时目标须在1200内、可见且普通武器合法。主目标可敌方地面/空中/建筑/机械/守卫，排除隐藏/Aloc/无敌/虚无，魔免允许HERO物理伤害。显式手动友军攻击仍走普通接口，不自动搜友军；不提供炮击式地面攻击入口。
2. 弹体按二维追踪900，目标普通隐形不自动停止追踪；死亡/删除后向最后已知点继续，绿龙若无合法存活主目标则无命中，msplash仍可在该点形成范围候选。来源死亡后已发弹继续，显式删除来源取消。变身后旧弹体不切换颜色档效果/数值。轨迹不额外加地形遮挡或模型碰撞。
3. 合法主目标即将命中时，沿 [native-critical-family-v1](native-critical-family.md)收集/快照一次真实已注册暴击候选并做普通命中检查；不逐溅射目标重抽。未命中已消耗正常随机，本 msplash 弹局部选择不产生单位伤害/毒/寒冷；这与炮击保留旁观溅射的选择不同。如果主目标已不存在或不合法而弹体在最后点形成范围，无主目标型暴击/命中抽样，取 M=1、B=0，只保留普通 R的范围份额，不捏造新的 ATTACKED目标。
4. 到达时以当前追踪接触点/保存落点为中心取外圈闭圆，合法原主目标先、其他 B04；每单位一次。距离 `<=F`全额，`F<d<=H`中额，`H<d<=Q`外额，之外0；中心距离不加碰撞半径、不加总圆环、不线性内插。主目标在接触中心只吃一笔全额，不再叠另一笔范围伤害。每位执行前重查存在/生命/免疫/位置，嵌套地图事件能改变后续结果；新出现而不在初始快照的单位不临时加进本弹。
5. 溅射掩码实际是 `ground,structure,debris,air,enemy`，因此只选敌方地空/建筑/机械，不伤自己/友军。普通隐形可被范围命中，排除隐藏/Aloc/无敌/虚无，魔免允许。ward/item只作为合法指定主目标，不扫描成旁观溅射对象。原生冰霜巨龙说明里“不对空军溅射”属于其标准武器配置，**本图只有一个已开启且明确对空的 msplash槽**，不能拿标准单位的另一个单体槽删去自定义对空溅射。
