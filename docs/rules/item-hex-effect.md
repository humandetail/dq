# 共享妖术效果：item-hex-effect-v1

本页完成邪恶镰刀 i202／雪落法杖 i325 的共享 `i202_Skill`、直接临时单位包装器和 T049 变羊效果。**Q30 的共享 50% 概率及原触发过滤保持不变**，详见 [共享妖术入口](item-hex-proc.md)；雪落法杖独立落雪主动不在本批范围。

`item-hex-effect-v1` 将已核脚本、原数据与 Q24 授权的 Web 原生适配分开记录；不是原客户端实测。字节码及对象记录、23 个边界案例见 [机器表](item-hex-effect.json)。本批没有确认新的可遇到图鉴冲突，原生英雄时长字段的边界见第 4 节。

## 1. 脚本实际上执行两个独立效果

[main.disasm](../../reference/map-6.25/main.disasm) `main/f245/f0`，L127935–128070，共 90 条指令、3 个条件、21 处调用；对应 [阅读稿](../../reference/map-6.25/main.readable.lua) L81101–81195。已逐条核对循环、所有条件与参数：

```text
S = GetTriggerUnit()
L = GetUnitLoc(S)
x,y = GetUnitX(S),GetUnitY(S)
G = GroupEnumUnitsInRange(x,y,700,null)
while (T = FirstOfGroup(G)) != nil:
    GroupRemoveUnit(G,T)
    if IsUnitOwnedByPlayer(T,Player(11)) and LIFE(T)>0:
        D = CreateTempAndSetAbilityLv(owner(S),L,0,"T049",1,1)
        SetUnitUserData(D,GetUnitUserData(S))
        IssueTargetOrder(D,"hex",T)  // 返回值不检查
GroupClear(G)
DestroyGroup(G)
SetPhyDamagePoint(S,0.2,700,x,y,1)    // 无条件登记，来源仍是S
RemoveLocation(L)
```

关键字节码：范围枚举 L127994–128000；移出组、Player(11) 与生命检查 L128010–128025；创建临时单位、复制归属索引和命令 L128026–128048；清理组和延迟物理包 L128052–128070。3 个条件分别是“组首为空则结束”“属于 Player(11)”“生命严格大于 0”。**脚本没有在这里判断建筑、飞行、魔免、无敌、召唤、Boss 或变羊是否成功**；其中一部分由 T049 原生施法层决定。

因此不能先用变羊的全部有效目标条件过滤组，再只为成功对象创建临时单位。符合脚本 Player(11)/生命门槛的每一个对象都会先创建一名临时施法者，命令即使失败，也继续循环。即使组为空、所有单位都不满足脚本条件或所有变羊命令失败，末尾仍登记**一份**延迟物理包，不是每个目标一份，也不是仅对变羊成功者补伤害。

## 2. 临时单位、归属和字段

`CreateTempAndSetAbilityLv` 为 main/f7/f20，字节码 L51457–51510，共 33 条指令、1 个条件、8 处调用；阅读稿 L31456–31490。第七参数未提供时默认类型 `q001`；按传入拥有者、位置和朝向创建单位，添加指定能力并设置等级，再 `UnitApplyTimedLife(dummy,BHwe,lifeSeconds)`。本次参数为：

| 参数 | 本次值与含义 |
| --- | --- |
| 单位类型 | q001；每个合格枚举对象单独创建 |
| 位置、朝向 | 原施法者函数开始时的位置，朝向 0；不是受术目标位置 |
| 拥有者 | 创建该名临时单位时读取的原施法者拥有者 |
| 能力 | T049，等级 1 |
| 计时生命 | BHwe，1 秒；不是变羊持续时间 |
| UserData | 随后复制原施法者索引，用于原有来源归属体系 |
| 命令 | 原生 `IssueTargetOrder(dummy,"hex",target)`，不是脚本的零秒命令包装器 |

q001 的原始记录：`units_unitabilities.json` L6555 为 `Avul,Aloc`；`units_unitbalance.json` L37578 为初始/最大魔法各 1000、生命 65；`units_unitdata.json` L19502 为飞行、空中目标类别；`units_unitui.json` L33684 的模型字段为 `_`。不能把它变成可攻击的玩家塔或可额外出售的召唤物。它仍是有类型、拥有者、UserData 和创建序号的逻辑单位，不能为省实体数合并所有临时施法者。

q001 位于 `IsTemp` 初始列表（字节码 L49860–49863），判定函数 main/f7/f15 在 L51273–51303。T049 生效事件即使走原通用施法分派，也会在 `AnySkillStart` 的临时单位早退处结束（L170040–170066），不再进入装备施法响应，不会由这些临时单位递归抽妖术/细雪。

**Q24 选择：**专用 q001 的一次 T049 命令以零前摇同步接受并生效；没有明确数值的此次耗蓝设为 0，不能把这项选择推广为所有 SLK 缺省字段均为零。生效时保留嵌套施法事件及父事件上下文恢复，普通脚本全局变量不自动回滚。有效施法会使用 T049 的 17 秒冷却，不过每名临时单位只收到这一次命令，因此不能把 17 秒加到原装备的共享触发上。

1 秒计时生命到期按共享单位死亡生命周期处理，不额外造成伤害，不用静默清除代替死亡事件；尸体/移除流程仍由共享单位生命周期负责。本次变羊状态独立于施法者生命，临时单位死亡或之后移除不会提前结束已经成功施加的 2 秒或 1 秒状态。

## 3. T049 原数据与原生资料的证明范围

[units_abilitydata.json](../../reference/map-6.25/units_abilitydata.json) L33209–33226 的完整记录没有对应 `war3map.w3a.json` 覆盖：

| 字段 | 原值 |
| --- | --- |
| code / BuffID1 | `AOhx / BOhx` |
| levels / Cool1 / Rng1 | `1 / 17 / 5000` |
| DataA1 | `1000` |
| DataB1 / C1 / D1 / E1 | 全为 `nsha` |
| Dur1 / HeroDur1 | `2 / 1` 秒 |
| targs1 | `air,ground,enemy,organic,neutral` |

[YDWE 工具附带元数据](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/AbilityMetaData.slk#L6928)将 AOhx 的 DataA–E 映射到 Ply1–5；对应 [编辑器字段名](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/UI/WorldEditStrings.txt#L6106)是最高野怪等级，以及地面/空中/两栖/水上变形单位。`adur/ahdu` 分别为普通/英雄持续时间，字段名在同一 strings 文件 L5838–5839。故 DataA=1000 **不是移速或额外伤害**；四种变形外观都指向 nsha。

地图 nsha 是羊：UI L15541 的模型为 `units\\critters\\Sheep\\Sheep`，balance L17294 的 `spd=100,minSpd=100`。它的原始生命 15 等属性不是被变羊目标应被覆写的新生命值。T049 的 [字符串提示](../../reference/map-6.25/units_campaignabilitystrings.txt) L19890–19898 仍写 15 秒，与有效数据的 2/1 秒不同；该临时能力提示不能覆盖图鉴或实际字段。

[暴雪 Hex 说明](https://classic.battle.net/war3/orc/units/shadowhunter.shtml)确认普通/英雄时长区分、空中/地面与有机目标、英雄可受术、禁用技能与物品、移速 100、可打断吟唱，以及不影响召唤单位。[官方法术说明](https://classic.battle.net/war3/basics/spellbasics.shtml)描述魔免、负面法术护盾和抗性皮肤缩短效果。它们未证明本图客户端的精确施法提交、覆盖刷新、所有被动与原生护盾触发顺序；这些按下文 Q24 明确选择，不把公开其他版本说明当本图实测。

另查 [Warsmash 开发者实现](https://github.com/Retera/WarsmashModEngine/blob/f9e0aeed4be372d6016519d0e97b384aa873f374/core/src/com/etheller/warsmash/viewer5/handlers/w3x/simulation/abilities/skills/CAbilitySpellBase.java#L77)，其通用持续时间函数用 `isHero()` 选 HeroDur。它是独立实现，只帮助区分字段和原生英雄标志，**不证明原 Warcraft 客户端行为，也没有补齐本图 Arsk 的精确规则**。

## 4. Web 变羊门槛、持续和刷新

本节为 `item-hex-effect-v1` 的确定规则。范围枚举借用 `area-damage-v1` 的**二维中心闭圆几何**，半径 700，不加碰撞半径；按 B04 创建序号形成组快照。这里仍是脚本的组枚举：不提前套范围伤害的敌我/无敌/魔免筛选，组内对象的当前 Player(11)/生命条件在原循环位置检查。新创建对象不加入该快照。

对每条 T049 命令，施法层在生效前重新检查：目标存在、生命>0、属于相对于临时施法者的敌方或非同盟中立方、有机且为地面或空中单位、非建筑/机械/召唤单位、非无敌/魔免、无有效 Aloc；非原生英雄的单位等级须≤1000，原生英雄不套“最高野怪等级”。5000 施法距离仍保留。原集合是 700 圆，不把 5000 误写成装备范围；本适配不另外施加隐形侦测/视野门槛。目标类型和免疫来自运行时有效字段/能力状态，不按名称或模型猜测。

无效目标拒绝该命令，不消耗目标法术护盾，也不施加 BOhx；循环继续。有效目标若有就绪护盾，则命令已接受并发生该名临时单位的施法生效，但护盾拦截状态，见第 5 节。两种失败都不撤销末尾物理包。

**成功、未被护盾拦截时才确定持续时间：**

- 普通目标取 `Dur1=2` 秒，对应图鉴 `装备与道具!H112/H218` 的普通基础持续。
- 原生 `UNIT_TYPE_HERO` 目标取原字段 `HeroDur1=1` 秒。
- 生效的 `code=Arsk` 抗性皮肤也取 1 秒，作为 **Q24 明确的 Web 抗性基准**；原图 N534 就是 Arsk，另有 ACrk、ACsk、Arsk 同类记录。此选择依据已知的“缩短负面持续”效果及现有两组字段，但不是原客户端 1 秒实测。

这不是以地图 `UnitIsHero` 选择时长：后者是 `N534 && SAPPER` 的自定义谓词。单有 SAPPER、名字叫 Boss 或在 Boss 列表中都不缩短；相反，确实生效的 Arsk 不要求再有 SAPPER。N534 在 abilitydata L27010；m005 等主线怪，以及 ma02–ma06、mw14 等相关目标有记录可查。尚未找到并证明 Player(11) 的可达**原生 HERO**目标，故本页保留 HeroDur 数据边界，不制造“所有 Boss 原版必为 1 秒”的用户问题。

持续时间在这次成功施加时读取当前英雄/抗性状态并固定；中途获得或失去抗性皮肤不重算已有实例。每个目标仅保存一个本效果的 BOhx 状态，跨装备和施法者共享：再次成功妖术使到期时间变为 **本次成功时刻＋本次持续时间**，覆盖旧实例，不累加，也不取更晚的到期值，因此新时长较短时可以缩短旧状态。最后一次成功的来源记录覆盖旧来源；被护盾拦截或无效的尝试不刷新。

每次应用取得新状态代号，旧到期回调失效。到期按 B05 排序的有效回调移除该代号；同刻事件严格按队列顺序处理。显式驱散负面魔法可提前移除并使旧回调失效；死亡同样移除，不带到复活后。受伤本身不解除妖术。单纯变成魔免不会由本效果额外轮询并清除旧实例；若具体能力另有已核的驱散步骤，该步骤照常处理。

## 5. 控制效果与 N535 的必要适配

**Q24 控制选择：** BOhx 使用 nsha 外观覆盖，保留同一逻辑单位 ID、拥有者、UserData、生命/魔法、护甲和能力列表，飞行对象也不因羊模型被强制落地。它不是创建一只 15 血新羊然后删除旧怪。

成功施加时打断正在进行的主动施法/吟唱及尚未提交的攻击前摇；期间禁止新的普通攻击、主动施法和主动使用物品。已经发出的独立弹道、已提交的伤害或独立脚本计时任务按各自原规则继续，不追溯撤销。移动命令和已有路线可继续；没有其他移动锁时，本效果将有效移速覆盖为 100，到期/驱散后重新计算当前正常移速及其他修正，不恢复一份过时的速度快照。其他控制锁不会因妖术结束被解除。

不删除目标能力等级，也不统一封停地图的被动伤害回调、属性、光环或已登记计时器。地图代码仍可检查这些能力并调用直接脚本效果；其后下达的原生主动命令会被妖术控制锁拒绝。原生被动的逐项封禁没有匹配版本证据，本基准选择保留上述被动/脚本效果，不能假称完全复制原生 Hex 的每种被动交互。

**N535 法术护盾是本次所需的真实目标能力。** abilitydata L27020 的 `code=ANss,Cool1=6,BuffID1=BNss`；unitabilities 中 ma02–ma06 和 mw14 初始携带。不是所有 Boss 都自动有护盾，也不从单位名字推断。原 map 没有用 Lua 包装这次 hex 来显式处理它。

本批只为 T049 制定确定门槛：目标先通过上节有效性检查，再检查有效 N535 的 `now>=shieldReadyAt`。若就绪，拦截本次 BOhx，并令 `shieldReadyAt=now+6秒`；若尚在冷却，则本次妖术可成功。新获得能力的初始状态就绪；使用共享能力冷却状态，不能每件装备各保存一份护盾。无效目标不会消耗护盾。这里的接受/拦截顺序是 Q24 选择，不扩写 ANss 对其他全部技能的行为。

护盾只拦这一条变羊效果，**不删除那份 0.2 秒后的物理范围包**。同样，魔免、召唤/机械/建筑门槛或最高野怪等级造成的变羊失败，不给目标附加针对后续物理包的保护。

## 6. 0.2 秒后的 1 点物理包与伤害主流程

原参数经 main/f7/f30（L51941–51970）提交：

```text
source = 原施法者S                // 不是任意q001
center = 函数开始时捕获的(x,y)    // S移动后不跟随
radius = 700
rawAmount = 1
delay = 0.2秒
attack=false, ranged=false, attackType=HERO,
damageType=NORMAL, weaponType=WHOKNOWS
```

完全复用 [area-damage-v1](native-area-damage.md)：在到期时重新查询范围敌方集合、按稳定序号处理，源死亡但仍存在时继续，源提前移除则取消。后一项和具体几何/调度仍是该基准的 Web 选择。最初被变羊的单位若已走出圆，可以不受这次伤害；后来走入的有效敌人可以受伤而从未变羊。后续范围包可以命中魔免、机械、召唤或建筑对象，只要满足范围包自身规则；它没有“身上有 BOhx”或“曾被成功 hex”的条件。

**1 是传入原始金额，不是保证最终扣 1 血。** 每名目标仍按 B03 经适用原生减免，再进入 [完整伤害分派](damage-pipeline.md)：

- 实际来源保持 S；按该来源正常执行归属逻辑，不把来源替换为施法用 q001。前置装备 L162607、后置装备 L164515 保留原条件与顺序。
- `attack=false` 排除明确要求普通攻击标记的特效，却不跳过整个装备分派、属性加成、怪物响应、物理分支或模式修正。伤害可能被放大、改零或另派生伤害。
- PC2480–2509（L165109–165139）在目标命令为空/stop/attack 时可能调用 `MonKeepMove`。妖术允许移动，因此这类原地图响应仍有意义；不能因为原金额小就删除事件。
- b115/b138 的特殊建筑判断要求攻击标记非零，本包不能伪装成满足条件的英雄普攻。怪物随后尝试原生主动施法时，妖术锁可拒绝命令；直接脚本响应不因锁而统一跳过。
- 本主程序没有 BOhx 的字面检查；不能另加“被妖术怪物免伤”或“受这 1 点伤害马上解除妖术”的规则。金币计分、商店归属和统计继续按原流程，不能简化成直接改生命值。
