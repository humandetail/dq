# N576 超新星

## 规则

主线 m050 实际持有 N576。原 B03 PC3098 按当前生命/上限严格<.3且就绪时下 elementalfury。成功提交耗300蓝、40秒CD，按 ANef 开始6秒替身期。单一实际 b138 凤凰蛋出生于 m050 当前点（原范围字段10，单蛋按 Q24 取中心），原 m050 保留同一ID、路线、模板和已登记点数，在替身期隐藏、停止行动且不可被选择。蛋是实际 P11独立实体，模板生命33、points=1、N534/SAPPER，套原敌方通用召唤登记、继承父路径号、仅共享表，不继承父最大生命、抗性或个人池。原本体仍在登记时也有自身points。按已经确定的幂等登记规则，蛋只加一项。蛋无普通武器，不给它新设攻击模式。[入口](../../reference/map-6.25/main.disasm#L165746) · [对象与模板](supernova-egg.json) · [敌方召唤登记](challenge-spawns.md)

PC2573–2605 原伤害特殊规则读实际S和当下 D，S 非空且是原生 HERO、attack非零且D>0才写 D=1，其余写0。已有真实引擎拒绝、0攻击伤害或普通攻击未命中继续先处理。动态解析的归属O是英雄不能代替实际S为英雄。写1处于 B03 中间，后续仍可调值，不能把任意英雄来包都承诺最终固定扣1。蛋死触发自己的普通实际死亡收尾，由引擎替身失败边界使原隐藏本体死亡，无成功FINISH；本体没有额外复制蛋击杀者。被直接清掉的一侧按已定原生移除接口执行，不造第二份奖励。[蛋伤害分支](../../reference/map-6.25/main.disasm#L165201) · [ANef 实验](https://github.com/Cokemonkey11/wc3-ability-doc/blob/main/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md)

6秒到期蛋仍存在且存活时，先结束蛋的替身期并清登记，使原本体同一实体在当前蛋锚点恢复，保持原路线号。然后发一次成功 FINISH。原 f216 在本体当前位置生成同所有者的1秒 q001/T097，先给 stomp，再播视觉，再读并填满本体当前最大生命。T097 零直接伤害，敌方半径1200，BPSE 4秒（包括原生英雄），保留对象无敌选择、魔免及原生硬控状态接口。单次 FINISH 和时间终了不重做花费；仅 ENDCAST、尚未生效的打断、提前失效或蛋已死不走成功补血，不重放控制。B05 持久化父子身份、进入点、蛋当时位置、状态和剩余时钟。[FINISH 入口](../../reference/map-6.25/main.disasm#L172400) · [眩晕与回满顺序](../../reference/map-6.25/main.disasm#L120901)

## 差异

原文本沿用熊猫三分身，但对象填入一个真实 b138；按对象和原分派只产一蛋。首次命中 PC 规则只有一段，对后部倍率不另豁免。Web Q24 用已有形态和死亡接口补齐替身行为，原客户端未实测。
