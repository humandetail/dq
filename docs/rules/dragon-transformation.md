# 真龙形态 A010／A239

局部基准 **`dragon-transformation-v1`** 确定两种真龙形态的施放、20 秒返回、冷却、状态继承与存档。沿用 [12 个龙形态及其四项攻击被动](dragon-attack-passives.md)、[同实体换皮及 Skill_BS_Still](skin-and-transformation.md)、[武器贡献及字段写入](weapon-field-source-notes.md)。[机器表](dragon-transformation.json)保留图鉴逐格值、对象参数、脚本行号和探针范围。

## 提交与源事件

Web 对两变体使用同一个无目标 `metamorphosis` 准入。实体须存在、存活、可操控、能施法、实际拥有启用且已学的技能槽，等级 1–6，当前蓝足，`state1=0` 且没有本实体活跃的真龙形态。预检拒绝不切命令、不耗蓝、不动 CD，也不发施法事件。异常同时存在两个实际槽时，无参数命令沿 A010→A239 顺序解析实际可用者；UI 按当前实际槽位发令。技能槽满级或被剥级不影响已提交的投射物或已上毒。

1. **开始。** 受理后同一模拟时点发 CHANNEL、CAST，脚本如果在提交前令实体不合法或撤销本次施法，发一次 ENDCAST，不提交资源、形态或基础冷却，也不发 EFFECT／FINISH。ENDCAST 仍可能按源移除 B164、写入剩余 0 秒并发 stop。进入提交前重验资格，玩家没有可插入命令的前摇窗口。一般眩晕、沉默、命令禁用沿共用准入，DataB 标志不绕过这些准入。
2. **提交。** 结算旧回复至当前时间。由此时实际 ID 和等级取上表配置，原子扣一次魔法、设置 30 秒初始 state1、切换同实体模板并登记 20 秒的返回事件。B031、临时生命及新模板武器在 EFFECT 回调观察前已生效。保存请求等本时点同步事件链完成。
3. **EFFECT → AnySkillStart。** 非玩家 11、非工人、非背包圈，且不在 `J003_Hero` 值集合时，两种 ID 都经 `skill_bs_id` 调用一次 `Skill_BS_Still`。它位于 IsTemp 提前退出之前，故即使临时实体也先按这四项判断。普通路径依序走 `Item_Skill_Action(nil)`、`WAbility_initAbility`、W012、W014、W016、W018、`ItemSkillUsed`、`Model_Change`；真实皮肤目录对 A010/A239 返回空。无目标查询不提供有效单位或用户指定地点，保留公共助手自己的过滤和副作用。[EFFECT 分派](../../reference/map-6.25/main.disasm#L170000)、[公共尾段](../../reference/map-6.25/main.disasm#L172145)
4. **FINISH → AnySkillEnd。** 非临时实体先走共用 f15 清理分派（两龙 ID 均无额外清理），再按当时 `Has_A_Item` 实际资格把本次 rawcode 的剩余 state1 写 21；有实际单位的龙施法路尾发 `stop`。共享神杖与实体 i310 同样满足资格；不把装备变动固定成施法快照。[FINISH](../../reference/map-6.25/main.disasm#L172233)
5. **ENDCAST → AnySkillStop。** 同一模拟时点按下节真实冷却分支处理。非临时有效单位且非玩家 11 的尾部再发一次 `stop`。两次显式 stop 照普通命令接口停止当前动作，保留已提交投射物。已经提交的形态由其自身生命周期结束，施放交易只终结一次，20 秒返回没有新 FINISH/ENDCAST。[ENDCAST](../../reference/map-6.25/main.disasm#L172450)、[末尾 stop](../../reference/map-6.25/main.disasm#L172886)

这三个地图入口均注册玩家 0、1、2、3、11 的事件。EFFECT 使用 TriggerAddAction，FINISH/ENDCAST 使用 TriggerAddCondition。回调关联与内部次序来自字节码，AEme 以同一模拟时点完成施放交易是 Q24 选择。[三个事件注册](../../reference/map-6.25/main.disasm#L179727)

## 冷却、自施法与增伤

state1 是当前剩余秒数。YDWE JAPI 的 getter 由到期时刻减计时器当前时刻，setter 写独立的能力计时器。Web 使用同一战斗时钟，形态期间照常扣减，采用到点明确归零的语义。神杖无其他缩减时，t0 提交→t20 返回→t21 可再施，符合提示里返回后 1 秒的表现。无神杖时 t30 可再施，返回后余 10 秒；中途拾/失神杖仅改变后续动态资格，不重新计算已发生的 FINISH 写入。[JAPI 原作者实现](https://github.com/actboy168/YDWE/blob/master/Development/Plugin/Warcraft3/yd_jass_api/AbilityState.cpp)

`AnySkillStop` 在有效非临时、非工人／背包圈时执行两个独立区块：

- i327、B164>0、B167>0 任一满足，读取一次 state1 后乘 .8。B164 的移除位于统一 OR 门槛内，只排除当前 A190；龙施法经过该移除，不管本次靠哪一项进入。i327 图鉴 `装备与道具!H220` 的20%吻合。A066/A206、A169 的下限分支不适用于两龙 ID。
- B180>0 时重新读取此刻 state1，再乘 P222 1–10 级对应的 .99→.90，其他等级乘 1。它可在上一项之后执行，不能拿原 30/21 直接覆盖上一项，也没有龙技能最低冷却数值。
- **神杖让每个乘区少写一次。** 第一区块 PC113–148 中，A010 有杖由 l113 跳 l131，再跳 l141 写一次。A239 有杖由 l113 跳 l123 写一次，再由 l131 跳 l149。两者无杖均写两次同一个本区块结果。第二块 PC242–277 的 l242/l252/l260/l270/l278 同构。各区块只读取一次 state1，两次写不复乘。[0.8 区块](../../reference/map-6.25/main.disasm#L172656)、[第二乘区](../../reference/map-6.25/main.disasm#L172802)

|---|---:|---:|---:|---:|
| 无杖，无缩减 | 30 | 30 | 20 | 30 |
| 神杖，无缩减 | 21 | 21 | 20 | 21 |
| i327，无杖 | 30 | 24 | 20 | 24 |

自动施法仍从 Player(11) 的 ATTACKED 路径按 B012 开关与 A010→A239 的顺序调用原 `Unit_Ability_Has_Cool_Down`。它只检查实际等级>0、剩余严等于 0、当前蓝≥当级费用。即使形态还在也可能发一条 `metamorphosis`；失败后照原脚本跳到物品尾段，不尝试 A008 等后序技能。**活跃形态单占用**是 Q24 的局部命令准入选择：活动期把该命令视为同一条原生形态事务占用，防止原生兼容差异造成刷新/堆叠；不伪造一秒最短冷却，也不把状态检查改写进 Lua 自动就绪函数。原客户端是否允许本自定义形态内重发尚未验证。[自动施法](autocast.md)、[真实就绪检查](../../reference/map-6.25/main.disasm#L52213)

B031 是随本形态存续的单份标记。`anyUnitDamaged` 在已核归属 O 当前含 B031 时，以当时的 D 乘 `1.1 + (Has_A_Item(O) ? .1 : 0) + (Game_Mode==1 ? .2 : 0)`。无本段本地攻击标记／物魔限制，源单位／归属、其他增伤与减免次序复用既有 B03。A008 火焰印记的独立伤害辅助也读取实际来源当前 B031 来选择当前生命的 30% 或 40%；其完整命中/目标/计时规则由 A008 模块负责。变龙的百分比不预乘到毒、本次弹体或武器模板数字中。[B031 伤害分派](../../reference/map-6.25/main.disasm#L164646)、[A008 火焰印记 B031 检查](../../reference/map-6.25/main.disasm#L61658)、[伤害管线](damage-pipeline.md)

## 同实体进出与外部中断

- **实体与模板。** 正常 A010 的返回类型 H003，A239 返回 G077。事务保存实际进入前的人形模板；受外部授予出现当前人形与 DataA 不符时，实际 rawcode 仍决定龙目标，退出恢复施放前版本。类型提交使用同实体模板替换接口，当前模型、武器、移速模板、夜视与回复模板随类型；坐标、所有者、物品实例、永久来源、技能、技能点／付费记录、状态和外部引用保留。G077 即使目标可学列表仍写 A010，实际槽依然 A239。H003 的 S371 模板皮肤书在龙形态期间缺席，退出恢复；普通命令不能在龙形态靠旧书直发 S372。基础三围及成长对 14 个模板一致，故本两种正常往返自然差为 0。等级与资格变化继续使用各自接口。
- **武器/资源。** 用现模板新武器基础、骰子、攻击类别和新前／后摇，保留 W01–W03 的脚本与装备通道。state37 进出先按目标−旧模板 `cool1` 重基准，state81 不复制或重复计入；现有 Skill_BS_Still 到 +3 秒的覆盖仍按此刻模板、i304、A111、i282 真实分支。该原回调可能覆盖先前 C 的脚本修改。比如带 i304 的第六级变龙由人形 1.0→龙形 0.7，+3 秒按 .9−.2 覆盖，回人形又由 .7→1.0。既存独立 timer 在原时点继续，退出不重新执行 Skill_BS_Still。
- **攻击范围。** 局部 Q24 令普通范围/acquire 走模板重基准（800↔1200）并保留其他实写偏移。对 i282 单独记录源拾取、掉落与 +3 秒回调对 state22/acquire 的数值贡献，源调用照常执行。进入时按 EFFECT 的四个计时器门槛决定初始值，适用 Skill_BS_Still 的实体在切龙时清旧的 i282 实写偏移，交给 +3 秒回调按当时持有和有效变身技能加回。其他实体在切龙点直接按当前持件贡献更新。退出时移除龙形态阶段的该物品净实写分量，再按人形当时持有装回单份（普通近战+100，两字段分别处理）。原回调若在两次独立组内触发仍各自执行。例：一直持件为 900→1200→1400→900，前 3 秒掉落则原掉落代码立即减 200，有效范围暂为 1000，返回按无件恢复到 800。原客户端对 i282 的原生重算未实测。[物品接口](item-lifecycle.md)
- **空间。** 两套人形和所有龙形都是 ground、碰撞72；龙形 hover／模型高度150，空间碰撞不改成空军。坐标、人口、地表占用实例不重建。保留既有脚本移动覆盖（普通英雄塔建成已设 type1），+0.04 开始仍照源最多写 74 次 type1，+3 秒清自身两计时器，不自动授予自由移动。没有额外的停攻击窗口、路径挤位、重新建造或占位释放。Acha/AEme均不得以删旧建新来模拟。[空间接口](pathing-and-placement.md)、[计时接口](attack-timing.md)
- **生命。** 500 作为独立有期限的最大生命贡献；入口存活当前生命也按实际最大值差加 500，退出减实际差，下限1、上限当前最大值；死者仍为0。例：最大1200、当前800→1700、1300；龙形中降到200再返人形→1200、1。这是本 AEme 的 Q24 回退，既不等同治疗事件，也不占直接 MAX_LIFE 偏移。包括 A009 击杀永久生命在内的直接最大资源写入，在龙形期间只改变各自真实通道并保留到退出。魔法除一次扣费、当前动态回复／真实属性变化外不重设，`mana0` 不当作回蓝。未来经验、回复和其他属性变化依当前有效输入继续。[属性接口](hero-attribute-interface.md)
- **取消与外部变化。** 未提交的取消参考上方事件链。提交后 stop、眩晕、沉默、失去神杖、剥级变到 0 或禁用技能都不会改变本次施法锁定的颜色／档位和到期。显式删除实际逻辑能力槽、显式移除本形态来源 B031、死亡、移除实体或外部永久类型提交，均终结本次记录一次。普通驱散不清除形态来源 B031；同名的其他明确来源由其自己的移除规则负责。死回人形仍死亡，保留有效句柄和独立回调；移除实体只撤销本记录。永久类型强制提交先撤旧形态再落新类型，禁止旧到期回滚本次 Acha；皮肤外层脚本的掉装、属性、ANeg 顺序照常，ANeg换 ID 属逻辑槽迁移，不按能力显式移除处理。冷却随逻辑槽迁移，除非该槽实际彻底移除；死亡/提前退形不重置已有 CD。
- **到期与存档。** t20 以 B05 登记序号执行，从当时状态撤与本次形态相连的被动 / 500 / B031，恢复已记录人形，不回写旧 HP、蓝、属性快照、背包、等级、直接数值或旧坐标。同刻若攻击结算明确先于返回，动态 B031 尚有效；先返回则旧弹体仍带其发射快照，但读取当前 O 已无本条 B031。已经施加的毒／寒冷保留自己的生命周期。序列化实体、当前模板和来源、实际 ID／逻辑槽／等级，以及进场前模板、临时 HP 贡献、到期事件、B05 序号、能力剩余 CD、既有 Skill_BS_Still 两 timer 和 i282 分量。读档恢复下一次真实事件，不重放蓝耗、stop、属性、选皮、技能学习或攻击。无效旧句柄不转给替代塔。

## 复现与边界

[验证工具](../../tools/audit-dragon-transformation.py)复用已有 Lua 反汇编执行器，记录相关 EFFECT／FINISH／ENDCAST 真实路径、条件跳标及写入顺序，并执行三个完整注册函数、变身就绪 helper 与独立 Web 合约。使用带 openpyxl 的 bundled Python 执行本工具，默认比对已登记机器表，`--write` 可再生。测试将物品/神器通用助手记录为真实调用边界，A008 完整机制、其他变身技能、整套原生引擎仍由各规则模块完成。没有匹配 Warcraft 客户端试验，探针结果是字节码＋原生桩及 Web 规则检查。

715 个字节码探针、34 个合约向量通过。三种事件注册分别覆盖 48/48、50/50、50/50 条指令。EFFECT、FINISH、ENDCAST 的执行覆盖为 997/1984、83/159、260/332，分母包含其他技能的分支。37 份原始快照哈希和两份图鉴压缩包校验通过。
