# A189 启明与 A191 灵魂形态

## 规则

两技能前摇.3秒、后摇.1秒。A189 手动800点选 `revive`，耗蓝90/140/190/240/290/340，冷却12秒。A191 手动900点选 `absorb`，耗蓝100/120/140/160/180/200，冷却15/14/13/12/11/10秒。B012 采用原先700范围的 P11 自动目标。两波统一采用 AUcs 已核实时扫掠，起点为实际载体当前位置，按命令方向以1500/秒行进1500，圆半径400，保留对象目标掩码和合法敌方判定，每波每个目标一次。效果于载体出生后立即下单，载体寿命1秒；都走法术伤害及原归属解析。[第四批入口](hero-spells-batch-04.md) · [AUcs 通用边界](creep-skill-family-001-053.md) · [实际弹速 T207](../../reference/map-6.25/units_campaignabilitystrings.txt#L21868) · [T408](../../reference/map-6.25/units_campaignabilitystrings.txt#L23390) · [自动施法94/95](autocast.md)

### A189

生效建立一次蓄力，锁定点选位置、开始时刻、1/2/2/2/2/2秒上限和可视蓄力点（沿初始朝向前200）。提前已提交中断和达到上限都走原 ENDCAST 释放，满时计时器本身只请求 Stop，前摇取消无该实例。防止超时和 ENDCAST 在同刻重复发波，以实例ID 检查并消费本次释放资格。重新建立同塔蓄力时取消失效的旧任务，旧 ENDCAST 不取新实例。发波从释放时本塔当前位置指向原点，不以200视觉点代替。按 Q76 用 `clamp(释放时刻−开始时刻,0,提交时上限) × 释放时 A189 档位的每秒量`，六档率1500/2000/3750/4500/5250/6000。释放时持神杖再乘1.9，金额保留精度直接进入 T207 母包。q064 记录 O，母包命中的既有 B218 先作用，随后可施加 B218。精确0蓄力的提交结束仍可发盲波，0点母额自身不制造伤害事件；用合法波命中登记控制，不伪造正伤害门票。[提交与停止](../../reference/map-6.25/main.disasm#L99533) · [释放](../../reference/map-6.25/main.disasm#L99650) · [ENDCAST](../../reference/map-6.25/main.disasm#L172560)

### A191

生效时在原塔位置造一个面向目标、2秒寿命的 q063 视觉分身，光球视觉在该方向前200。按该200点固定本次投射瞄准点，1.2秒后真正的 T408 载体从塔的实时坐标出发，向这个已固定点下 `carrionswarm`。到期用塔当前 A191 档与是否有杖选择基础金额3000/5000/7000/9000/11000/13000、普通 q001 或持杖 q062。已排队的每个分身独立保存瞄准点和到期任务，保存/读档保留同序；无可用来源引用时取消晚发，不让旧任务借新实例。神杖已发波保留 q062 身份，即使后来失杖。q062 碰撞在哪一档与有多少智力，按解析到的 O 碰撞时实时 A191 档和 `GetHeroInt(O,false)` 读，附加4/4/6/6/8/8倍基础智力的独立法术子包，来源为 O。母包对原有 B218 放大，然后尝试刷新 B218，最后同步发子包。[分身及延迟坐标](../../reference/map-6.25/main.disasm#L100045) · [命中次序](../../reference/map-6.25/main.disasm#L100244) · [PC921 与933](../../reference/map-6.25/main.disasm#L163456)

### 共用致盲之光

A189、普通 A191 与持杖 A191 的母包命中时按已有 B218 决定×1.6，先查后刷新。A189 原 q064、神杖 A191 原 q062 在被击目标当前位置造1秒 T409 载体并向目标下 `innerfire`，通过通常法术合法性后施加或刷新 B218 5秒。普通 A191 只用已有标记加成。B218 本身是敌方相关状态和视觉 tag；T409 的攻击、防御数值未设置，通用陈旧模板说明不赋友军属性，亦无额外失手率。普通 A191 匹配本次 T408 事件身份，在原 q062/q064 回调顺序的同层读 B218，独立于无关 q001。神杖 INT 子包不是 T408 母包，不再次套本地致盲倍率。保留 B03 上游早退、当前原生魔免与状态写入顺序。[T409 与状态回调](../../reference/map-6.25/main.disasm#L100303) · [B03](damage-pipeline.md)

## 差异

- A189 原 Lua 先对整秒向下，再换 T207 千伤档，神杖再对千伤档向下。源探针满1秒第1档 T207=1，提前0.75秒甚至请求0级。Q76 按实际蓄力连续计算，保留上限和神杖。第1档满为1500，持杖为2850；第3档1.75秒持杖为12468.75。
- A191 原 q001 普通母包没有进入 q062 处理，因此即使已经有 B218 也不放大。专属提示在常规伤害段写明已致盲时额外60%，神杖段另列 INT 并施加状态，按 Q71 补普通母包倍率和保留神杖子包独立。
- A191 原每塔只有可查找的一个 timer/运行位置。重施覆盖旧槽却没有取消旧计时器，旧到期出现索引−1和空瞄准点。图鉴的每次施法各自生成分身，Web 用逐实例关联修复，不更改共同的实时等级/坐标/神杖读点。
