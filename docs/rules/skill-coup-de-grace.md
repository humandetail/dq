# 恩赐解脱：A027原生暴击与既有秒杀入口

本页补齐A027的六级原生暴击、与普通攻击和额外秒杀的关系，以及本技能涉及的幻象/物品暴击交互。**图鉴两行都对应A027，六级均为10%，倍率依次为10、14、18、22、25、30。没有新增图鉴冲突。** 下文 `coup-de-grace-native-v1` 的明确Web选择依据Q24；不宣称本图原客户端已实测。

既有[秒杀脚本与Q26突破防御](combat-and-skills.md)保持。秒杀的 `2/1001、4/1001、1/1001` 不改成10%，也不把本页变成新的概率裁决。机器表见 [skill-coup-de-grace.json](skill-coup-de-grace.json)。

## 2. 原生暴击与额外秒杀是两条路径

AOcr是引擎普通攻击被动，A027脚本模块只定义 `A027_Action`和 `A027_Get_probability`，没有用Lua实现10%暴击。完整 `A027_Action`为 [main/f29/f0，B63370–63490](../../reference/map-6.25/main.disasm#L63370)，先显示“恩赐解脱”、调用 `UnitKillUnit(S,T)`，再按TxShow与G052身份播放不同特效；不读取本次是否暴击，也没有给父伤害乘10或30。

既有额外入口 [main/f291/f1，PC513–552，B163033–163072](../../reference/map-6.25/main.disasm#L163033)要求**实际来源S的A027等级恰好6、事件attack非0**，随后抽一次原秒杀helper；成功后才排除m999/m998与Game_Mode=2。没有“先原生暴击成功”条件。helper [main/f29/f1，B63492–63535](../../reference/map-6.25/main.disasm#L63492)保持：主线阈值2，无尽阈值4，幻象覆盖为1；原区间0–1000，严格小于阈值。深渊及金币目标到达此处仍先抽样，再拒绝秒杀效果。

`UnitKillUnit`仍是[main/f7/f44，B52387起](../../reference/map-6.25/main.disasm#L52387)创建q025、归属和0.5秒生命、再发10,000,000神圣伤害；不是KillUnit。[q025技能 L6675](../../reference/map-6.25/units_unitabilities.json#L6675)只有Avul/Aloc，`SetRealDamage`传 `false,false,CHAOS,DIVINE`。这是额外脚本伤害，不能再乘A027倍率，也不能从“秒杀”二字保证必死。

按[B03](web-baseline.md)，原生暴击组成原普通攻击包并经过适用减免，随后地图流程读取它；A026的Q26修正仍在原位置处理当时事件值。若额外秒杀触发，子事件提交后恢复父事件，继续其原流程。两个随机结果可以独立成功：**原攻击不暴击也可触发秒杀，暴击成功也不保证秒杀**。脚本 `attack=true` 的直接伤害仍可按原入口到达秒杀判断，但不是仅靠该标记就重新启动原生武器暴击。

## 3. 已查原生资料的边界

[暴雪剑圣说明](https://classic.battle.net/war3/orc/units/blademaster.shtml)确认普通Critical Strike是增加攻击伤害的被动，也写了stock技能不作用建筑、旧镜像看似暴击却不造成普通伤害。它没有证明本图空targs的自定义A027、可造成伤害的AIil幻象或六级扩展数值的执行。不能用stock镜像的零伤害覆盖本图明确的30%/50%幻象参数。

[原作者能力实测记录的Critical Strike段](https://github.com/Cokemonkey11/wc3-ability-doc/blob/main/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md#L1037)标注测试版本1.36：倍率字段用于乘伤害，并记录同时触发时较高倍率生效；概率精度选项、额外伤害仍有版本或待测说明。这提供采用“取最大”的参考，**不证明本图客户端的多件相同物品、随机分布或幻象继承**。本页没有拿其他引擎重实现当作原版实测。

因此以下独立随机、判定时点、空目标字段、同物品实例叠加、幻象快照和伤害合成次序都是明确Q24选择。资料支持字段语义，图鉴固定数值；查证后未知处不冒充来源事实。

## 4. Web普通攻击接口

1. 本技能只接入**真正普通武器攻击的主目标包**。在攻击流程即将判定主目标命中、已通过普通攻击合法性检查时，快照实际来源当前生效的A027等级与下节有效物品实例。取消且未到此点的攻击、非法目标、技能/范围/反弹/秒杀子包不抽原生暴击。不因A027另造普通攻击事件。
2. A027有效等级1–6，每次独立抽 `uniformInteger(1,100)<=10`；未学/不生效不抽。选择独立随机而非未确证PRD；没有隐藏累计概率。先抽A027，再按物品实例创建序号抽各有效物品；不因A027已成功而跳过后者。结果与等级保存在本次攻击上下文，落空或命中回调不重复抽。
3. A027不增加必中、额外固定伤害、闪避、Buff或控制；也没有耗蓝、冷却。本页将空targs适配为沿用**该普通攻击的合法目标**，不额外排除飞行或建筑；这是自定义技能的Q24目标选择，不称stock技能事实。它不绕过无敌、伤害免疫或攻击合法性。
4. 所有适用倍率候选独立判定，取成功者的最大值 `M=max(1,successMultipliers)`。普通武器原始伤害R只抽取/组成一次；`raw=R*M+B`，B为成功命中类AOcr贡献的固定奖励之和。倍率不会相乘或相加；B不被倍率再次放大。R已包含生效普通攻击加成，不重复加入武器属性；缺R/能力状态提供者属于集成错误，不能填0。
5. 成功的必中贡献取逻辑或。没有必中时继续既有普通命中流程；**A027成功本身不免除落空/闪避**。落空不提交攻击伤害事件，也不到达额外秒杀判断；但已抽的原生暴击结果不退回随机序列。命中后保留原武器的attack/ranged/attackType/damageType，先适用原生减免，再进入地图流程。其他命中率及弹道系统不由本页重写。
6. 幻象的普通攻击输出系数f在倍率与固定奖励合成后应用一次：`raw=(R*M+B)*f`；正常单位f=1。这里的f来自实际创建能力/既有幻象规则，不用统一30%或50%代替所有幻象。脚本额外秒杀包不乘本项f，不随普通攻击暴击次数重复。

## 6. 幻象：脚本事实与局部快照选择

实际AIil入口包括：[i272幻影斧／T165命令，B132516–132533](../../reference/map-6.25/main.disasm#L132516)，[i274幻影匕首／T166，B132623–132635](../../reference/map-6.25/main.disasm#L132623)，[幻想神符I225，B136732–136739](../../reference/map-6.25/main.disasm#L136732)。它们向目标下达852274原生命令，并非Lua逐项复制单位能力。T165/T166的DataA1分别0.5/0.3、持续7秒，[L35667/L35682](../../reference/map-6.25/units_abilitydata.json#L35667)；I225为0.3、持续10秒，[L22037](../../reference/map-6.25/units_abilitydata.json#L22037)。这里核创建来源和字段，不把两次发令直接宣称为原客户端已接受两次。

`UnitBeComeEvent`读取召唤者和召唤物，再调用handler，[main/f291/f21，B173544–173567](../../reference/map-6.25/main.disasm#L173544)。关键 **BIil分支**是 [main/f291/f20，PC1–74，B173201–173277](../../reference/map-6.25/main.disasm#L173201)：先解析召唤者/临时单位的归属；BIil>0时将召唤物置于召唤者坐标、设置归属索引，处理已有A123/A230后return。**该分支没有复制/升级A027、物品或通用英雄技能。** 它不经过后面的普通召唤物装备加成分支。

Misc的[两项幻象攻击/攻速继承开关 L40–41](../../reference/map-6.25/war3mapMisc.txt#L40)是明确配置，却不能证明技能、物品能力、Buff全量继承。额外秒杀helper特判幻象仅证明“已有六级A027的幻象到达入口后用阈值1”，不能反推出引擎必然赋予它六级A027。

查证后按Q24，本模块在**幻象真正创建成功时、召唤回调前**，以被复制目标此刻的实际状态建立局部快照：

- 复制其当时已持有的A027等级；未学则不生成该能力，不凭heroAbilList补一级。幻象本模块产生真实普通攻击暴击，不只显示红字。后续本体学习、遗忘、出售装备或死亡不自动同步既有快照；新幻象取新的状态。明确针对幻象自身的后续技能增删仍照常生效。
- 仅为本模块复制上表五种当时**实际生效**装备实例的原生攻击贡献，并保留复制来源的稳定实例次序。它们是幻象内的虚拟被动实例，不生成可交易物品、不触发拾取/合成、不给真实物品增加充能，也不将一整套装备脚本/Buff宣布为可继承。其他装备和属性继承仍由相应规则提供。
- A027的10%对幻象不减为1/1001；后者仍仅用于六级额外秒杀。幻象有自己的后续独立抽样序列位置，不复用本体某次攻击结果，也不复制PRD累计状态（本规则无PRD）。A027消失或被禁用时，本次原生被动不参与；已有秒杀分派仍严格按其原查询条件执行，不擅加新的通用门槛。
