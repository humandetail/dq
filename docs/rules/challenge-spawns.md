# 挑战怪和技能召唤敌人的登记

## 规则与来源

共享容怪由仍有效的敌人实体及其对象 points 累加。个人模式只看该入口池，团队看共享池。每个实体最多占共享池一项，只有入口参数0–3才进对应个人池，−1只进共享。登记不靠怪名字、阵营 alone 或是否可攻。所有实际死亡和移除统一撤该实体的容怪、路径与实际伤害监听；自然计时死亡继续原死亡，纯删除不构造击杀和奖励。一般波次的排序/失败不重定义。[共享登记 f294/f36](../../reference/map-6.25/main.disasm#L186248) · [个人点数](../../reference/map-6.25/main.disasm#L58750) · [团队点数](../../reference/map-6.25/main.disasm#L58873) · [波次边界](web-wave-boundaries.md)

### 挑战商店

第11波开，54波关闭。挑战通知、按钮推进、每玩家240秒预约沿原购买事件。第一个对应出生任务在点击10秒后开始排定；计数为1的各族 .1秒后发首只，多怪魅惑魔女每.5秒一只，共12只。首只因此分别在10.1／10.5秒。每次实际发波前店已隐藏即不生成；54波关闭隐藏商店，清活挑战怪及其登记并取消正在生成的周期，即便10秒预约稍后到期也不能复活该店。预约和阶段库存各自保存，不在恢复时重新付费或重置间隔。[按钮事务](item-lifecycle.md#L106) · [队列](../../reference/map-6.25/main.disasm#L138432) · [关闭](../../reference/map-6.25/main.disasm#L138624) · [预约](../../reference/map-6.25/main.disasm#L138752)

## 差异

源 CreateDamageTrig 本身插入共享。N548 与通用 P11 召唤先额外 AddArrAny，N555 在真实注册后额外 AddArrAny。原一个 ID 得两槽，容怪加两次，死亡只删第一次匹配。N548 先遇到未加 trigger 的槽时，真实伤害触发器也会遗留。Web 幂等处理使同单位实际 points 只计一次，真正独立的不同召唤物、个人池权重、技能访表、伤害包仍按各自身份处理。普通挑战原只登记一次。
