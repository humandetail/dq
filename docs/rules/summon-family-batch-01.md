# 召唤技能第一批

A049（含皮肤 A130）、A167、A209、A215 已有可实现 Web 规格。A125 熊灵仍待独立生命周期专项。机器表保留每级对象、单位武器和辅助记录，只用各主 ID 计本批完成数。

## 共用接口

这些技能都是无目标命令，沿已核 [施法准入](native-targeted-batch-01.md) 在前摇结束后按当前可用等级支付蓝、起冷却、同步发一次 SPELL_EFFECT；取消在提交之前，后续移动不改变已经出生的实体。自动沿 [Skill_Auto](autocast.md) 的相应无目标命令，不因无敌人替自动原分支加门槛。母体被生效链杀死或删除时取消尚未开始的原生创建，已提交的资源不回滚。召唤不占建造人口，不重放装备获取、英雄成长或学习事件。

每支新实体使用自己的模板、所有者、技能和武器状态，同步触发其 SUMMON。通用 S18、出生装备与 Q55 契约、实际 S 和 SAPPER 按当前 Tower_ALL 归属 O 沿 [群蛇守卫已核接口](ward-summons.md)。本批普通四项继承当时有效三围×0.4／i240 单独0.5／任一高阶0.6；原极端三围重新计算、A168 自光环与 A216 额外 T275 均按各自源接口。非深渊原通用 handler 把移动类型写1，禁止自主移动；深渊保留各自模板运动类型和速度。死亡守卫模板本身缺移动速度取0，所有模式静止。 [SUMMON处理](../../reference/map-6.25/main.disasm#L173119) · [狼与兽王光环](hero-aura-family-next.md)

Q24 保留本图 AOsf/AIfs 的 Area 字段作为相对出生偏移。生效时以施法者当时位置为圆心，以面向为第一个方位，N 个产物等角分布，半径取对象 Area；一对象从面向方向的阵位生成。阵位按产出次序处理，A215 先鹰后猪。越界或地表不合法时，在同一地图边界内按距理想阵位的距离和行列序取最近静态合法格中心；无静态选址时退到地图内最靠近该点的格中心。这是即时召唤的局部规则，允许初始动态重叠、保留总数，移动单位随后按[初始重叠可分离](pathing-and-placement.md)处理，未给这些技能新增施工判定。不同类型明示的碰撞半径保留，缺失的本批取0。飞行以飞行层查询。

各实体有效期间自行按已定 [攻击计时](attack-timing.md) 选定主目标；当前目标有效时保留，丢失后按自身索敌范围、实际武器掩码、可见敌方和 B04 选择，范围外移动只在模板可移动时发生。显式攻击命令仍受实际掩码和射程限制。原模板普通/穿刺/英雄/魔法攻击类别、武器与投射分法分别保留。自然到期派一次死亡、停索敌和未提交攻击，已发箭继续；显式 RemoveUnit 取消未命中武器弹。复用群蛇守卫的自然到期和存档接口，保存当前实体与期限、入队顺序、同槽记录、普通在途武器和独立 Buff。Avul 保护正常伤害，计时寿命/显式删除仍生效。
