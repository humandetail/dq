# A214 野性飞斧

## 规则

- **施放。** 兽王 H056 学习 A214，1–6 级均耗蓝 0、冷却 12 秒、点目标射程 1200、施法点 .5 秒。手动使用 `carrionswarm`，自动按既定顺序和 B04 选择 1000 内首个合格 P11 目标，以其当时位置下点命令。成功时按公共施法提交一次，`A214_Action(S,castPoint)` 读取提交点。原生 AUcs 的常规波形伤害字段为空，本技能的两斧轨迹与伤害由 A214 专属代码驱动。[施法提交](native-targeted-batch-01.md) · [自动](autocast.md) · [范围外壳](area-active-batch-01.md)
- **每次施放。** 以唯一 `castId` 存计数、0.03 秒周期、两柄 q053、三个固定路径点、原施法者 S 与其动态塔槽，以及两柄斧各自的访问表。两柄载体生于 S 提交时的位置和所有者，以点击方向面对，附 BHwe 3 秒兜底寿命。载体的坐标由周期直接写入，Aloc/Avul 载体承担表现与取样坐标。S 面向取点击角向下取整。
- **路径。** 以 S 提交位置 C₀ 和点击点 D 求方向 a=角(C₀,D)、b=角(D,C₀)。F 是沿 a 距 C₀ 1200 的固定汇点。B₁/B₂ 分别是 C₀ 沿 a−90°/a+90° 偏移 150，E₁/E₂ 分别是 F 沿 b+90°/b−90° 偏移 150。原偏移量是 `I2R(|C₀F|/3)`，正常为 400；用它分别从 B₁/B₂ 朝 E₁/E₂ 投影得到固定 P₁/P₂。重合点仍走公共角度函数。仅初段和回收段插值使用捕获 S 的实时 XY，已捕获的 F/P₁/P₂ 保持原值。每步 n 的两斧各自执行下表的线性插值，倍率从该行起点向终点计算。

| n | 斧 1 | 斧 2 | 比例 |
| --- | --- | --- | --- |
| 1–11 | S→P₁ | S→P₂ | n/12 |
| 12–32 | P₁→F | P₂→F | (n−11)/22 |
| 33–53 | F→P₂ | F→P₁ | (n−32)/22 |
| 54–63 | P₂→S | P₁→S | (n−53)/12 |
| 64 | 移除 | 移除 | 只回收、无扫描 |

- **命中。** 先移动两斧、读回各自当前 XY，再按斧 1、斧 2 顺序分别 B04 枚举闭圆半径 200。只取所有者 P11、当时生命 >0 且原生分组可枚举的单位。斧 1 的完整同步 B03 伤害可变更斧 2 枚举时的目标状态。伤害取样为离散点位置，交错点与前后取样之间无扫掠碰撞。每柄按真实目标 ID 一次，往返始终保留命中记录；两柄遇到同一目标时可以各命中一次，包括同一步。提交包后写入该柄的访问表。按 B03 结算减免，点目标外壳不为斧头的范围命中打开定向 N535 检查。
- **金额和来源。** 每步开头先读取原塔槽 `Tower_ALL[index]` 当前有效单位 O 的 A214 等级 L 和最大生命，整步两柄、全部目标共用递交量 `maxHP(O)×(L+3)/10`。1–6 级为 40/50/60/70/80/90%，仍有效但技能变为 0 级时原式为 30%。伤害包的实际来源始终是本次捕获 S，走 `SetPhyDamage` 的 `false,false,HERO,NORMAL,WHOKNOWS`；随后的归属按 B03。槽中 O 变化可以改变金额，原 S 的实际来源与形态不因此改绑。S 死亡但句柄仍有效时保留该路径；永久移除的 S 不转赠为继任塔的伤害来源，按 B03 处理无效来源。[最大生命接口](hero-attribute-interface.md) · [B03/B04/B05](web-baseline.md) · [伤害管线](damage-pipeline.md)
- **回收。** 正常在 EFFECT 后 1.92 秒第64步，或下一周期查到动态塔槽无有效单位时结束。结束先在可用 O 上实时调用原 `Has_A_Item(O)`，成立且能力句柄有效时把当前 A214 冷却 state 1 写 0。飞出后装备或失去神杖以回收时为准，保留回收可直接刷新同一个技能冷却的规则。只销毁本实例周期与两柄载体，释放点和访问表。对同一来源的更新 cast 仍按自己的 64 步运行。[神杖](scepter-lifecycle.md)
- **存档。** 与 B05 一起保存 castId、原 S/塔槽 ID、两柄载体及其斧索引、F/P₁/P₂、下一步和到期键、对应两份真实目标 ID 集。恢复继续下一次取样，重新读取 O 的当前等级、最大生命和回收时神杖。

## 差异

- **Q63。** 原两次扫描访问同一个塔槽目标表，并在第32步扫描前清空。一个持续站在交汇区域的目标可两次都被斧 1 命中，同段先被一柄碰到的目标会被另一柄跳过。按图鉴与用户确认，每柄使用独立访问表且不在第32步清空，仍保留第32步至第33步的原轨迹转折。
- **Q54。** 原重施覆写以塔槽为键的计数、周期、两载体、路径点、施法者和访问表。旧周期随后反查得到 −1，清理时拿不到旧周期及两载体，遗留定时器和载体。Web 以 castId 绑定全部状态，过期回收自己。
- 原技能提示写同一目标可受两次伤害，图鉴及 Q63 落实为每柄至多一次。点击位置只定方向，1000 自动范围、1200 施放/轨迹及200采样半径分别保留。
