# 敌方光环与补充能力

## 规则与来源

敌方光环沿共同实时资格、中心闭圆和生命周期。同 Buff 的同通道取有效最强源，来源退出或死亡后回落，离圈不留额外独立效果。持久化有效来源和实际速率快照，恢复时不重抽或累计两遍。同组独立属性通道保持既定速度、护甲和回复限制。友方光环包含自身；敌方光环不把魔免等平台状态当普通标签，仍走已选敌方目标资格。[光环接口](hero-aura-family.md#L93) · [资源时钟](night-state-and-regeneration.md#L45)

## 差异

N553/N545/N546/N547/N556 每一个原 Ubertip 都是通用旧模板，对比分辨原对象实际字段。N556 百分比回复基准和换装不重采采用 AHab 独立编辑器实验作为 Q24 选择，常规固定加蓝的技能保留原契约。Aoar 在同类实验中已对应百分比血量回复，Web 复用按当前上限的共同正回复通道。 [原字段词典](https://raw.githubusercontent.com/actboy168/YDWE/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/UI/WorldEditStrings.txt) · [AHab 和 Aoar 直接实验](https://github.com/Cokemonkey11/wc3-ability-doc/blob/main/sources/screwthetrees-wc3-editor-ability-insight-document/2023-11-14.md)
