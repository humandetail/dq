# A007 石化凝视：概率、暂停与解除

本批核查 A007 完整模块、伤害事件入口、计时回调及必要的自定义 Boss 判定，并有界核查 N536 提前解除与 T302 对石化表的读取。**没有展开整个 A164 模块或全部控制效果。** [skill-stone-gaze.json](skill-stone-gaze.json) 保存全部模块条件、源字段与验证向量。概率 Q33 已确认：主线／无尽采用各级准确百分比，深渊固定3%；原 `/101` 公式另存为来源事实。

`B` 是 [main.disasm](../../reference/map-6.25/main.disasm) 行号；PC 为指定函数内部指令序号。模块 `main/f19` B61027–61382。关键分支按字节码核查，不依赖阅读稿重组。

## 2. 触发入口与准确原概率

主伤害函数 `main/f291/f1` **PC293–315，B162801–162823**：

1. 实际伤害来源 S 的 A007 等级>0；
2. `IsUnitIllusion(S)==false`；
3. 调用 `A007_Get_probability()` 取得整数阈值 t；
4. 再抽一次 `GetRandomInt(0,100)`，若 r<t 则调用 `A007_Action1()`。

目标是当前事件 `GetTriggerUnit()`，不是周围范围枚举。此处不检查 attack 标记、物理／魔法类别、目标所属玩家或 Boss／金币 ID，没有额外耗蓝、冷却和每次攻击去重。只有归属塔 O 持有 A007、而实际来源 S 没有时不会触发。DOT、技能包等也必须实际进入这一分支并满足来源资格，不能一概替所有归属伤害补抽。

该片段之前的 N142／N152 attack 条件仅管各自分支，没有包住 A007。更早的初始零伤害 return、q039 旁路、B177 攻击提前 return 仍适用，详见 [damage-pipeline.md](damage-pipeline.md)。A007 这里没有再次判断 D 是否为正，因此“原始零伤害已提前返回”和“先非零进入后又被写零”不能混为一谈。

`A007_Get_probability`（`main/f19/f3` B61302–61382）**只返回阈值，不自行抽签**。先读实际来源的 A007 等级，随后：

```text
Game_Mode == 2：直接返回 3，不再看等级分支
其他模式：等级1..6依次返回 5、6、7、8、9、12
非深渊且等级不在1..6：返回0
```

深渊分支 PC9，B61338，真路径 PC11–12 返回3；等级判断在 PC13／18／23／28／33／38。深渊优先于等级，所以直接调用函数时，即使等级不在1–6仍返回3；正常入口另要求等级>0。

原抽签有101个整数，真实概率为 **t/101**。例如6级主线／无尽12/101≈11.881%，深渊3/101≈2.970%。图鉴和原图实际提示均没有写深渊例外。用户 Q33 已确认保留原图深渊补充，但使用准确百分比：6级主线／无尽12%、深渊3%；这里的 `/101` 只记录原脚本。

## 3. 目标资格、持续时间与写入顺序

`A007_Action1`（`main/f19/f0` B61059–61208）重新取 S、T；T 当前生命≤0就 return。**这个检查在成功抽签之后**，因此伤害事件目标已死或后续重复被拒绝，仍已消耗本次随机数。没有额外 nil 检查，也没有伤害后死亡复查。

持续时间只分两档，不随技能等级变化：

| 判定 | 登记的持续秒数 |
| --- | ---: |
| `UnitIsHero(T)==true` | 0.2 |
| 其他 | 1 |

这里的 `UnitIsHero` 是地图自定义函数：**N534 等级>0且原生 UNIT_TYPE_SAPPER 为真**；不是原生 UNIT_TYPE_HERO。字节码 `main/f7/f45` B52444–52480 已核：N534不满足时返回false，满足后才取SAPPER判断。只有原生英雄类型、只有N534或只有SAPPER都不足以进入0.2秒档。阅读稿在此辅助函数曾有失真，不能照其表面表达式重写。

如果 T 已在全局 `A007_units` 表中，并且 `IsUnitPaused(T)` 为真，立即 return：不改外观、不建 timer、不续时。否则按顺序：

1. 顶点颜色设为 RGBA=(96,96,96,255)。
2. 动画时间缩放设为0。
3. `PauseUnit(T,true)`。
4. 从槽1开始，找首个单位为nil **或该槽单位生命≤0** 的位置。
5. 新建一次 timer，持续0.2或1秒，回调 `A007_time_end`；随后写入 `A007_timers[i]` 和 `A007_units[i]=T`。

没有调用眩晕技能、没有在 T 身上添加一个石化 Buff，也没有伤害包。上述是明确脚本写入；暂停对移动、施法等全部 native 行为的细节不由几行 setter 独立证明。

三个英雄数值相同。只有实际来源为 G043 且 TxShow=true 时，创建 `AZ_ShuiJingShiHua.mdx`，持续与本次 timer 相同，随后立即把目标恢复白色255；**暂停与时间缩放仍保持**。G043关闭特效或其他皮肤则保持灰色到解除。颜色不能作为是否石化的可靠判据。

## 4. 重复、提前解除与计时器清理

两张表是全局表，不按施法者分隔。多个美杜莎／皮肤不会各自绕过“已登记且暂停”的重复拒绝。

- 正常已经石化且暂停的目标：再次抽中仍不刷新持续时间。
- 目标被其他机制提前 `PauseUnit(false)`，但 A007 表项尚在：再次抽中可写入另一槽，形成同一目标的多条记录，**旧 timer 没有被取消**。
- 某槽目标已死：分配可复用该槽，覆盖旧 timer 句柄；没有先销毁旧 timer。旧 timer 到期查不到自身，仍会销毁自身，不得据此误清新目标槽。
- 目标虽然被其他效果暂停，但不在 A007 表：仍可登记；A007到期会写 `PauseUnit(false)`，没有保存其他暂停所有者或上一状态。

到期函数 `main/f19/f2` B61239–61300 先查 timer 索引。只有“索引!=-1且对应单位不为nil”时，依次写白色255、时间缩放1、暂停false，然后清两张表的该槽。没有存活检查，不恢复进入石化前的自定义颜色或时间缩放。**无论索引或单位是否有效，最后都 DestroyTimer。** 若找到 timer 但单位槽为nil，原函数不清 timer 数组槽，只销毁句柄。

重叠示例：t=0登记1秒石化，t=.4被外部解除暂停，t=.5再次登记；两个到期点是1和1.5。第一个 timer 在t=1就会恢复目标，第二条记录仍在表中，直至t=1.5再恢复并清除。不是自动延长到1.5，也不是“仍在表中必定仍暂停”。这是源代码已明确的交互，不用 Q24 擅自改成引用计数控制。

模块还导出 `A007_time_start(timer)`（`main/f19/f1` B61210–61237）：创建一个监听 timer 到期的 trigger，添加同一结束动作，最后只清局部变量，未销毁 trigger。全主程序中没有找到该名称的静态调用；正常 A007 直接用 `TimerStart` 回调，不能额外再注册这个 helper，导致重复结束。

## 5. 提前解除与伤害联动的限定事实

**N536 海妖外壳可在同次伤害事件后部解除暂停。** 主管线 PC3099–3110、B165764–165775 在目标有N536时调用；本批完整核了 `main/f190/f0` B115496–115598：

1. 当前可变事件伤害 D==0 时 return。
2. 若目标已在 N536 私有表且 D>当前生命，清该表项与计数并return。
3. 若未登记，建立记录、计数0；随后计数+=D。
4. 当累计**严格大于**最大生命×0.1时，计数归0、移除负面 Buff、`PauseUnit(false)`、恢复默认飞行高度，并显示特效。

它不清 `A007_units/A007_timers`，也不写回 A007 的时间缩放或颜色。故石化计时0.2秒不等于控制必定维持完整0.2秒；重复应用还会受上一节的表项／暂停状态组合影响。深渊福利小鸡另有周期解除暂停，已在 [waves-and-modes.md](waves-and-modes.md) 记录；本批未扩成全部控制效果调查。

**A007自身没有通用承伤加成。** 全主程序对 `A007_units` 的唯一模块外直接读取是 `A164_T302_Eff`，本批只核它与石化有关的片段：`main/f115/f9` **PC27–46、B89785–89805**。该次派生魔法包原式为 `T302等级×私有蛇段计数×2000`；目标在 A007 表中就×2，再用参数0单位作为实际来源发 NORMAL/MAGIC、attack=false、ranged=false伤害。它**不要求目标此时仍暂停**，也没有把所有来源的所有伤害都翻倍。

原图 T302 实际提示也明确“对石化凝视作用下的石化单位将造成双倍伤害”（units_campaignabilitystrings.txt L22963），与这项特定联动一致。该 helper 从主管线的 q034 来源／归属塔有 T302 的分支调用，见 [damage-pipeline.md](damage-pipeline.md)。这里没有递归核完整 A164 蛇链的生成、段计数生命周期与全部分支，不将局部倍率例子冒充整项技能还原。

## 6. 已决 Web 规则、验证和完成边界

概率 **Q33 已决**：主线／无尽按等级1–6使用5／6／7／8／9／12%的准确概率；深渊固定3%。保留任意伤害、实际来源、非幻象、之前的早退／旁路，以及“先取阈值，再抽一次，抽中后才检查目标生命／已登记暂停”的原时点。

深渊判断仍先于等级分派：先读取等级，若 Game_Mode==2，阈值函数立即返回3；不得先加“等级必须1–6”限制。非深渊遇到未匹配等级才返回0。外层独立的 `A007等级>0` 门槛不变，所以正常伤害入口的0级来源不抽签；7级之类超出图鉴档位但仍>0的来源，在深渊仍是3%，非深渊是0且保留一次抽签。阈值函数仍返回整数百分比点 t，Web 在原调用点执行一次准确 `t/100` 概率判断，不把返回值改成小数后继续套原整数比较。

目标、持续、重复拒绝与已知解除交互均保留原规则。本批只落实已确认的概率差异，没有用 Q24 覆盖未核查脚本。

模块4函数共 **195指令、17个条件、28次调用、14个return指令**；另完整核查的 UnitIsHero 与 N536_Action 共 **82指令、6个条件、13次调用、5个return指令**。计数含隐式不可达return；模块13条初始化指令另记，不混入函数合计。

55个验证向量（原始与Web概率分列）覆盖六级三模式概率、抽签边界、非法等级、四种自定义Boss组合、重复暂停、死槽复用、提前解除后的双timer、nil／死亡目标清理、皮肤特效、任意伤害／幻象／实际来源门槛、T302仅查表倍率和N536严格10%门槛。JSON、源行／条件跳转、图鉴与实际提示、源哈希和链接进行静态校验；未运行客户端或游戏。

仍未闭合的是原生setter在移除句柄和其他控制并存时的细节、原生对象缺省字段，以及完整A164和全部外部控制写入者。Web B03/B05给出事件提交与同刻回调顺序的已选语义，不冒充原客户端实测结果。

本页历史列出的原生接口缺口已在[旧技能接口收口](legacy-control-and-cast-closure.md)逐项解决；当前实现规则以该补充及本页原脚本事实共同为准，原客户端未实测单独保留。
