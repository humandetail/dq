# A079 猴子猴孙

## 规则

- H024 孙悟空和 G036 齐天大圣用点命令 `repair`，提交前摇 .3、射程800、冷却20，1–6级耗蓝 50/60/70/80/90/100。自动取600内 B04 首合格活 P11 的坐标。合法空点可手动施放，位置按本次提交点捕获。成功后同步造阵，不额外发一个能伤害的 ANcl 母包。[外壳](hero-spells-batch-02.md)
- **阵型和所有者。** 以提交点为中心，先在半径400的方位 (72°×i,i=1…5) 造5只，再在半径800的方位 (40°×j,j=1…9) 造9只，所有者取当前 `GetTriggerPlayer`。每只朝出阵方位+180°，向内。精确位置优先，越界或静态不可落点使用已有即时召唤回退。允许初始动态重叠，不另置塔占位。每只 BHwe 13秒、450生命、Avul/Aloc、moveType 1，保持静止。各晚到的旧组继续按自己原出生时间到期，重施只建新组，无旧组替换。[阵形成员](../../reference/map-6.25/main.disasm#L74572) · [即时落点](summon-family-batch-01.md)
- **继承。** 同一 cast 在建阵前读取有效 A079 档、实际施法者的 W01 `S18+S19`、当刻形态和 `Has_A_Item`。每只在独立武器系统建立继承攻击属性 (S18+S19) 的50/60/70/80/90/100%，用 W02 把 S19 设为继承额减该只实际 S18，沿已定精度转换。模板自身2d5保持普通攻击骰，不再给继承显示额加原脚本固定120或重复底数。已经出生的单位的继承、模板与神杖不随塔后续换装/升级重算。没有通用召唤 handler 或本次 W01 数据以外的额外装备、三围继承。写 UserData 塔表索引，使真实来源仍为该只猴子、O 由 B03 动态解析。[共享攻击字段](weapon-field-source-notes.md)
- **模板及普通攻击。** 无神杖 H024/G036 分别用 b117/b118，有神杖使用 b139/b140。四模板第一武器 HERO、普通 `normal`，前摇 .4，后摇 .77，基础间隔1.3，索敌与攻击距离700，射程缓冲800。持杖模板+100索敌和攻击距离，保持900缓冲，以+25%独立攻速输入到 T01/T02（无其他贡献时 1.3/1.25=1.04秒）。`weapTp1=normal` 有效命中走同刻普通武器结算，未使用空闲的溅射参数或图像弹速1300制造副击。空地、建筑或原掩码内的其它物件各自走普通武器允许检查。无目标时取合法可见敌人，使用 B04/静止守卫搜索接口。自带一级 T061，应用共享必中，不补缺省暴击倍率。技能阵列无需自行调用另一组 ATTACKED、法术盾、额外眩晕或特效伤害。[攻击时序](attack-timing.md) · [静止守卫选择](ward-summons.md) · [T061](exorcism.md)
- **英雄额外倍率。** Q68 采用主技能提示，武器命中真正原生 `UNIT_TYPE_HERO` 时，进入共有 B03 结算前把本技能这笔武器原始量乘1.25。N534/SAPPER 等地图 BOSS 判定或护甲类不令本项生效。全套原有类别、护甲减伤及其他倍率照常使用。[护甲向量](native-armor-and-xp.md)
- **A077 交接。** 四种模板的实际伤害进入已有 PC1037–1087，按当时 O 的 A077>0 且 A078≤0 每笔计数。计数是在进入伤害管线后的此处，发起攻击未碰到不加。既有初始零伤返回与中途旁路保留，此分支本身无新增攻击标志、正伤害或来源存活门槛。不把持有者 A078 暴击递给普通猴子攻击，也不刷新现有 A078。来源塔缺失只断 O 业务，不把仍存活的猴子归给别塔。按真实 ID 保存独立14名成员、继承量、命令与攻击状态和各自BHwe截止，恢复无重复出生。[A077](skill-jingu-and-tidebringer.md) · [分派](damage-pipeline.md)

## 差异

- 源原式是 (120+S18+S19×继承率)，然后写克隆 S19，图鉴明确按施法者攻击力百分比继承。W02 保留普通武器与实际属性接口。
- 原模块变量保存上一次施法的神杖状态。先持杖的 H024 反而首发14只 b117，随后未持杖 G036 得 b140。Web 按当前施法状态决定副本，保留真实模板及+100距离。源基础间隔 1.3→1 对应约+30%攻击频率，按本技能提示 +25% 修正。
- Q68 补上原技能说明的英雄1.25倍。f68 与猴子专用分派未看到另乘该值；用户已确认按原生英雄身份额外应用。
- 主动 H 的“晕头转向”未给硬控时长，四模板无另发硬控机制。保留攻击命中和伤害，高级文字不重造硬控。
