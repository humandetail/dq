# 挑战怪自身战斗效果

覆盖 N701–704、N706–712、N582–584。出生、路线、容怪与奖励沿[挑战登记](challenge-spawns.md)，既有 N525、N536 的共享入口继续采用各自规格。这些辅助不计图鉴英雄技能数。[机器表](challenge-enemy-effects.json)

## 规则与来源

- **N701–704** 是出生时按入口挂的标记，AHad 的 targets=none、无护甲量。其终端显示与颜色沿各入口，半径字段900不因此制造护甲光环。N705 未见实际可达授予。[出生挂载](../../reference/map-6.25/main.disasm#L138329)
- **N706／N707／N708 不可侵犯。** 原对P11的 ATTACKED 处理，非幻象攻击者在 Skill_Auto 之后、装备攻击段之前，若受击者有这三标任一且攻击者当刻没有 B135，就按708、707、其余的优先顺序，生成受击者所有者的0.5秒 q001/T140，从攻击者当前位置发定向 slow。范围9999；准入 enemies,invulnerable。生效 B135 2秒，分别移速减10/40/60%、攻速减50/80/120个百分点，普通与原生英雄时长相同。两个方向各进共享速度最终夹限。活动标记在时这条入口不刷新或插入第二施放，可驱散/到期后由下次攻击开始重新触发。保留真实 ATTACKED，前摇取消不倒卷，弹道撞击没有第二次扣速。旧原生 AEev 字段空，只作为 ATTACKED 标记，无附加原生闪避。[攻击开始位置](../../reference/map-6.25/main.disasm#L167173) · [实际辅助](../../reference/map-6.25/main.disasm#L125248) · [共享普攻](shared-attack-resolution.md)
- **N709 神灵武士魔抗。** 入场一级。原 B03 在仍带能力时对实时当前生命／最大生命档位回写 N709，已到该档不重复写。严格小于 .12/.21/.31/.41/.51/.61/.71/.81/.91 对应10/9/8/7/6/5/4/3/2级，否则1级。原生 AIsr 法术抗性按对象等级10/20/30/40/50/60/70/80/90/99%，和模板其他原生抗性按 AIsr 共同接口；当下已经完成原生减免的母包不追改，其后新包读取当前等级。非仅法术伤害才更新，实际入口仍要求到达 B03 位置。[调用点](../../reference/map-6.25/main.disasm#L165551) · [严格阈值](../../reference/map-6.25/main.disasm#L122039) · [原生抗性](item-defense-batch-01.md)
- **N710 鱼人碎击。** 原 B03 当前生命比<.5 且技能就绪时下 stomp。AOws 成功提交耗400蓝、20秒CD，以自身位置1000闭圆取敌方，保留原 invulnerable 掩码、魔免及硬控资格；普通 BPSE 3秒，原生英雄1.8秒，按共同原生规则应用相同的抗性路径。DataA缺失且实际提示为旧模板，Web零直接伤害。范围控制不耗定向盾。与 N581 同类几何不同对象，各自触发。[生命判定](../../reference/map-6.25/main.disasm#L165350) · [同类](area-active-batch-01.md)
- **N711。** 原 B03 就绪后发 harvest，无附加生命阈值。成功耗300蓝、20秒CD，召唤一个 b142 或 b143。上一专项已闭合两模板49/51顺序、属性、30秒和父入口继承。[分派](../../reference/map-6.25/main.disasm#L165819) · [N711生成](challenge-spawns.md)
- **N712 佣眷献祭。** 原 B03 就绪且当刻生命比<.7发 harvest。成功耗1000蓝、20秒CD。以施法者位置1500圆，一次计算施法者最大生命×.2，再加各存活P11普通候选当刻生命×.5，排除 mBOS/m999/m998 和 IsShopBoss。可在没有额外候选时自加起始20%；被吸取单位没有对应扣血、减益、删除、伤害事件或玩家击杀。逐匹配登记独立0.5秒连线，再按合计当前生命上限截断一次。连线纯外观，原颜色调用的共享名称不绑定战斗。[分派](../../reference/map-6.25/main.disasm#L165837) · [遍历与治愈](../../reference/map-6.25/main.disasm#L121829)
- **N582／N583／N584 骷髅王重生。** 仅达到原 B03 PC3959、存在任一标、且 D 严格大于当刻生命时先将D设0；相等不进入，本段无 q025 排除。当前实体立刻恢复实时最大生命，原所有者创建1秒 q001/T254 在自身坐标发 thunderclap，然后播视觉，移除三项标记。没有死亡或新实例，也无本次挑战结算。T254 选等级1/1/3，1000敌方闭圆（保留 invulnerable）；B182 攻速减40/40/120个百分点，4秒（包括原生英雄），无移动减速或直接伤害配置。范围控制遵循已定原生准入及叠加，消耗的是同实体一次重生能力而非其他独立保护。[触发](../../reference/map-6.25/main.disasm#L166641) · [回满与移除](../../reference/map-6.25/main.disasm#L113859) · [Htc4 字段](https://raw.githubusercontent.com/actboy168/YDWE/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/AbilityMetaData.slk#L3845)

## 差异

N583 的代码第二次也读取 N584，原二级辅助分支不可达。图鉴没有明定这里的减速档，能力名只标重生 Lv2，不能拿模板“致命一击”或通用雷霆一击说明改值。保留实际1/1/3。N712 名称“献祭”未给单位扣血、死亡或消耗说明，原无这些操作。N706–708 的模板闪避5/10类文案不覆盖实际本技能施法路径。
