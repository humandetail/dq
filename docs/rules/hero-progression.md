# 英雄自然成长、技能点与剥级

基准 `hero-progression-v1` 补齐[经验分摊](experience-sharing.md)和[变强资格](qualification-lifecycle.md)调用的原生接口。机器表为 [hero-progression.json](hero-progression.json)，包含136个有可学技能列表的塔模板及186个可学能力；这不将普通塔、召唤物自动变成原生英雄，也不宣布每个技能的学习回调已核完。

## 已核输入

- 136个模板的力量、敏捷、智力及每级成长从单位表读取；两本图鉴各816个字段已逐格比对，明确数值没有差异，见[图鉴对照](hero-growth-workbook-check.json)。G059的J91/P91与H021的J60/P60均为空，对应SLK也没有AGI/AGIplus。只对这四项按Q24选择0，保留空值来源，不声称图鉴写了0。
- 所有显式属性与成长均为整数。`war3map.w3u`没有覆盖这批成长字段或可学列表；`war3map.w3a`没有覆盖可学上限、首级或等级间隔。
- 地图 `HeroAbilityLevelSkip=3`、`MaxHeroLevel=30`。185个六级技能的学习门槛选为英雄1/4/7/10/13/16级；P000只有一级、要求英雄30级。前185项中164项明确写首级1，其余21项未写，Q24选1，完整名单在机器表。平台地图等级的取消不取消这些英雄等级门槛。
- 已查业务脚本没有直接修改技能点；唯一业务剥级调用位于完整核过的 `main/f291/f18`：无B015而超过20级时剥回20级，然后按新的等级处理W019。学习脚本的实际副作用仍由相应技能模块负责。

[暴雪英雄说明](https://classic.battle.net/war3/basics/heroes.shtml)支持新英雄一点技能、升级获得属性及技能点。官方原版等级10不覆盖本图30。[2025年的原生接口复现报告](https://us.forums.blizzard.com/en/warcraft3/t/unitstripherolevel-unlearns-an-ability-when-it-shouldnt/37269)显示剥级可能在仍有剩余点时撤销能力，且不能据此证明本图版本。下面回退顺序是Q24明确的Web选择，没有把报告当作本图实测。

## Web状态转换（Q24）

1. 新建原生英雄从1级、0经验、1个未分配技能点开始；初始技能状态按当前单位固有/可学列表区分，不自动学满。其他来源显式创建的等级或技能继续按其创建规则处理。
2. 自然属性分量 `natural(L)=base+(L-1)×growth`。等级变化只增加 `natural(new)-natural(old)`，保留脚本永久修改、装备及临时贡献，不从模板覆盖整项最终属性。按X04逐级提交自然成长与一个技能点，然后同步执行原升级事件；内部剥级在W019之前完成。
3. 正常学习要求存活的原生英雄、当前可学槽位、至少一点、未到上限，并满足下一等级的英雄等级和明确科技条件。先原子扣一点并提高实际等级，再执行一次原学习事件。学习门槛只约束本次新增等级；不能因英雄等级后来降低就额外进行第二套自动洗点。
4. 剥级先按X04更新经验/等级，扣除对应自然成长。每实际失去一级回收一点：先扣未分配点，仍不足时按付费学习历史逆序撤销，降低对应逻辑槽位的当前实际等级，下限0。没有历史则不凭空制造学习记录或负技能点。这个回收过程不派发新学习事件，也不冒充升级事件。
5. 直接脚本添加、移除或设置技能等级不生成学习支出、退款或学习回调，不额外写入付费历史。若历史槽位的能力已被脚本移除，撤销该记录只将当前等级裁剪到0，不复活能力。脚本单独授予且不在付费历史中的技能保留。
6. 原生按等级计算的贡献随实际等级更新；任意脚本副作用不能擅自反向执行。例如A084学习时已写入的最大/当前魔法各+500，没有已核反向调用便不自行扣回。完整属性与最大生命/魔法的联动还需对应资源接口，不由自然成长公式推断当前资源比例。
7. 换皮、ANeg替换的逻辑槽位映射由各自事务明确维护，不能仅凭相同技能名猜映射，也不能用新模板直接重置学习历史。存档保存实际等级、技能点、付费历史、自然分量及原有脚本/资源状态；加载不重放建成、升级或学习事件。

## 边界检查

| 状态 | 结果 |
| --- | --- |
| 剩余4点，失去2级 | 剩余2点，已学技能不变 |
| 剩余1点，历史A/B/A，失去3级 | 先扣剩余点，再撤销最后A、B，保留最早A |
| 记录中的A已被移除，另有脚本直接授予B六级 | 撤销A记录不复活A，不动B |
| 英雄实际升到21级但无B015 | 先经过原21级升级入口，再原剥级回20；不将资格失效主动改成降级事件 |
| 当前P000未学、英雄29级 | 不能学习；30级仍须有技能点并走实际学习入口 |

[提取与规格检查工具](../../tools/audit-hero-progression.py)校验136个模板的36,720组自然成长往返算式、186个学习门槛表和4组明确技能点回退结果。前者是算式检查，不声称运行过原生属性接口。两本图鉴数值对照独立保存，没有修改图鉴。
