## 武器命中

- 指定非单位目标，使用已选武器的正常起手射程、可见和控制门槛，并核目标真实在世界中存在、活着、可攻击、无无敌及类型掩码匹配。世界物体按其明确的 `item/tree/debris/wall` 类别匹配，不伪装为 `ground` 单位。物件没有战斗单位阵营和单位躯体，不以物品归属锁推测敌我，不加入默认自动索敌；手动合法攻击与各武器已启用的地点／溅射入口均保留。再投递时重验对象的当前生命、有效性、地上状态及无敌。按原武器的落地／追踪方式处理已发弹；一次攻击至多对同一物体生效一次。
- 炮击 n156–158 的直接掩码允许 tree、item；溅射掩码含 tree、debris、wall，**不含 item**。因此攻击地面可损伤圈内 LTlt，地面物品只可能是明确指定、仍合法且在圈内的主目标。使用原闭合环及 1/.7/.4 份额；指定物件也只吃一份，不额外叠同一炮弹直接包。指物件发炮时仍快照固定点，后来该物件拾走或死亡不抵消已发炮弹的其他合格受害者。
- 绿、红、蓝两套实际形态的直接掩码含 item、debris 而无 tree。红/蓝的溅射掩码含 debris 而无 item 或 tree，当前地图可达非单位受害者只有合法指定的地面物品。绿龙单体照常可手动打地面物品。红/蓝对合法地面物品发弹，物品承受本次全额单次基础份额，其他合格单位照常取该接触点的溅射；若物品失效，红蓝沿原最后坐标产生允许的旁观溅射，绿龙单体不转移目标。该发弹不把地面物品变成单位攻击触发器。
- 对同一落点，合法指定主目标先，其余世界物体与单位共用 B04 稳定创建序候选快照；每成员按武器规格重验合法性和实际距离。不因先前成员死亡就补入刚产生的对象。指定世界物体和只有地点的炮击不执行针对单位的普通命中、闪避、目标暴击、控制、法球或 ATTACKED 回调。武器原伤害与骰子只计算一次，单位主目标的暴击快照照原武器局部规则用于整发范围份额，绝不对每个物体补抽。

## 伤害、无敌与生命周期

编辑器把物品 `iarm` 和可破坏物 `barm` 都归为 `armorType` 材料，字段和单位的 `defenseType` 枚举分开。Wood 仍为受击表现用材质标签，无法从原图映射到单位 `NONE` 或 `FORT` 等战斗防御列。Q24 合同保留父武器交来的原始份额和实际来源／攻击类别供排序与表现。世界物体最终伤害等于这笔正份额乘1，没有护甲状态32、单位类别倍率、魔抗、物理忽甲、模式单位增伤或单位 B03 回调。有效世界物体生命结算为 `max(0, life−damage)`；非正金额不伤害。普通范围技能继续只枚举单位，除非其专项另有明确的物体入口。

- **物品无敌随实例。** 新建无明确保护的地面实例默认可伤。在正常拾取 [Item_Get PC214–224](../../reference/map-6.25/main.disasm#L144877)到达原步骤时，`IsItemInvulnerable==false` 就写 true，先于 `AnyUnitPickUp` 及后续资格拒绝。沿用已经有实际源记录的早退，包含 i421/i422 特例；拒绝若发生在设置之后，回到地面的同一实例仍无敌。普通 DROP 没有清该标记、回复 HP、重新造实例；真正 CreateItem 才初始化新实例生命及默认保护。背包内也永远不可攻击。
- **地面销毁只有物体结果。** 生命降至0即退出选择、拾取、伤害与保存的活物件集合；旧引用失效，仍指同一已销毁实例，不改绑定。不会走单位受伤／死亡、计数、经验、金币、英雄、法术和装备击中链，不触发 PICKUP/USE/DROP/售卖。i421 活件拾取才走已核金元宝奖励；原 Lua 单独有一个 `SetWidgetLife(0)` 后显式发奖励的局部函数，既无父模块调用也无导出，不把它当成“打碎元宝会给金币”。[拾取事务](item-lifecycle.md) · [金元宝来源](item-economy-batch-01.md) · [未达辅助指令](../../reference/map-6.25/main.disasm#L157800)
- **树的死态与原计时。** 从正生命第一次降到0，树立刻不再可攻击或阻挡；只按它自己的占用 ID 释放格子，不删除相邻树和其他障碍。无配置的死亡占用、木材、掉落或补生均不创建。施法登记的树ID数组和目标发芽标记继续到原10秒回调；到期删除存活或死亡的实际旧引用，已经释放的占用不用二次处理。保留死亡模型作为表现时不建立新的目标。
- **并发和续局。** 同刻拾取、攻击到达、刷树、清理与其他事件遵循 B05 入队顺序。每次更改是同步事务；先拾取的物品可令此后到达的攻击无有效物品，先致命的攻击使后续拾取失败。保存实例ID、物体种类/位置/当前HP、活死状态、无敌、树占用ID、原术圈和到期顺序；已发弹保存实际源、武器快照和落点或对象句柄。读档不复活对象、不重放掉落/拾取、不重新给死树加阻挡。

校验 `python3 tools/audit-world-object-damage.py`。复用共享索引对照两本图鉴的唯一物品 ID、原物品物编字段、两套各六个龙形态及三档炮击掩码、原拾取与动态树引用；临界案例验证同刻竞争、准确生命为0、重复移除以及不得把装饰、旁观物品或类型不合的树加入伤害。倍率及生命周期边界是 Q24 Web 选择。
