## 本批共有的 Web 施法与事件边界（Q24）

主动技能接收命令时要求来源存活存在、实际能力启用且等级1、无眩晕/妖术/沉默/暂停等施法锁、冷却0、足够明确费用；目标命令要求有限坐标、合法可选目标及施法范围。来源自己的 Avul/Aloc 不妨碍施法。直接点地命令要求合法坐标/范围；无目标即时技能不要求一定能命中敌人。

普通塔施法前摇用自身单位 `castpt`：本批半人马/熊怪/狂暴洗劫者0.5秒，丛林捕食者0.75秒；攻速不缩放施法前摇。q001 的 `castpt` 未写，本批选择0。未生效前移动、打断、新的不兼容命令、死亡会取消，不扣蓝、不起冷却；生效时重检来源/能力/蓝量/冷却，扣费一次、开始冷却、派发一次原 `AnySkillStart`，再提交 native 效果。如果该事件中的效果杀死或删除来源，取消其后 native payload，已付费不退。已接收的地点瞄准不因原目标后来移动/死亡而自动取消。

零前摇仍经 B05 排在当前同步调用栈之后，不能在 `Issue*Order` 内插入伤害而越过原有归属写入。普通技能生效后的后摇是表现，不再锁住新操作。保存前摇截止时刻、原命令目标/地点、来源稳定 ID、冷却、Buff、弹道/引导进度与随机状态；关闭不推进，1×–4×共用战斗时间。

每次伤害保留实际来源，经 B03 执行减免→可改写地图伤害事件→最终提交；不能把召唤物或 q001 都替换成原塔发包。`NORMAL` 攻击类型是法术攻击类别，和普通武器的 `MELEE` 常量不同。本文主动法术包统一局部选择 `attack=false,ranged=false,ATTACK_TYPE_NORMAL,DAMAGE_TYPE_MAGIC,WHOKNOWS`；原生武器强化仍保留武器攻击类别/标记，不转法术包。

地面/空中看有效目标分类，不能拿 `movetp=fly` 推成空军；图中许多波次怪移动类型 fly、目标分类却是 ground。圆形范围沿用二维中心闭圆与 B04 快照顺序；按成员重查存在/存活/本技能免疫条件，不按客户端帧/渲染顺序。原生隐藏单位不参与效果；普通隐身单位可受非点选范围效果，手动直接目标和副箭则仍要求当前玩家可见。不同技能保留下述不同目标掩码；不把 `area-damage-v1` 允许所有空军的配置整体套过来。

## 黑暗剑雨 N045–047

模板ANst（Stampede），不是蝗虫；DataA20是每秒投射物数量，DataB50是碰撞半径，DataC240/360/800是每箭伤害，DataD100是爆炸半径，DataE伤害延迟未写。Area700、Range800、持续6秒；前两级100蓝/15秒冷却，末级50蓝/12秒冷却；速度700。原学习提示雷蜥蜴60伤害/30秒是默认文案。官方 [Stampede](https://classic.battle.net/war3/neutral/beastmaster.shtml)支持投射物碰撞爆炸、地面/建筑和需要维持引导；没有公开本图随机出生分布/首箭时刻/延迟。

以下均为 **Q24 局部弹道定义**，不推广到其他 ANst：

1. 自动零时目标命令接收时固定其位置为场地圆心；生效时方向从施法者指向该点，重合则用朝向。场地半径700，原施法目标只提供瞄准，之后移动不拖动场地。
2. 生效后在 `t+i×50000μs，i=0..119` 各产生一箭，最多120箭；没有第121箭。引导到6秒结束。停止/移动或新不兼容命令、施法锁、死亡/移除、失去技能，停止未来发箭；同刻按B05已入队顺序，不补发遗漏箭。
3. 每箭从保存的战斗随机流抽一个均匀u∈[0,1)，横向偏移 `y=(2u−1)×700`，半弦 `h=sqrt(700²−y²)`。起点为圆心−方向×h+垂向×y，以700速度沿弦前进至另一端；未撞到目标便消失。未实际产生的箭不抽随机。
4. 动态扫掠半径50，取第一个合格敌方中心接触；同刻B04。首次接触处爆炸一次、箭消失，范围100闭圆。忽略单位collision额外半径；缺失DataE在本组明确取0，立即同步范围结算。
5. 只命中敌方地面/建筑/机械（单位形式的debris按同类；不宣称已支持独立destructible接口），跳过空军/Aloc/无敌/魔免。爆炸按本技能掩码形成B04初始快照，每个有效成员一笔240/360/800，逐包完整B03；同一单位可中多箭，没有整次共享伤害上限、减速/眩晕或N535消耗。
