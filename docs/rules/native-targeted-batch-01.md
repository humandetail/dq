# 普通目标伤害第 1 批

本批核十个能力。机器表记录每项取证坐标、所选数值和验证结果。图鉴 H/I 的明文数值高于对象、提示和 J 列补充字段。引擎时间、免疫与事件顺序使用本页限定的 Q24 Web 选择。原客户端未实测。

## 共用入口

按当前有效技能等级 1–6，复用[施法提交](creep-skill-family-001-053.md#本批共有的-web-施法与事件边界q24)和[自动入口](autocast.md)。手动与自动使用同一合法发令接口，预检施法者、等级、控制、范围、魔法和冷却。前摇可取消，生效重检后扣蓝并起 CD，发一次 `AnySkillStart`。保留其装备分派、初始化、专用分支及原分支返回位置。A019/A029 走通用尾部。临时单位走 `IsTemp` 早退路径。普通地空定向 `enemies` 本批限可见敌对单位，排除建筑、隐藏、Aloc、无敌、魔免，允许机械受伤。显式有机/中立掩码优先，有机掩码排除建筑、机械和守卫，接受敌对或非同盟中立。一次定向原生载荷生效时检查共用 N535，命中失败无退款或改选。脚本派发的马甲各自检盾，纯脚本范围包无独立盾检查。定向限定包装如 A020/A073 仅由实际马甲检查 N535。

实际法术伤害走 `false,false,NORMAL/MAGIC/WHOKNOWS` 和 [B03](web-baseline.md)。范围包复用 [area-damage-v1](native-area-damage.md)。实体弹按[普通塔投石](creep-skill-family-next.md#单体投石-n079081-与群体投石-n082085)接入，定向合法性于发射和撞击复查，撞击免疫或目标失效即终止，离开原射程仍追踪。BPSE 在伤害前施加，同槽取较晚截止，普通驱散不清，显式移除、死亡、删除或到期清除。原生 HERO/Arsk 使用明示英雄时长，控制免疫仅免控制。源死且仍存在时已发弹继续，移除取消。零前摇的定向马甲在原调用内提交并发弹，无时间间隔的波及和链跳沿已有 B03/B04，正到期沿 B05。
