# 暗影萨满：群蛇守卫 A094／A095

图鉴 `塔技能!H345:I345` 对应 H029 的 A094。A095 仅由神杖把同一学习槽换型，没有独立图鉴行。当前配置只有 H029 带 A094 学习槽，没有另一个皮肤或学习别名。直接复用 A096/A114 的 [ANeg 换槽](scepter-lifecycle.md)，沿用等级、付费和冷却。换槽改变下一次合法施法，已经生成的守卫保留其单位类型、攻击槽、主人槽和到期。 [A094/A095 玩家提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L1395) · [自动入口](autocast.md)

## 施法、位置与到期

两型均为 AOwd 地点指令 `ward`，射程800，CD18，耗蓝100/115/130/145/160/175；实际 H029 前摇0.3、施法后摇0.1。手动接收合法有限地图坐标，包括迷雾和空地。沿已定施法接口，在前摇结束复核实际槽、等级、位置范围、冷却和法力；成功扣蓝/起 CD 并发一次通用 SPELL_EFFECT，然后提交召唤。通用分派保留原装备、尾部和其他回调。若成功生效事件使源删除或死亡，则取消尚未建立的召唤，不退资源。自动范围700、按 hasMon 找活 Player(11) 并快照地点，在 B05 零秒计时下走普通地点指令；施法不绑定其后移动的怪物。 [施法准入](native-targeted-batch-01.md) · [原自动分支](../../reference/map-6.25/main.disasm#L175533)

每次固定创建8支，A094 持续12秒、A095 15秒。原字段 `Area=300`，AOwd 原生精确布阵与挤位没有匹配客户端证据。Q24 选择以瞄准点为中心、半径300依东→逆时针每45°一个的阵位，偏离只有越界时发生：该阵位改取距其理想位置最近、中心300闭圆内的地图内格中心，等距用既有行优先格序，并避免重复用本次其他阵位。优先保留其余合法理想阵位。守卫无需施工地、人口或可移动路径；对象没有碰撞半径与路径贴图，局部选择占位半径0、无额外动态阻挡，不挤开单位。此选择只用于群蛇守卫，地图边界沿[既有空间接口](pathing-and-placement.md)。 [官方守卫能力](https://classic.battle.net/war3/ORC/units/shadowhunter.shtml)

按阵位顺序建真实单位、立即登记该支 SUMMON，实际所有者取本次施法者，8支共用本组绝对到期。没有总槽覆盖或数量替换；重叠编队各自存活到其期限，装备丢失、换型、源死亡、源删除不回收旧组。每支到期只结束自己的生命，停止索敌和未提交攻击，派一次既有单位死亡事件。自然到期的原句柄供已发箭按普通死亡语义结算，逻辑退役在最后一枚引用它的已发箭结算后完成；外部显式删除取消尚未命中的箭，旧到期令牌随后无效。普通驱散不会清除群组寿命；原 BOwd 文本允许参与驱散伤害类检查，但守卫实际挂 Avul，仍由共享无敌规则拦损伤。无 N535 点选拦截，无主动召回。恢复存档保留阵位、所属组、各句柄、独立绝对到期、武器状态、已发箭与入队次序。 [SUMMON 登记](../../reference/map-6.25/main.disasm#L180081) · [BOwd](../../reference/map-6.25/units_commonabilitystrings.txt#L1785) · [官方驱散](https://classic.battle.net/war3/basics/spellbasics.shtml)

12个模板都是 HP75、无敌 Avul、地面 SAPPER、无移动速度、穿刺远程 missile、只有武器1有效。普通移动不可用。原召唤 handler 在非深渊调用 `EXSetUnitMoveType(1)`，深渊保留模板运动类型，模板仍无移动速度。正常射程和索敌均800，前/后摇0.3/0.7，追踪弹900，原生目标掩码 `ground,structure,debris,air,item,ward`。敌方地空/建筑/守卫按普通单位武器准入；合法可攻击物件走武器物件分支，不把它们当副箭单位。自动保留有效的当前目标，无目标则在800闭圆按 B04 取第一合法可见敌人。使用 [攻击计时](attack-timing.md)、[武器字段](weapon-field-source-notes.md)和完整管线，前摇视实际有效攻速缩放；攻击开始仅向原注册入口派发一次。模板值 `dmgplus=图鉴值` 另加固定1d1，Web 本体保持图鉴显示额，不再添1。后加的继承、光环与事件处理仍分别应用。 [守卫单位表](../../reference/map-6.25/units_unitweapons.json) · [追踪及弹速增量](../../reference/map-6.25/war3map.w3u.json) · [官方普通守卫角色](https://classic.battle.net/war3/orc/unitstats.shtml)

原 `UnitBeComeEventHandler` 将实际召唤者解析成 O；正常 H029 是同一原生英雄。守卫不会命中 BIil、A209、b107–b110 或熊灵/伙伴特例。原先跑召唤装备辅助，随后送入普通属性继承分支。每支创建时读原英雄当时有效 STR+AGI+INT，向本支 S18 写一次继承。Q24 沿 W01 的 setter 精度；无提升装备乘0.4，只有 i240 提升系数时按图鉴乘0.5，任一高阶红/绿/蓝（i243/i245/i247/i249/i250/i251/i252/i253/i254）时0.6。同一档/多档不重复增加这个系数；i242 只有攻速，不加继承系数。宿主的原始武器、装备攻击、当前资源和技能槽没有整体复制。守卫自己可受合法友军 Buff/光环，已写的继承不会随主人加点或装备变更重算。 [召唤者解析与处理](../../reference/map-6.25/main.disasm#L173119) · [S18/归属写入](../../reference/map-6.25/main.disasm#L173499)

守卫是实际攻击源 S；出生时将主人当时 `GetUnitUserData(O)` 写入自身，不因此登记成普通塔。主伤害和击杀归属沿原 SAPPER 入口每次使用当前 `Tower_ALL[S.userData]`，不存在则保留 nil，不改为假想的原英雄句柄。图鉴本体40与 S18 继承是不同层次；SAPPER 仍用伤害管线的独立三围乘数，已核装备及模式响应按原 S/O 规则执行。 [伤害源与归属](damage-pipeline.md) · [击杀归属](dragon-breath-and-blood.md#击杀与状态保留)

A095 的每支守卫另持一级 N132（Aroc）。三个明示提示均写同时攻击四个目标，按既有 Aroc 接口选主箭+最多3支副箭，原 DataC=2 留证。每支守卫自己的副箭锁2秒，攻速不缩放；就绪的主攻击提交时取700闭圆内其他合法敌人，按 B04 取3个，少则少发；零候选也起锁。各箭共享该轮武器原始金额，副箭总预算9,999,999、末箭可部分，不复制主箭专属效果。与主箭同为900追踪；各自独立命中、B03 及召唤物装备回调，副箭无额外 ATTACKED、不再触发分裂、不消耗盾或独立蓝。 [N132 提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L14515) · [既有 Aroc](hero-attack-extensions.md)

## 召唤装备在本组的交接

`i240_254_Action` 先按三套装备档位赋 T085（i243/i249/i250）、T086（i245/i251/i252）、T087（i247/i253/i254），同组优先最高。按 Q64 逐件叠加实际持有的攻速贡献，含同色多档及同名实际实例。每个高阶实例 +0.5，i240 +0.3，i242 +0.2，通过既有原始 R 和上限规则。原脚本每色只给0.4。原召唤装备模板的取放更新只按实际已经证实的路径执行；本组普通守卫不属于相关熊灵/伙伴，之后主人换装不改守卫已赋档位。 [出生装备](../../reference/map-6.25/main.disasm#L125445) · [攻击计时](attack-timing.md) · [提尔与取放边界](item-summon-contracts-batch-01.md)

命中时，原前置装备后，若 O/S 存在、S 为 SUMMONED、非临时且无 Aloc、attack≠0，进入 `i240_254_Damage`。远程守卫带 T085 时无红契近战分裂，也无 T201 必中，原其他装备仍能看到已赋 T085。Q55 确认绿契按归属者实时有效敏捷×0.6/0.8/1.0，远程使用完整系数；无尽沿原×2，实际守卫发 `false,false,CHAOS/DIVINE`。随后蓝契从整数1–100抽一次，≤15成功；金额取守卫实时 `S18+S19` ×6/8/10，远程使用完整系数，主线仍×0.5，目标中心半径400发同步 `false,false,NORMAL/MAGIC`。先发绿再处理蓝，保留原分支回调和 B03，主箭与副箭均按实际条件执行契约。原远程绿契半伤、蓝契阈值<7及半伤保留为差异证据，蓝契源常规阈值<15。此节闭合这些装备在蛇棒上的实际分支。 [装备命中函数](../../reference/map-6.25/main.disasm#L125917) · [入口](../../reference/map-6.25/main.disasm#L162636) · [范围包](native-area-damage.md)
