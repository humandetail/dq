# 高射火炮 A196

基准 **`flak-cannon-v1`** 闭合 H051 矮人直升机与 G080 矮人轰炸机的开启、攻击预扣、发射、晚弹和装备交接。[机器表](flak-cannon.json)保留双图鉴、对象和探针。

### 开启、预扣和结束

- 自用 `berserk` 沿 [Absk 瞬时事务](self-buff-batch-01.md)一次扣蓝、开 A196 冷却并装 B170。EFFECT 在共用装备前段之后调用 A196_Action，返回当前分派。每个逻辑塔只有一个当前火炮状态，重新成功施法取消旧到期，给当前级完整额度和新 3 秒期限。先前已发火炮各自继续。B170 是指示 Buff，T217 是独立授予；普通正面驱散 B170 不撤除 T217，显式撤销 T217 则结束资格。死亡只移除普通指示 Buff，T217 可保留到期限，已发弹依撞击时的合法尸体来源结算。逻辑实体删除清自身状态和未落地弹。这里的刷新是源明确设计的单个活动授予。
- **原始次序。** ATTACKED 的主触发仅登记 Player(11) 目标，幻象进专路后返回。扩展分支在普通攻击起手、Skill_Auto 之前，用当时 T217 预扣计数。降到0立刻取消 T217/B170 再继续自动派发。一次起手之后取消前摇，源没有返还入口。A196 的自动分支第100位照常使用 B012、真实就绪和即时 `berserk`。
- **Web 占额。** 从已有 T217 发起普通主攻击时先为其攻击 ID 占一次，再走原自动及后续起手。取消、失效、落空不返还已占次数。若这次攻击的起手自动新施了 A196，当前攻击也占新状态的首次额度。若旧状态先被预扣，它已由成功重施整体覆盖；本次只有最新占额可驱动发弹。Q24 对前摇内手动获得火炮采用相同的提交资格，若实际提交时已有新 T217，可为新状态补占一次；没有提交就不补占。攻击开始通知与提交各只执行一次。非 P11 的一般武器攻击也遵图鉴额度，但不会据此新造地图 ATTACKED/Skill_Auto 回调。幻象不占额、不发本能力副弹。
- **末次。** 余量变0只保留该次已占额攻击的提交资格。若该次实际提交且当前状态代号相符、T217有效，仍发最后一轮；到期/显式移除先发生则回落为普通攻击。为保留原预扣门限和命中时的实时 T217 窗口，最后一次占额之后仍保持脚本标记，到下一个可计数的普通攻击开始或最初3秒到期即清除，谁先执行谁结束。它不再给新攻击提供火炮额度。若下一个起手随即自动重开，已发弹照撞击时当前状态读取。到期、攻击开始/提交和撞击同刻沿 B05。
- 清理以逻辑塔和本次活动代号定位，撤本组 T217/B170 和自己的计时器。已覆盖或终结的旧回调不处理后来授予。源销毁参数是全局 `timer`，与自己的登记 timer 不同。Web 收回本活动实际句柄，保留资料中的原异常。

### 发弹和命中

1. 合法普通攻击提交取当前武器。H051/G080 第一武器为英雄攻击，C/P/B=1.2/.55/.85，主范围1000、基础35+2d4；主弹两形态均3000速度追踪，按普通武器、属性、原生暴击和主目标专属固定奖励结算。一次受益攻击在提交时从攻击者**当前二维中心**取1000闭圆，按 B04 选全部其它合法可见敌方战场单位，主目标不重复。复用既有武器合法集合，允许武器能攻击的地面、空中、建筑、机械、魔免和守卫，排除 Aloc、隐藏、无敌、虚无、失效、友军、未完工等。该半径不用于回头取消已发弹或重选。无其它候选仍占一次额度。[攻击计时](attack-timing.md) · [原武器副目标接口](hero-attack-extensions.md)
2. 图鉴“每次攻击”“所有敌人”不对 T217 再加原 2 秒锁或 100 目标截断。保留 T217 明示 **1 点原始物理伤害/副弹**、总预算9,999,999；主弹不占副弹预算，也不是1点。副弹用 T217 的 RocketMissile、1600速度、追踪，弧度.08。主弹先入队，同刻副弹按 B04。已发主弹落空不取消副弹，每个投射物独立检查目标有效性及普通命中。Q24 选择符合资格的本轮优先使用火炮，屏蔽同轮其它原生法球效果。共用普通武器贡献和不属原生法球的装备脚本仍按各自规则。
3. 每枚有效副弹以实际塔来源、`attack=true,ranged=true,HERO,NORMAL,WHOKNOWS` 独立进 B03。它不复制主目标专属固定伤害、原生暴击或必中，无独立 ATTACKED、施法、蓝耗和 N535。**1 点只是进入管线前的副弹基数。** 先走原生护甲/类别及原主伤害分派，B03 原 Before/After 和其他命中响应可读改各弹自己的事件金额或生成独立子包。原金额可变，即使副弹只有1点也会触发符合门槛的装备；主武器金额由其自己的攻击公式决定。
4. PC158–179 动态查**实际** S 当前 T217>0、非幻象、attack!=0，符合才另调 `Item_Attack_Special(S,T)`；没有“该弹曾为火炮”的快照判定。此时 i132 可按自身概率发 460 范围的独立物理居合；i302 群星之怒在非近战分支读取有效敏捷和攻击距离，发以受击者为中心的独立神圣范围包；i316 斩敌巨斧远程路径按本件力量与基础敏捷差及范围内目标数量发独立物理范围包。两个子包以各装备当前属性及阵地条件为输入，数值覆盖随各装备契约，且共享 helper `IsKillCdSkill` 的 T217/B210 判定影响自身限流。猎取、伤害范围、概率和门闩不由副弹1点推算。整个管线后续照常执行。已发副弹晚到而失 T217，仍发普通伤害，跳过该专路；未标记火炮的普通弹若落地时 S 当前有 T217，也可走这条原路径。首次 ATTACKED 尾对原主目标的 `Item_Attack_Action` 自己仍可调用一遍 Special，没有跨两入口的通用去重。[妖刀居合](item-muramasa-takemitsu.md) · [群星之怒原包](../../reference/map-6.25/main.disasm#L133578) · [斩敌巨斧原包](../../reference/map-6.25/main.disasm#L134015) · [装备分派](damage-pipeline.md)
5. 存档保留逻辑塔当前状态代号、T217/B170、剩余额度、等待清除的尾窗口、到期与 B05 序号，另存进行中攻击 ID 的占额和主副在途弹实际来源、目标、飞行及伤害输入快照。读档恢复队列和记录，不重跑 ATTACKED、预扣、蓝耗、随机或发弹。

## 差异

原 B170 Absk 一级时长12秒，实际 f141 在3秒清除。Web 按图鉴与脚本使用3秒。图鉴1000、“每次”和“所有”覆盖 T217 对象的1300、2秒内置CD和原100目标。源初始计数为表定值+1，手动初次后的 N 个起手仍带 T217，下一起手清标记。自动在预扣之后才挂 T217，源可能让该攻击额外受益。Web 保留原预扣时点，采用图鉴 N 次上限，使自动开火的本次也占一个额度。前摇内新挂资格、末次发弹和法球优先是局部 Q24 选择。

原清除函数调用 `DestroyTimer(_G.timer)`。当前发现的三个写入点各分配未启动的全局 timer，再单独启动实际回调。原 A196 自身计时器先失登记映射，之后孤立回调查到−1；Web 终结自己拥有的期限，规避无效计时。
