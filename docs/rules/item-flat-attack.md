# 装备固定攻击

`item-flat-attack-v1` 确定《装备与道具》中 **31 件有 AIat 挂载的装备与组件**对普通武器固定攻击通道 F 的贡献。原地图字段、图鉴数值及 Q24 的 Web 生命周期规则各自有据。机器表记录逐项证据和验收结果。[item-flat-attack.json](item-flat-attack.json)

逐格核对下载版《刀圈TD 6.25 图鉴.xlsx》和仓库《图鉴.xlsx》的《装备与道具》A–H，共 247 行（含标题等 4 行），243 条物品记录相同。31 件装备的挂载列表含 13 种 AIat alias、43 次出现。另 20 条含固定攻击描述的行均为制作书，描述的是成品，制作书实例在本模块的 F 为 0。机器表逐行保留 H 列原文与制作书自己的挂载字段。

## 脚本入口与 Web 规则

完整扫描 `main.disasm` 常量及 `war3map.j`，13 个 alias 的原文和大小端整数表示均无匹配。逐段核对 `GetId` 的四字节大端转换和 `StringTypeID` 的逆转换，并查短 ID 前缀、格式化与字段写入口。唯一 `EXSetAbilityDataReal` 所在函数改临时单位 q056 的 T286。唯一 `EXSetItemDataString` 所在函数改 i546 的图标、说明与名称。这个静态边界仍允许外部二进制或不透明运行期输入改变对象行为。物品类型通过原事件上下文动态读出，拾取脚本继续执行归属、等级、资格、合成与互斥判定。[GetId](../../reference/map-6.25/main.disasm#L50362) · [StringTypeID](../../reference/map-6.25/main.disasm#L52891) · [T286 写入](../../reference/map-6.25/main.disasm#L108313) · [i546 写入](../../reference/map-6.25/main.disasm#L152661) · [Item_Get](../../reference/map-6.25/main.disasm#L144536)

1. **每个实际挂载且合格的实例贡献一份表值。** 多件可共存的实例以实例身份累加，包含同类型物品及共享 alias 的不同类型。重复 alias 完整保存在源数据中，单件贡献直接取表值。工人、能量圈等仅存放时是否具备装备效果由载体能力规则界定，继承也沿各自机制。
2. **原拾取限制继续执行。** 按 L01，成功入包时先更新该载体的挂载贡献再进入 PICKUP；脚本拒绝并移出时先撤销该实例贡献再进入 DROP。圣剑和遗物之刃的原互斥组继续保留，嵌套事件能看到当时已经提交的贡献。满包失败没有挂载。换槽只改位置，重新加载从已有挂载实例重建这一份 F，延续原保存的脚本偏移及其他来源。 [物品生命周期 L01–L09](item-lifecycle.md) · [互斥表](../../reference/map-6.25/main.disasm#L142604) · [互斥分支](../../reference/map-6.25/main.disasm#L145211)
3. **接到武器接口的固定 F。** 该批贡献与其他有效固定来源相加，进入 W01 的 S19 整数视图及普通武器包 `R=(X+D)*(1+P)+F+J19`。百分比 P 只乘 `X+D`，F 不改变 S18 或骰子。持有状态变化保留当前 J19，仍按 W02 处理之后发生的脚本绝对写入。暴击、伤害、溅射等沿已定执行入口。 [武器接口 W01–W03](weapon-field-source-notes.md) · [伤害分派](item-damage-dispatch.md)

固定 F 的实例叠加是 Q24 在这 31 项内的选择。辉耀的唯一灼烧、狂战斧分裂、装备附带的三围与攻速、其他 AIat 单位能力和原版物品、其他 AIab 变体、熊灵／幻象、死亡背包与存放载体的装备资格均由各自规则负责。

## 验收

[验证脚本](../../tools/audit-item-flat-attack.py)以两份工作簿和来源快照重建机器表，`--check` 比较既有产物，`--write` 重建。用带 openpyxl 的 Python 执行。下载版默认位置为 `~/Downloads/刀圈TD 6.25 图鉴.xlsx`，可用 `--original-workbook` 指定副本。

用既有物品生命周期解释器执行 `Item_Get` / `Item_Drop` 字节码，挂载使用 L01 测试桩，攻击数值使用 W01/W02 参考接口。12 个探针涵盖单件 60 覆盖、两个阔剑实例累计、50% 光环只乘武器基数、S19 残差保留、换槽、满包、存档重建及嵌套合成。资格拒绝观测到圣剑 800→0，遗物之刃重复拒绝时为 180→360→180，合成结束仅 i136 贡献 85。原客户端叠加与事件时序仍待匹配环境实测。
