# 石化凝视、淘汰之刃和无影拳的接口收口

本页补齐 A007、A057、A180 旧审计明确留下的接口，不重做已验证的数值、分支或共享系统。来源规则分别见[石化凝视](skill-stone-gaze.md)、[淘汰之刃](skill-culling-blade.md)、[无影拳原模块](skill-focus-fire.md#5-a180无影拳用于排除错配的独立证据)。缺少匹配原客户端的部分沿 Q24 明确为 Web 选择，三项规则可实现；原客户端未实测。

## A007：直接暂停和控制并存

保留原脚本单一 `PauseUnit` 布尔，后一次写入覆盖前一次，不改成按技能引用计数。`IsUnitPaused` 只读这个布尔；普通眩晕、束缚和沉默各有自己的控制状态，不因读取或清除 PauseUnit 而互相消失。有效暂停禁止新移动、攻击和施法，取消未提交的普通攻击/施法前摇；已经发射的载荷、技能脚本计时器、Buff 到期和冷却按 B05 战斗时间继续。解除暂停不重放被取消动作，也不越过仍有效的眩晕等控制。[普通攻击](shared-attack-resolution.md) · [原生施法](focus-fire-native.md) · [计时](web-baseline.md)

因此 N536、福利小鸡或 N540 着地写 false，可以提前解除 A007 的暂停；它们没有同时写颜色、动画缩放或清 A007 表时，这些状态仍保留。A007 到期写 false 也会解除其他代码此前设置的直接暂停，但不会清除独立眩晕。原已核的“外部解除→再次石化→旧 timer 先到期”的行为保持：旧 timer 可在新记录到期之前解暂停。这是原脚本明确的共享状态，不适用 Q54 单次施法计数隔离。

暂停、颜色和动画缩放属于仍存在的具体实体；死亡不自动撤销原脚本表和 timer。同实体复活继续沿原表读写。移除后句柄失效，相关 setter 无效果、`IsUnitPaused` 返回 false，不把旧句柄映射到新实体；旧 timer 仍执行原清槽步骤。动画缩放0只冻结表现，不冻结模拟时间。A007 本体 AUav 没有明确的吸血或光环幅度，作为原伤害入口标记，不额外添加吸血。

T302 的石化双倍仍检查原 A007 表成员，不改成检查暂停布尔。完整蛇链及 Q79 偷蓝已由[吞噬借技](doom-devour-borrowed-skills.md)闭合。

## A057：提交、两个正面状态与延迟返还

四种英雄模板的 `castpt=.3,castbsw=.1`；A057 是单体 ANcl，射程600，蓝/CD按原图鉴六档。命令沿共同定向前摇/提交复验：来源存在存活、技能可用、无施法锁、资源和CD满足，目标是可见、存活、可选、非无敌的敌方地空单位，排除隐藏、Aloc和建筑。没有脚本明确魔免排除，局部 Q24 允许魔免目标；实际物理/神圣包仍各走 B03。壳没有原生伤害和 N535 载荷，不另耗一层法术盾。`targs=_` 不作为任意友军也能斩杀的授权。自动550选靶只是发令入口，不能放宽600提交射程。[源对象与原分支](skill-culling-blade.md) · [共享施法](creep-skill-family-001-053.md#本批共有的-web-施法与事件边界q24)

成功提交扣费、启动CD并派一次原 EFFECT；先行装备分派及原阈值读取顺序不变。ANcl DataA=.8 是提交后的跟随段，不是额外伤害、额外前摇或阻止独立回调执行的锁；有效替代命令可终止跟随，不撤销已经发出的效果。技能冷却随战斗时间减少；.1秒返还回调继续取当时剩余值乘.5。

T410/T220 共用已定的临时目标施法接口：q001 本次零前后摇、缺省耗蓝选0，目标命令在原同步调用中尝试；来源存活且能施法，目标存活、友好、允许无敌、拒绝魔免，分别检查600/500射程。成功先安装状态，再派临时单位 EFFECT（走 IsTemp 早退），该 dummy CD1秒；失败不回滚主技能效果或返还冷却。两者均无额外自动施法。

原回调保存的是 timer 所在槽，并在执行时查 `Tower_ALL[槽]`，不是保存旧施法者再强行绑定。新实体若确被原表写入该槽，就使用当时实体及其实际 A057 句柄；失效能力读剩余0、写无效果。表为nil时跳过返还与T220，仍清 timer。死亡但未移除的实体保有能力属性，返还仍可写；T220目标命令则因死亡被拒。换皮/变身保持同实体身份，不重新建累计。[回调 L68932](../../reference/map-6.25/main.disasm#L68932) · [同实体规则](skin-and-transformation.md)

## A180：原攻击请求、迁移与视觉能力

H046/G065 均 `castpt=.01,castbsw=.1`。ANcl 点选射程1200，半径250/300/350/400/450/500，蓝20/30/40/50/70/90，CD8/7/6/5/4/3。前摇和提交按共享点选规则；提交后跟随.3秒不阻止脚本已安排的.01秒首步及.25秒周期，后续接受的attack可结束跟随。原已在 `A180_Dur` 的生效函数返回不撤销此前提交费用；正常自动入口仍按原门槛排除已在状态者。

原目标表在生效时按 B04 快照 Player(11)、生命>0的区域成员，后续逐拍读当初的目标表。每拍和结束时都重新读当初 UserData 槽对应的 `Tower_ALL[i]`。载体与该拍目标均为非nil时，在目标X/Y上各抽一次10–50的正偏移，执行 `SetUnitPositionLoc`、朝向和普通attack请求，再推进索引。迁移先试请求点，失败则按250范围内格中心距离及稳定索引找可容纳位置，仍失败留原处。源指定迁移可以在普通MOVE被禁时执行，仍受世界边界约束。结束回当初保存坐标也走同一接口，入区比较旧、新位置。[逐拍取槽 L96234](../../reference/map-6.25/main.disasm#L96234) · [位置适配](pathing-and-placement.md#w018移塔与核心刷怪创建)

attack请求沿普通目标、控制、距离、前摇和冷却条件提交。成功接受新目标可取消尚未提交的旧前摇，拒绝请求则保留已有攻击。死去或移除的目标继续占该拍，移除的非nil句柄坐标读0，仍消费两次位置随机，攻击准入拒绝。如果塔槽仍保存已移除的旧句柄，setter及命令无效，原周期照常推进。如果槽为nil，则该拍只推进索引，结束仍销毁timer、移除dummy并清表。如果真实登记把槽改写为其他实体，下一拍及结束写入当时载体，仍用原槽保存的旧目标表、原位置、C差额和转身速率。正常登记与回收沿既有规则，旧无效句柄继续失效。死亡、同实体复活和控制恢复按当前状态判定，无额外补发。手动命令不销毁独立遍历timer，下一拍仍可能改变命令。[命中与投射](shared-attack-resolution.md) · [塔生命周期](tower-lifecycle.md)

保留C直接写.3、R加5、结束加回保存C差额并R减5的原顺序。遍历末项后的下一次推进清状态。B03实时判断当时归属 O 是否为 `A180_Dur` 的值，槽里新载体不会自动继承该表中的原施法者身份。无尽 Game_Mode=1 时伤害×2.5，主线、肉山和深渊等其他模式×2.7。在途弹抵达时状态已清就没有该分支增伤，技能包符合原分派门槛时也可获得加成。[伤害分派 L163812](../../reference/map-6.25/main.disasm#L163812) · [模式编号](waves-and-modes.md)

T012/T020 的专属名称都明确为“马甲-无敌斩武器视觉效果”，DataA伤害、DataB减甲和Buff均未配置，也无其他脚本读它们。Web只提供原武器附着表现，不添加腐蚀减甲、额外伤害、眩晕、无敌或必中。结束时原函数按**结束当时**的TxShow/类型选择移除T012或T020，并非保存创建时选择；潜在残留仅为表现，不新增战斗收益。[T012 L19651](../../reference/map-6.25/units_campaignabilitystrings.txt#L19651) · [T020 L19688](../../reference/map-6.25/units_campaignabilitystrings.txt#L19688) · [结束选择 L96312](../../reference/map-6.25/main.disasm#L96312)

## 保存与验证

三项保存真实实体/生命代、脚本槽和timer身份、全部未到期回调及B05入队序号、直接暂停布尔和独立控制、Buff版本、无影拳目标表/当前索引/原位置/C差额/转向值、PRNG。移除不把旧引用重新绑定到新实体；从原槽动态取载体的脚本仍按原槽执行，不能混为一种身份模型。加载不重新施法、返还或补攻击。

复用现有 A007 的55项和 A057 的23项来源/边界向量。专项工具核对对象、视觉提示与清理引用，并运行9个原指令边界探针，覆盖 A057 当前槽与空槽、A180 的攻击请求和末项恢复、A180 换槽与空槽及三个模式的 B03 倍率。运行 `python3 tools/audit-legacy-control-and-cast-closure.py --check`。原指令探针使用显式原生替身，原客户端未实测。
