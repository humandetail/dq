# 工人天赋的选择、升级和实际效果

两本《玩法总览》都要求开局选择工人天赋（源B5、仓库B6）。这八项没有独立的《塔技能》ID，名称、数值和业务细节来自工人对象、各自专属提示与执行。W001、W002–W009 是选择辅助，随八个天赋记录。 [机器记录](worker-talents.json) · [经济规则](economy-and-progression.md)

## 选择、升级和撤回

给每个实际 HUMAN/PLAYING 玩家创建 w001 时授予常驻 W001 选择书。Aspb 含 W002–W009：按尾号分别永久授予初始一级 W012–W019。通过自己的实际工人及仍有效的选择书接受其中一个，实际 SPELL_EFFECT 先移除 W001，再加技能并保持永久挂载（跨同实体皮肤）。原 WAbility_initAbility 只对实际 IsWorker 命中；W001 已撤回后没有合法选择子命令，也不开放重选。子按钮各是1秒CD的无目标选择入口，蓝耗缺失为0。书不是自动选随机天赋。 [起始工人与书](../../reference/map-6.25/main.disasm#L199817) · [选择分派](../../reference/map-6.25/main.disasm#L188396)

第10、20、30、40波进入该波生成阶段后、首个周期生成前，每个已登记工人实际已持者各+1，共五档。没有50波补升，也没有后选追补之前波次已过的档。源升级单写同一能力的等级，已发生的当前CD不清零；下一次提交使用新基础CD。无尽开关实际提交及深渊入场准备的清理各调用 WAbility_Remove，移掉工人的 W001 与 W012–W019；S001/S031随同一原入口去除。战斗中不补发被撤掉的未提交技能。已发生的抽卡、合成、金币、位移、永久三围写入保持。 [波次入口](../../reference/map-6.25/main.disasm#L184127) · [升档](../../reference/map-6.25/main.disasm#L190409) · [无尽撤回](../../reference/map-6.25/main.disasm#L186171) · [深渊撤回](../../reference/map-6.25/main.disasm#L157390)

W012/W014/W016 是零蓝无目标 animatedead。W018 同名命令但为对象定向；只有该工人持有的实际天赋接此正常指令，不因同一命令名串到其他天赋。实际 w001 的施法前摇0.3、后摇0.51秒，工人同实体皮肤以实际模板和既定交接为准。提交前受控或资格失效则按共享法术规则取消。W012/W016 有提交后的失败补偿，详见各项。

## 八个天赋

- **W012 卡片置换。** 冷却230/190/150/110/70秒。提交时读取工人实际物品栏第1格（内部0）。c001–c013变强资格卡、SSR、为空、不是同品质合法普通卡池成员则提示失败；不挪其它槽、不耗材料、不抽卡，0.1秒后清本次 W012 剩余CD，强制同工人再次失败替换旧撤回计时。无效实体／能力撤销后只清定时器。合格等级11/12/13分别对应 N i701–717、R i601–609、SR i551–597。环形均匀抽1到池大小−1作偏移，所有其它同品质卡各一次，本张排除。成功先移除整个旧实例，再在工人当前点创建独立新卡并尝试交付，同既有 D01 失败留地。原只用物品Level先行筛选；i902/i903等非卡13级道具能越过此条件但在卡池查找无匹配，会形成无效替换ID。Web按提示仅适用实际卡，先确认卡池成员再删旧件。 [原随机环](../../reference/map-6.25/main.disasm#L188747) · [原提交、失配与回退](../../reference/map-6.25/main.disasm#L188815) · [D01交付](summon-and-delivery.md)
- **W013 英雄无敌。** 被动，提高己方英雄塔在 B03 原阶段的当前伤害×1.04/1.08/1.12/1.16/1.20。使用实际攻击归属 O，O 须存在且为原生 HERO，读其玩家实际工人当前 W013 档。非英雄来源的归属若确实为英雄塔同样可得；归属缺失或非原生英雄不触发。原函数在该阶段不再按物理/法术/神圣、是否普攻另筛；伤害已经早退就不到这里。Aamk无其它三围字段，技能名没有免伤或无敌效果。 [专属提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L23553) · [B03归属调用](../../reference/map-6.25/main.disasm#L164678) · [原倍率](../../reference/map-6.25/main.disasm#L189053)
- **W014 宝箱许愿。** 每档CD250秒。一次有效施放先交付箱、再交付钥匙，各用同档独立抽样。一级固定i401与i411，不抽随机；二、三、四级各独立均匀从品级1…2、1…3、1…4抽；五级各从2…4抽，可不同级。箱 i401–404、钥 i411–414。每步在工人实际当时位置创建并尝试背包，前一次交付失败留地仍做第二步；不自动开箱、不给成对保证。已有钥匙开对应同级箱业务保持。 [原两次交付](../../reference/map-6.25/main.disasm#L189151) · [箱钥开箱](item-reward-packs-batch-01.md)
- **W015 财源滚滚。** 被动。在真实怪物死亡入口取得实际 GetKillingUnit，读取其拥有者登记的工人当前W015档，每只额外5/9/14/20/27金币。nil击杀者及无天赋不付，不把其他玩家归属、基础金币或怪物等级作为支付条件，付款和原基础击杀赏金分开。专属范围是“每只怪”，只适用真实敌方怪物死亡；源注册P11和P0–3，且在过滤前调用导致玩家单位死亡也可给钱，按Q71排除玩家单位，纯删除也不构造死亡。实际临时来源或召唤的拥有者仍按原GetKillingUnit所有者付账。 [专属提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L23578) · [原死亡顺序](../../reference/map-6.25/main.disasm#L168392) · [登记](../../reference/map-6.25/main.disasm#L179487)
- **W016 卡片合成。** 冷却160/150/140/130/120秒。提交顺序扫描实际六槽，先取最前四张Level11 N卡，有则删除四个完整实例、独立等概率创建一张R；不足才取最前四张Level12 R卡，创建一张SR。原以真实品级编码选择，c001–c013合格档可作为材料，W012的置换禁表不移植到这里。SR、SSR、四张混档不合，无原单独SR→SSR。合格先删后给，D01无法入包则留地；冷却不退款。材料不足不删、0.1秒后清本次W016冷却，实际工人存在且能力还有效才写。普通装备配方不替代本专属卡片流程。 [原扫描及触发](../../reference/map-6.25/main.disasm#L189535) · [原输出、失败](../../reference/map-6.25/main.disasm#L189737) · [稀有度卡池](economy-and-progression.md)
- **W017 幸运机会。** 每个真实已提交使用 I001/I002/I003/I005（蓝／普通橙／红／黑）在 ItemSkillUsed 内先读施用者所属工人天赋，按Q17用一次合法整数1–100掷，档1…5按≤10/13/16/19/25命中。只在命中时先走一次该档完整抽卡、显示幸运提示，再无条件走正常抽卡。原即使天赋0也消耗预掷，此流保留正常顺序，等级0不可能成功。额外抽取不额外消耗抽卡道具充能、不递归且不跳过权重状态更新。黑卡首次额外若选中SR并重置权重，随后正常抽取读取更新值。I004特制橙卡、新手礼包和收到塔卡、置换、合成都不进入这条概率分支。 [完整入口](../../reference/map-6.25/main.disasm#L143805) · [Q17与个人权重](economy-and-progression.md) · [一次物品提交](item-lifecycle.md)
- **W018 神兵天降。** 定向9999，冷却25/20/15/10/5秒，蓝0。沿已核同主且非能量圈，实际目标与可落位规则详见空间专项；不会创建新塔或重新触发建造。原工人点不可建造先搜索250圆周；这一层全部失败走原0.1秒清CD。局部Q24原生挤位在其后执行，找不到完整位置则保留旧坐标，已经开始的CD保持。 [完整空间和失败规则](pathing-and-placement.md#W018移塔与核心刷怪创建) · [实际目标入口](../../reference/map-6.25/main.disasm#L190092)
- **W019 潜能爆发。** 共享基础三围写入。每个已有真实原生英雄塔独立记贡献 floor((.5×天赋档+.5)×本次调用英雄等级)，先撤旧贡献再加新。接英雄升级事件及每次W019波次升档遍历同拥有者已有Tower_ALL（包含原守门允许的目标）。原初次选 W009 只挂W019、无立即遍历，后续合格入口才改既有英雄。天赋模式撤回后不再成长，不回滚已经记下的永久贡献；同实体换皮保还，真实换新塔不接旧贡献。 [完整属性与回调](hero-attribute-interface.md#W019-潜能爆发完整函数) · [原批量重算](../../reference/map-6.25/main.disasm#L190224)

## 验证

两个《玩法总览》单元格、工人选择页／八种对象五档、三种卡池边界、随机及物品交付顺序、波次和模式分派都有机器锚点；复用原 VM 核同品质随机、非法第一槽、箱钥独立、击杀金币时点与四素材优先次序。原客户端未实测。 [复查工具](../../tools/audit-worker-talents.py)
