# 原生范围伤害：area-damage-v1

本页闭合 `UnitDamagePoint` 的 Web 目标集合、几何和提交顺序，以及村正、竹光、龙卵领主、雷霆战斧、力量压制五个已核调用的接入方式。**`area-damage-v1` 是 Q24 授权的独立 Web 基准，不是原客户端实测。** 图鉴明文和已核调用参数属于来源事实；无法匹配实际客户端的范围筛选、边缘和调度行为明确按下文选择。

Q28、Q29 的概率、公式和其他已决规则保持：[居合与细雪](item-muramasa-takemitsu.md)。本批没有发现新的图鉴冲突，没有修改图鉴或原始证据。机器表见 [native-area-damage.json](native-area-damage.json)。以下 `Lua`、`字节码` 分别指 [main.readable.lua](../../reference/map-6.25/main.readable.lua) 与 [main.disasm](../../reference/map-6.25/main.disasm)。

## 1. 来源能证明什么

图鉴 `装备与道具!H44` 的细雪和 `塔技能!H776/H779/H782/H785` 的龙卵领主都写明“周围敌人”；村正 `装备与道具!H42` 只说对目标范围造成伤害。后者没有明确友伤规则，不能因为 Lua 没有逐单位过滤，就断言原图违反图鉴或必定伤害自己。

[YDWE 开发工具固定版本的 common.j 声明](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/compiler/jass/24/common.j#L1618)列出来源、延迟、半径、中心坐标、伤害金额、两个布尔标记、攻击类型、伤害类型、武器类型，返回布尔值。它没有公开 native 的枚举、碰撞或零延迟实现。同版本 [Blizzard.j 的点位置包装器](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/compiler/jass/24/blizzard.j#L3844)仅展开位置并传递参数，没有新增目标过滤。

[暴雪法术分类说明](https://classic.battle.net/war3/basics/spellbasics.shtml)区分物理、魔法、通用效果，说明魔免不等于免疫一切技能。该说明没有把每种 `damagetype` 与 `UnitDamagePoint` 的内部行为逐一对应，也不能证明本图实际运行版本。它支持保留伤害类别的必要性；下文的三类魔免矩阵仍明确属于 Web 选择，不伪称来自 native 实测。

本地已有证据没有 `UnitDamagePoint` 引擎实现；公开声明和所查开发者实现资料未补齐匹配本图版本的实现。原地图的编辑器版本字段也不能替代实际客户端版本，参见 [战斗基础的版本边界](combat-and-skills.md)。因此本轮不再将这些底层细节悬置，按 Q24 选定以下确定行为。

## 3. Web 目标集合和圆形边界

一次范围包保留来源单位、中心 x/y、半径、原始金额、延迟和完整伤害类型。**默认选敌方单位**；本页五个完整接入对象都使用此规则。敌方关系取范围包开始结算时来源的当前拥有者与目标拥有者之间的关系，不把“敌人”硬编码成单位名称或固定 Player(11)。已核具体调用若明确使用其他关系策略，以该调用为准；额外的技能筛选只能按其证据接入，不能凭普通点选法术的限制添加。

在范围包开始结算时，对候选单位形成一次快照，要求：

- 单位仍存在且存活，满足敌方关系和调用者明确的额外目标条件。
- 中心距离满足 `(unit.x-x)^2+(unit.y-y)^2 <= radius^2`。只用二维中心点，**包括等号，不加单位碰撞半径或模型大小**。
- 当前不是无敌，没有生效的 `Aloc` 蝗虫能力；魔免检查按下一节。

飞行单位和建筑不会仅因其类别被排除；如具体技能明确只伤地面，再使用该技能的条件。高差、路径阻挡、视野、侦测和隐形不是此范围包额外的过滤条件；也不重新检查普通攻击的射程或地面/空中武器目标列表。这里只选择战场单位，不附带损伤物品或可破坏物；这些对象若有独立、已证实的受伤调用，单独保留。

快照按 [B04](web-baseline.md) 的单位创建序号升序处理。处理每个成员之前重新检查其存在、存活、`Aloc`、无敌和魔免状态；已被较早子事件杀死/移除或变为免疫者跳过。**不重新枚举、不重查位置或阵营**：结算中移出圆、改变拥有者的原成员仍在这次快照；新创建或后来移入的单位不加入。这是明确的 Web 快照选择，可与以后取得的原生实测不同。

半径为 0 时仍是中心点闭集合。有效请求要求中心、金额、半径、延迟为有限数，半径/延迟非负，来源仍存在；错误输入拒绝并报告集成错误，不偷偷裁剪半径或把 NaN 变成全屏命中。零金额不制造伤害事件，调用者随后继续；此前触发门槛、随机数和其他效果不撤销。本基准只接入非负伤害请求；负值明确返回 false，不制造伤害或登记延迟任务，也不解释成治疗。五个完整接入对象中尚未证实可达的负金额：居合/细雪明确在 P<=0 时早退，龙卵本身没有 P>0 早退，不能据此断言所有单位状态下都非负。若后续技能调查证实可达负值，须单列原调用含义，不能静默丢弃。

## 4. 无敌、魔免与运行时接口

| 目标状态/伤害包 | `NORMAL` | `MAGIC` | `DIVINE` |
| --- | --- | --- | --- |
| 无敌 | 跳过，无伤害事件 | 跳过，无伤害事件 | 跳过，无伤害事件 |
| 魔免但非无敌 | 继续进入相应减免/伤害流程 | 跳过，无伤害事件 | 继续进入相应减免/伤害流程 |
| 无上述免疫 | 继续进入相应减免/伤害流程 | 同左 | 同左 |

这是本基准对**已出现的三种 damage type**作出的选择，攻击类型仍原样保留。`attack=false` 不会把物理范围包变成 MAGIC；`DIVINE` 也不因此得到穿透无敌的权限。表中“继续”只表示没有被本节拦截，**不是最终无减免扣血**：原有类别倍率、护甲、魔抗、物品和地图事件仍由相应规则处理。其他 damage type、虚无、独立技能的无敌穿透不能由此类推。

魔免和无敌必须由运行时提供当前状态，不能通过单位名字、模型、满魔抗、生命值或“Boss”标签猜测。已查可接入字段：

- [units_abilitydata.json](../../reference/map-6.25/units_abilitydata.json) 中 `ACm2/ACm3/ACmi/AImx/Amim/T060` 的 `code=Amim`，记录分别始于 L923、932、957、4191、11310、33562。机器表保留这 6 条原记录，包括不能丢掉的 AImx 额外字段。本基准对已生效且最终 code 为 Amim 的能力提供魔免标记；并不借此解释其所有其他参数。
- 同表 `Avul` 在 L13107，`Aloc` 在 L11101。地图 [campaignabilitystrings](../../reference/map-6.25/units_campaignabilitystrings.txt) 的 Amim L9959、T060 L20039 明示魔法免疫；Avul L11174、Aloc L9785 分别标为无敌和蝗虫。
- 初始技能来源是 `units_unitabilities.json` 的 `abilList`，仍须合并 `war3map.w3u.json`、能力增量及局内增删。无敌还可能由 `SetUnitInvulnerable` 设置，不能只检查 Avul。`common.j` 另声明 `UNIT_TYPE_MAGIC_IMMUNE`，但类型声明不列完整的赋予/解除来源。

最小接口是当前 `exists/alive/invulnerable/magicImmune/activeAloc`、单位位置/创建序号和敌我关系。临时变身、Buff 等其他赋予者由各自已核能力适配器更新同一状态；本页不创建那些技能尚未证实的持续时间或触发门槛。缺少该状态提供者是实现时的集成错误，不能静默当作“不免疫”。这保留全局能力生命周期的真实工作边界，同时范围包对给定状态的结果已经完全确定。

## 5. 零延迟和正延迟的提交顺序

**delay=0 采用同步调用。** 在当前脚本调用点形成快照，依次为每个有效成员提交独立伤害上下文；每个子事件按 [B03](web-baseline.md) 先执行适用的原生减免，再走 [伤害主流程](damage-pipeline.md)，最终提交后恢复父事件。处理完全部成员后，`UnitDamagePoint` 才返回，随后执行原调用点后面的特效或伤害改写。

这与 B05 的 `TimerStart(0)` 不同：零秒计时器仍排在当前调用栈之后；范围伤害 native 的零延迟不伪装成一个零秒计时器。每个成员得到同一份调用时已计算好的原始金额，不按目标数均分，也不因为前一个成员承伤不同就修改后一个的输入。地图回调在子事件中照常读取实时属性、修改状态、生成嵌套伤害；不缓存一份“最终伤害”广播给所有人。

一次范围包内部产生多个目标的伤害事件，**仍是一次范围技能发射**：不为每个成员重新抽村正/竹光的触发概率，不重新付费/耗蓝，不额外触发点选施法或普通攻击事件，不应用普通攻击命中掷骰，也不改变原 `attack/ranged` 标记。若地图某个子事件明确另触发效果，仍按该分支执行，不能因此整体关闭嵌套效果。

**delay>0** 则按 B05 将到期时刻与入队序号加入战斗事件队列，续局保留。请求时固定中心、半径、金额、来源引用和全部类型；到期时才按当时的位置/阵营/状态形成目标快照。来源移动不移动已发出的圆心；来源死亡但尚未移除不取消，来源在到期前已移除则取消该范围包。这两项生命周期也是本轮明确的 Web 选择，不能当成已证实的 Warcraft 行为。到期后按同样的同步成员处理规则完成该包。

请求有效则返回 true，即使当时/到期没有目标；无效请求返回 false。正延迟的 true 表示已接受入队，不预言命中结果。已查直接调用不读取此结果，自定义三个包装器也不返回它；BJ 包装器保留透传返回值的接口。

## 6. 五个接入对象保持的行为

**村正：** 原随机入口及资格、B060 与强化资格判断保持；Q28 金额为第一攻击上下限均值×3.6＋最大生命×0.15，必要时×0.8。只在原函数 P>0 时制造一包，以原目标位置为中心，原目标符合集合条件时也受这份范围伤害，不能额外排除它。没有额外金币怪×0.2、取整或最低伤害。

**竹光：** 保持原施法事件过滤，先发生原入口的 A084 回蓝分支，再在细雪函数原读取点获取当前魔法；Q29 金额为该值×0.67。900 圆内敌方地面、空中和建筑同样参加候选，魔免依矩阵排除；不另扣这份魔法。关闭特效不取消范围包。

**龙卵领主：** 原 `attack!=0` 且拥有 N068–N071 任一的入口保持。技能档位按 N069、N070、N071 的优先级确定为 2、3、4，否则 1；金额为第一攻击上下限均值×`[0.8,1,1.2,1.4]`，半径为 `min(1200,50+260*S37/S81)`。这是混乱攻击类型的 NORMAL 伤害包，不能改成 MAGIC 或 HERO。

龙卵字节码 L113628–113648 明确先调用范围伤害，随后才 `EXSetEventDamage(0)`。按本基准，所有子事件完成、恢复父事件后，此语句将**父事件当前伤害**写零；不能误写到最后一个受范围伤害目标的事件。也不能改成先取消父事件再产生范围包，或取消整个攻击事件并跳过主流程后续分支。子包 `attack=false`，不会因这次范围命中再次通过同一个要求 `attack!=0` 的龙卵入口；其他明确满足的地图分支照常执行。

**雷霆战斧：** Q36准确15%及先抽样后查技能的入口保持。N055优先取1200，其次N056取1800，其次N057取4000，否则800；以受击目标当次坐标为中心发出额外范围包，不清零或替换原攻击。后续0.8秒/缩放1.4仅用于特效；完整条件、AOcr适配和案例见[效果规格](skill-thunder-axes-effect.md)。

**力量压制：** Q38准确12%及先查实际来源技能再查攻击标记的入口保持。范围金额为实际来源当时最大生命，读取一次；受击目标中心600，额外CHAOS/NORMAL包保留父攻击。范围结算后才重新读取视觉位置；没有控制调用，详见[效果规格](skill-power-suppression-effect.md)。
