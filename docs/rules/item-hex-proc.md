# 邪恶镰刀／雪落法杖的共享妖术概率

本批只核 `i202_Get_probability` 全函数及其施法事件入口、持有检查、调用顺序；**没有完成 `i202_Skill` 的变羊目标、抗性、持续时间及雪落法杖吟唱效果**。原始字节码与紧凑条件索引见 [item-hex-proc.json](item-hex-proc.json)。

后续共享 `i202_Skill` 与 T049 已在 [妖术效果](item-hex-effect.md) 补齐至明确的 Web 规则，包括目标、控制/持续、护盾和独立延迟伤害；本页仍仅声明概率审计范围，雪落法杖独立主动效果仍未在这两页核查。

## 图鉴、原脚本与 Web 裁决

| 来源 | 明确规则 |
| --- | --- |
| 图鉴 `装备与道具!H112`，i202 邪恶镰刀 | “释放技能时有50%的概率使周围敌人变成小动物，持续2秒。” |
| 图鉴 `装备与道具!H218`，i325 雪落法杖 | 妖术段使用同一句说明；该装备另有独立落雪主动效果，不在本批范围 |
| 原脚本 | `GetRandomInt(0,100) < 50`：101 个整数中 0–49 共 50 个成功，即 **50/101 ≈ 49.505%** |
| **用户已决 Q30** | 两件装备的共享妖术统一为 **50%**；同时持有仍只抽一次，保留原触发过滤和顺序 |

概率函数是 [main.disasm](../../reference/map-6.25/main.disasm) `main/f245/f1`，L128072–128098。PC1–4 抽 0–100；PC5（L128092）`LT r0<50` 为真跳至 PC8 返回 true，为假执行 PC7 的 false 并跳过 PC8。末尾另有不可达的隐式 return。原脚本函数共 **10 条指令、1 个条件、1 次调用、2 个 return 指令**，不是把 `<50` 直接解释为 50%。

## 调用门槛与顺序

入口是 Player 0、1、2、3、11 的 `EVENT_PLAYER_UNIT_SPELL_EFFECT`，注册证据 `main/f291/f35` L179727–179797。`AnySkillStart` 先排除临时单位以及技能 T033、A040、A070、A210，再调用 `Item_Skill_Action`；更早的 `Skill_BS_Still` 调用没有使所有 Player 11 单位直接早退。见 `main/f291/f14` L169999–170072。

`Item_Skill_Action` 的顺序是：

1. 若 `IsWorker(caster)`、`IsBOX(caster)`、`IsUseless(abilityId)` 任一为真，return。
2. 可能先执行 A084 回蓝，再可能执行 i134 细雪概率和效果。
3. 按短路 OR 检查 `HasItem(caster,i202) or HasItem(caster,i325)`。持有 i202 时不再查 i325。
4. 结果不是 nil 才调用一次 `i202_Get_probability`；抽中才调用一次 `i202_Skill()`，否则继续后续装备／技能分派。

前置过滤与先行效果见 `main/f285/f16` L146490–146582；共享检查与调用在 **PC90–112、L146583–146607**。这里没有额外的目标类型、近战、模式、英雄类型或技能内部冷却检查；父入口已有的过滤仍需遵守。函数名含 i202 不表示 i325 使用另一套概率，也不能让同时持两件变成两次独立抽签。

验证枚举原随机整数 0–100，成功数为 50；边界 0／49 成功、50／100 失败。Web Q30 使用准确二分概率，仍只有一个共享抽签点。本批未运行 Warcraft 客户端。
