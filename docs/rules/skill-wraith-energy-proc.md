# 邪盅能量：引用殊死一搏的独立暴击概率

**按用户新增的全局数值策略，A036 附加伤害的独立暴击采用图鉴准确的10/12/14/16/18/21%。** 原拟编号 Q42，现记录为 `resolved_by_global_workbook_numeric_policy`，不表示用户另行回答过 Q42。原脚本的9/11/13/15/17/20%保留为证据；倍率、等级读取、触发门槛及抽样顺序不变。[机器证据](skill-wraith-energy-proc.json)保存完整 helper、caller 与入口。

范围只限 **A036「邪盅能量」附加伤害调用 `A036_CheckA035` 的判定**，不将此结果扩为 A035「殊死一搏」普通攻击原生暴击概率，也不声称已完成整个技能效果。

## 原 helper 与唯一调用路径

完整 `A036_CheckA035` 为 **main/f34/f1，[L64466–64558](../../reference/map-6.25/main.disasm#L64466)，51条指令**，对应 [Lua L39922–39966](../../reference/map-6.25/main.readable.lua#L39922)：

```text
rank = GetUnitAbilityLevel(actualSource, A035)
if rank <= 0: return 1                  // 不抽样
threshold, multiplier = 对应六级表
roll = GetRandomInt(1, 100)             // 包含1和100
if roll < threshold: return multiplier
return 1
```

决定边界的是 [L64547–64556](../../reference/map-6.25/main.disasm#L64547)：区间1–100，`lt 0 r4 r2`严格比较 `roll<threshold`。例如一级成功仅1–9，六级仅1–20；所以原脚本比被引用的图鉴百分比各少1个百分点。等级大于6时，原默认阈值仍为0、倍率1；会抽一次但不暴击，不能自行扩成六级阈值。

全 Lua／字节码命名引用已核：helper 除导出外，**唯一业务调用是 `A036_Action`**，[Lua L39877–39879](../../reference/map-6.25/main.readable.lua#L39877)、[main/f34/f0 PC47–49，L64420–64422](../../reference/map-6.25/main.disasm#L64420)。没有发现其他效果调用它。这里传入的是 `GetEventDamageSource()` 的实际来源 S，不是归属塔 O。

`A036_Action` 自身先读取 S 的 A036 等级，只有1–6级会得到力量系数2/2.5/3/3.5/4/5；其他等级在调用 helper 前返回。确认系数后调用 helper 一次，再将返回倍率乘入这笔额外伤害。**helper 内没有模式、A杖、目标类型、数量、幸运或幻象概率修正。** Action 的 G046 分支仅选视觉资源；幻象判断发生在抽样之后，将额外伤害乘0.2，不改变上述概率。未据此假定自然生成的幻象必然继承 A035/A036。

原额外伤害调用为 `UnitDamageTarget(S,T,STR×系数×暴击倍率×可选0.2,false,false,HERO,NORMAL,WHOKNOWS)`。这里仅记录倍率的使用边界；公共装备、护甲、模式与嵌套伤害结算仍有独立流程，不能把 helper 返回倍率直接称为最终扣血倍率。

## 事件入口及门槛

[anyUnitDamaged PC575–589，L163097–163111](../../reference/map-6.25/main.disasm#L163097)，对应 [Lua L110962–110976](../../reference/map-6.25/main.readable.lua#L110962)：

1. 先检查实际来源 S 持有正等级 A036。
2. 再检查 `EXGetEventDamageData(2)!=0`，即攻击标记。
3. 满足后调用无参数 `A036_Action()`，Action 再按上述等级门槛决定是否进入 helper。

没有 A036 或非攻击伤害不会抽本项；有 A036 但没有 A035时仍可产生普通倍率的额外伤害，helper 直接返回1而不抽样。本入口没有自己的幻象排除、耗蓝或冷却条件；不添加原本不存在的门槛。

保留已核 [伤害主流程](damage-pipeline.md) 的公共前置：初始零伤害返回（包括 q004/q005 的归零）、q039 旁路、攻击来源 B177 处理后返回。JSON保留三段源指令。之后其他回调把事件伤害写0，不会自动制造一个新的全局早退。

## 全局策略下的 Web 数值

只将此 helper 的最终比较改为 **`GetRandomInt(1,100)<=threshold`**：

- 一级成功1–10，失败11–100；随后各级分别成功1–12、1–14、1–16、1–18、1–21。
- 保留同一抽样位置、实际来源等级、六级倍率及无技能时不抽样；不增加重抽，不读取或复用普通攻击原生暴击结果。
- A036 的力量系数、幻象后置0.2、入口及其他来源规则保持。A035 原生普通攻击暴击不在此次数值改动中。

这是用户“以后图鉴与脚本数值差异以图鉴为主”的统一授权应用，不再留逐项批准问题。

## 验证与停止边界

已核206条源指令身份、图鉴四行与实际提示、完整 helper 的全部600个原结果及600个 Web 结果；另外3个等级边界、128个 caller 状态、12个事件入口状态通过。Web 探针只把最终 `lt` 改为 `le`，检查阈值前／等于阈值／阈值后的结果，倍率不变。caller 验证包括有效／无效 A036 等级、未学习／有效／超范围 A035 等级及幻象后置缩放。

探针使用原生函数替身，不代表魔兽客户端实测；未递归执行全伤害分派器，也未验证普通攻击原生暴击、暴击叠加或幻象生命周期。本轮的有限候选筛选见 [内联概率调查](skill-inline-probability-audit.md)，发现此差异后停止扩展。
