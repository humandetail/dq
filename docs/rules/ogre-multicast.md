# 食人魔魔法师的火焰爆轰、嗜血术与多重施法

## 共同施法和掷骰

H018 的实际学习栏含 A058/A059/A060，单位 `castpt=0.3`。主动命令沿[施法提交基准](native-targeted-batch-01.md)，生效后先经过 `AnySkillStart` 的通用物品分派、初始化和各先行分支。实际执行到 PC447 且当前 A060 等级>0 才抽一次均匀整数 1–100。设等级为 L、抽值为 r，本次总次数是 `ceil(r/(100/(L+1)))`，包含原手法；结果为1立即退出多重分支。被动 AOcr 外壳没有独立原生暴击、闪避、必中、魔法或冷却；两种临时能力的效果事件由 IsTemp 早退，不重复掷骰或计数。 [A060 与 A058 分派](../../reference/map-6.25/main.disasm#L170488) · [算法和分支](../../reference/map-6.25/main.disasm#L69513) · [AOcr](native-critical-family.md)

## A058 火焰爆轰

手动/自动共用合法目标。脚本自动从750范围按 hasMon 选目标，提交前摇0.3，实际定向射程800。蓝50/60/70/80/90/100，冷却采用图鉴12/11/10/9/8/7（对象14/13/12/11/10/9）。A058_Action 在 A060 检查之后，仅在 TxShow 开时显示目标头顶火焰表现，伤害和控制由原生适配处理。六级金额1500/1800/2100/2400/2700/3000，普通眩晕1/1.2/1.4/1.6/1.8/2，原生 HERO/Arsk 使用对象0.6秒，五六级缺失时延续0.6。原生合法掩码、BPSE、N535、追踪与 B03 沿[本批定向共用基准](native-targeted-batch-01.md)。主弹速度3000。 [普通效果函数](../../reference/map-6.25/main.disasm#L69301) · [自动入口](../../reference/map-6.25/main.disasm#L174913) · [提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L811)

Q51 确认每次成功多重独立登记实例序号、施法者句柄、原目标、当前塔归属槽、剩余追加次数和下一次0.6秒到期，以 B05 排序及续局恢复。每次到期读取该实例；已满、目标非存活或句柄失效即终止并销毁其计时器、清理其记录。存活的原目标始终是唯一可能目标，失败不另找。对存在的原塔每次取当时位置、拥有者与实际 A058 等级，建立2秒 q001、T053 为同级，把本实例登记时的归属槽写入 UserData（原脚本通过 `IsInTable(原施法者,A060_Units)` 取得），随即向原目标发 `thunderbolt`。该辅助前摇0、费用0、CD1、射程2000、追踪3000，其他同级伤害与控制和主弹相同。原塔死亡但存在时可继续尝试，删除取消。A058 已失效或等级为0时本次尝试失败；合法目标后来越出2000、变无敌、魔免或被 N535 拦截也按失败处理。每次发令尝试消耗本实例一个额度，无补打、没有额外主塔扣费或主塔冷却。成功发出的弹在马甲死亡且仍存在时继续，马甲删除则取消；原塔归属仍由完整伤害流程实时按 UserData 查。 [T053 发令](../../reference/map-6.25/main.disasm#L69370) · [周期](../../reference/map-6.25/main.disasm#L69714) · [T053 弹速](../../reference/map-6.25/units_campaignabilitystrings.txt#L19941)

L6 抽到7时，连续尝试发生在生效后0.6至3.6秒，第4.2秒回调清理。抽中一次不会新建额外计时器。Q51 下新 A058 的额外链与旧链并行，A059 和其他合格施法也不会改写旧链；已发弹道持续按原生命周期运行。同一目标若先被一个实例击杀，随后实例按自身到期的目标存活检查结束。存档恢复不重抽，不重复添加兜帽计划次数。

原行为对照：两种技能都曾写同槽的 `nowNumber/targetI`。三级 A060、A058 抽100本可从0.6秒起追加3枚；若 A059 在首回调前抽50且对额外目标发令一次，原火焰链首回调读到2/2，追加零枚。两次 A058 在 t=0、0.1 都抽100时，第二次先写1/4，再调用 End 销毁旧timer并清表，新timer只留下句柄和目标，t=0.7 首回调在 VM 读 nil 比较失败。Q51 相同输入各追加3枚，分别在0.6/1.2/1.8秒与0.7/1.3/1.9秒发令。 [重施原顺序 PC66–96](../../reference/map-6.25/main.disasm#L69581) · [End 清表](../../reference/map-6.25/main.disasm#L69783) · [B05](web-baseline.md)

## A059 嗜血术

Q50 确认，额外目标在主目标提交时的位置600闭圆内，从当时存在、存活、通过下述 T054 目标准入的友方单位中排除主目标，均匀无放回选最多 `总次数−1` 个，按抽中顺序下单。不足不补，只有一名可用候选时可直接选，零候选不抽；因前一个效果使后一个排定目标在下单时非法，不改选。额外尝试只使用本次 A059 自己的限额，Q51 下对旧爆轰没有计数写入。主目标资格使用主法术掩码；额外目标按 T054 的 friend/invulnerable 条件，可含非英雄且不增加有机标签条件。实际临时施法者必须满足其射程1200，隐匿/已删除/Aloc/魔免仍拒绝。源脚本 PC113–150 只按组枚举、排 Player(11) 和主目标，随后消耗额度；这份顺序保留为来源证据。 [原嗜血援助分支 PC99–190](../../reference/map-6.25/main.disasm#L69616) · [T054 原提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L19955)

## 灰烬兜帽交接

A060 只在持有 i318/i319/i320 至少一件且总次数>1时，将计划额外次数 `总次数−1` 一次性写同一塔槽。此处没有智力门槛、没有即时释放焚焰，也不按实际命中、候选不足、盾或后续打断撤回，三件只加一次。原代码对尚不存在的槽直接尝试 nil 加法；Web 新计数槽从0开始，原 nil 加法保留在源探针。正常的英雄基础标记由先行 `Item_Skill_Action` 在非 A075 时调用 `i318_AddSign`；A075 走另一条完成入口，跳过该处的生效计数。该函数只在含加成的 INT ≥ STR 且 INT ≥ AGI 时累积或兑现，平手可用。原零或空记1，旧1–3加1，旧值≥4时从塔当前坐标750圆按 hasMon 选目标。有则清零并发一次焚焰，无则保留原标记。原计数超过阈值时仍整槽清零。Q53 已改为每次消耗5层、保留余数；无目标也保留本次新增印记。A060 的接口继续只写入计划次数。 [灰烬兜帽专题](ogre-hood-items.md) [额外计数 PC29–58](../../reference/map-6.25/main.disasm#L69542) · [普通入口](../../reference/map-6.25/main.disasm#L146649) · [门槛](../../reference/map-6.25/main.disasm#L153369) · [A075 完成入口](../../reference/map-6.25/main.disasm#L172372)
