# 昼夜、暗夜猎影与基础回复

本页落实 Q43，并补齐 A193/A194 的自然夜晚、个人夜晚、换挡、伤害入口和计时器。局部基准为 `night-hunter-v1` 与 `world-clock-and-base-regen-v1`。原函数、逐级物编和案例在[机器表](night-state-and-regeneration.json)，图鉴原值与坐标在[双图鉴核对](night-workbook-check.json)。原生未公开细节明确标为 Q24 选择；未运行原客户端或 Web 游戏。

## 两种夜晚

**全局昼夜**由地图时钟决定。**个人夜晚**是黑暗飞升赋予该英雄的状态，不改变地图时钟、其他单位的昼夜或地表回复条件。二者任意一种有效，就能满足本技能的夜晚判定。

[初始化 main/f306/f64](../../reference/map-6.25/main.disasm#L202876) 将时间设为6时、速度设为2。地图 Misc 没有覆盖一天长度；[固定版本 YDWE 基础配置](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/MiscData.txt)给出 DayLength=480、Dawn=6、Dusk=18、DayHours=24。**Q24 采用该480秒基础值**，因此本图一天为240个模拟秒，白天 `[6,18)`、夜晚其余时段。开局120秒首次入夜、240秒首次天亮，此后各隔120秒。

[时刻事件登记 main/f291/f42](../../reference/map-6.25/main.disasm#L180222) 挂接6时移除、18时添加。Web 用 B05 精确时限排事件，不每帧用浮点相等判断。登记时已在6时不额外生成一次天亮事件。暂停、倍速、后台追赶使用同一模拟时钟；保存当前相位、下次切换时限和事件序号，恢复不重播初始化事件。

## 暗夜猎影 A193

图鉴 `塔技能!F311:I311`、`F341:I341` 分别属于 G071 恐惧之主、H050 暗夜魔王，均6级。白天的攻击附加值为 **50/75/100/125/150/175**，攻速贡献为 **35/40/45/50/55/60%**；夜晚将这两项翻倍。原脚本通过 T208/T209 的第1–6级与第7–12级切换，不在已有值上反复叠加。

T208 是一次平直武器攻击贡献，T209 是一次原始攻速贡献，接入[攻击计时](attack-timing.md)的 R。T209 原物编浮点值保留为证据，Web 使用图鉴精确十进制。A193 的 AOae 外壳不再额外发一份光环：其不完整 DataB 字段、`targs="_"` 不构成第二份加成的依据，此为局部 Q24 选择。

[学习入口 PC200–208](../../reference/map-6.25/main.disasm#L169251) 调用 A193_Action。该函数先以塔槽登记英雄，再调用 Change_Skill_Lv。源逻辑仅看已有夜晚标记，所以夜间首次学习仍可能得到白天档。

**Q43 的改动点：登记后、换挡前，仅同步刚学习者的自然昼夜标记。** G071 的自然标记为 T255/T257，其他类型为 T214；同步先移除该单位已有的这三种自然标记，再按当前全局昼夜添加应有标记。添加保持原永久能力性质。T215/T256/T258 个人标记及个人计时器不受影响。白天但个人夜晚有效时，换挡结果仍是夜晚档。

Change_Skill_Lv 的原控制流保持：A193等级≤0直接返回，不自动清除旧加成；夜晚判定成立则期望等级加6；只比较当前 T208 和期望等级，不比较 T209。因此 T208已等于期望档时，不额外修复缺失的T209；两者不等时才按顺序添加/设级/永久化两项。Q43没有授权顺便改变这些其他路径。

## 黑暗飞升 A194

图鉴 `塔技能!F312:I312`、`F342:I342` 的冷却均35秒，持续 **15/16/17/18/19/20秒**。耗蓝采用图鉴 **20/40/60/80/100/120**；原对象40/70/100/130/160/200保留作差异证据，依用户全局规则自动覆盖。

正常主动施法为无目标自用。Q24 施法接口核存活、存在、技能有效且等级1–6、控制锁、蓝量及冷却；使用实际英雄0.3秒前摇，提交时重检，扣蓝并起冷却，然后派发一次原 AnySkillStart。前摇取消不扣费；提交后不自动返还。原对象 ANcl 的0.1秒字段不解释成需要持续引导15–20秒。手动施放可以刷新已经存在的个人夜晚。

[施法分派 main/f291/f14 PC1218–1227](../../reference/map-6.25/main.disasm#L171334) 进入完整 A194_Action：读取塔槽和旧计时器，销毁旧计时器，创建并登记新的单次计时器，再添加个人标记并换挡。G071添加永久 T256/T258；其他类型添加永久T215。核心函数没有独立存活或等级准入检查；直接调用时等级2–6对应16–20秒，其余值（包括0）走15秒分支。正常施法准入与直接脚本调用不合并。

到期回调从计时器反查槽位，读取**当时的 Tower_ALL[槽位]**，销毁并清除计时器记录，再按当时单位类型移除个人标记：G071移除T256/T258/T215，其他移除T215，最后换挡。自然夜晚仍在时保持夜晚档；自然白天时退回白天档。旧计时器刷新后失效，不能多排一次恢复。

[自动施法优先级98](../../reference/map-6.25/main.disasm#L177319) 先检查就绪，再要求 IsYeMoNightBuff 为false，最后发立即 `channel` 命令并结束本轮扫描。因此自动不会在自然夜晚重复施放，手动不受这个附加条件限制。

## 夜晚伤害与生命周期

IsYeMoNightBuff 仅检查 **T214、T215、T255、T256** 任一等级>0；不检查全局时钟、T257/T258或A193等级。T257/T258仍按原脚本添加/清除，不能因为当前判定不用就从存档丢弃。六个标记的 AHad 外壳没有明确护甲贡献，目标为空；Q24 不发额外护甲或外部光环，也不把能力标记当作普通可驱散 Buff。

[伤害主流程 PC1273–1293](../../reference/map-6.25/main.disasm#L163834) 对**归属来源 O**调用上述判定：Game_Mode==1时当前事件伤害×2.5，其他模式×1.8。该局部入口没有要求攻击标记，也没有另查A193等级；前面的公共过滤、已改写伤害和嵌套调用顺序照旧。不能把乘数提前到原生暴击或再复制到所有者以外的单位。

自然天亮/入夜只遍历已登记且非空、生命>0的单位，再处理自然标记并换挡。死亡单位会跳过，可能保留旧标记；Q43只修学习时同步，**不额外修复复活或换皮**。个人计时器回调没有相同生命门槛。删除单位按共享接口读0/写无效，槽位保留墓碑不复用。保存注册表、实际能力等级、身份/槽位和全部未完成计时器；恢复时不伪造学习事件。

## 基础生命与魔法回复接口

[暴雪昼夜说明](https://classic.battle.net/war3/basics/daynight.shtml)指出普通单位存在夜晚/荒芜地条件，并说明英雄持续回复；[英雄说明](https://classic.battle.net/war3/basics/heroes.shtml)分别描述基础回复和属性回复。这些资料不证明定制地图的所有组合与引擎版本，以下按 Q24 明确采用分量模型，与[英雄属性接口](hero-attribute-interface.md)一致。

- 生命基础输入：`gate(模板regenHP, regenType) + 原生HERO的有效力量×0.1`。条件只限制模板分量，不限制力量分量。
- 魔法基础输入：`模板regenMana + 原生HERO的有效智力×0.03`。regenType不限制魔法分量。
- 条件为always、day、night、blight、none，分别为始终、全局白天、全局夜晚、当前荒芜地、关闭。未知条件不能默认为always；个人夜晚不代替全局条件。
- 仅对存在、存活、未隐藏对象积累；单位暂停本身不关闭被动回复，全局暂停停止模拟时间。在切换属性、昼夜或地表之前先结算旧速率，保留小数，不按整秒取整、不储存溢出回复。

这部分只定义基础输入和正回复计时；模板缺值的导入、负回复及致死、百分比装备、其他额外回复提供者仍需各自接入，不能宣称全部回复系统完成。A018/I230固定附加回复继续服从[回蓝光环](mana-auras.md)的既定位置。

本图W3E为97×97角点，共9409条记录。按[解析器的7字节结构与0x20荒芜标志](https://github.com/flowtsohg/mdx-m3-viewer/blob/master/src/parsers/w3x/w3e/corner.ts)扫描，初始荒芜标志为0。此事实不等于对局永远没有荒芜地：后续原生生产能力或显式修改要另行维护地表状态，不能由“未找到自定义SetBlight调用”推出永远为假。

## 验证与边界

`python3 tools/audit-night-state.py` 解析8个完整函数共408条指令，执行82条原生接口桩案例及6个时钟向量，并合并10项能力的SLK/物编。关键调用片段另核函数、PC和行号，避免将相邻施法handler混认。

案例包括四标记16种组合、两种英雄的各级昼夜学习、自然/个人夜晚重叠、刷新销毁旧计时器、死亡时跳过天亮、T208相同不修T209，以及核心函数等级0的15秒路径。此为静态执行和明确Web规格检查，不能替代引擎实测或游戏验收。A192、全部换皮/复活/幻象转移与其他回复提供者继续核查。
