# 力量压制：N086 概率入口与 Q38 裁决

本批只确认 **肉山（伪）<SR> n208 的 N086“力量压制”**：图鉴身份、概率 helper、伤害事件入口和公共门槛。**Q38 已选图鉴的准确12%；原12/101保留为来源证据。** 机器证据见 [skill-power-suppression-proc.json](skill-power-suppression-proc.json)。相邻 T325/末日使者复制技能是另一条入口，不在本题范围内。

## 身份与明确差异

`塔技能!F548=N086`，对应 n208 肉山（伪）<SR>，G548 为能力等级 1。**H548** 原文：

> 肉山的攻击有12%的概率产生一次威慑，对目标600范围内的敌人造成肉山血量的物理伤害。

[实际 Name/Tip/Ubertip，units_campaignabilitystrings.txt L13985–13995](../../reference/map-6.25/units_campaignabilitystrings.txt#L13985) 与此身份及文字一致；Ubertip 在 L13995。相邻的 Researchubertip 是“致命一击”15% 模板残留，不能代替实际 N086 的 12% 提示，也不作为新冲突。[单位挂载 L6260](../../reference/map-6.25/units_unitabilities.json#L6260) 明确 `n208.abilList=Avul,T033,T037,N087,N086,N085`；[能力记录 L25354](../../reference/map-6.25/units_abilitydata.json#L25354) 与相关物编查询保存在 JSON，不能因名称相似就将 N086 换成 T325。

[N086_Get_probability，Lua L72165–72175](../../reference/map-6.25/main.readable.lua#L72165) 对应完整字节码 **`main/f181/f1` L114054–114081，共 10 条指令**：

```text
roll = GetRandomInt(0, 100)  // 两端均包含，共101个整数
return roll < 12
```

[字节码 L114070–114079](../../reference/map-6.25/main.disasm#L114070) 明确加载区间 0、100 和阈值 12；`lt 1 r0 k3` 根据比较设置返回值。返回 true 仅为 **0–11**，false 为 **12–100**，所以原执行概率为 **12/101 ≈ 11.881188%**，图鉴与实际 Ubertip 均为 **12%**。

这是单个1级能力的固定阈值。完整helper没有模式、幻象、技能等级、A杖等修正分支。**Q38 已选准确12/100**：Web 在原helper调用点抽一次均匀整数1–100，以 `roll<=12` 判定；1–12成功、13–100失败，原区间和比较符仅留作来源证据。

先查实际来源持有N086，再查攻击标记，符合后才抽这一次。无技能、非攻击伤害或已被公共流程跳过时不抽本项；不能套用前两项先抽后查能力的顺序。本题不改相邻T325的概率或入口。

## 原入口顺序与公共门槛

入口为 `anyUnitDamaged` / `main/f291/f1` 的 **PC1878–1896**，[字节码 L164474–164492](../../reference/map-6.25/main.disasm#L164474)，对应 [Lua L112288–112307](../../reference/map-6.25/main.readable.lua#L112288)：

1. **先查实际伤害来源 S（r0）拥有 N086 正等级。** 不改用归属塔 O（r2），不检查相近名称或 T325。
2. 再要求 `EXGetEventDamageData(2)!=0`，即攻击标记的伤害事件。
3. 然后调用一次 `N086_Get_probability()`；成功时调用一次无参数的 `N086_Action()`，失败继续下一段。

**没有 N086 时不消费本 helper 的随机数；非攻击伤害也不消费。** 这与前两项先抽再查能力的顺序不同，不能套用同一段泛化代码。该入口位于 N054_57、N058_60、N068_71 之后，它们的独立调用及随机数仍保留；随后从 PC1897 进入 T325/A164_T325 的独立分支，本题不共享、合并或裁决后者概率。

此段没有自己的非幻象限制、Game_Mode 限制、额外敌方玩家检查、耗蓝/冷却检查或修改后的事件伤害正值检查。不据此假定幻象创建时必然继承 N086；本批仅说明实际持有后的准入代码。

保留 [伤害主流程](damage-pipeline.md) 中已核公共门槛：

| 公共分支 | 字节码 | 对 N086 的影响 |
|---|---|---|
| q004/q005 来源写 D=0；随后初次 D==0 返回 | PC1–27，[L162494–162522](../../reference/map-6.25/main.disasm#L162494) | 不到达本段，不抽本 helper |
| 实际来源 q039 旁路到 PC3964 | PC98–105，[L162598–162605](../../reference/map-6.25/main.disasm#L162598) | 跳过主体；不是立即 return |
| attack 非 0 且实际来源有 B177 | PC198–214，[L162702–162718](../../reference/map-6.25/main.disasm#L162702) | 先调用 A164_T322_Action，再 return，不到达本段 |

初始 D==0 只检查一次。后来其他回调将 D 写为 0，不会自动增加一个原本不存在的全局提前返回；保留已有流程和回调次序。

## 验证与停止边界

已只读对齐图鉴 F548/H548、角色、实际 Ubertip 与单位挂载；JSON 保留完整 helper、19 条入口指令、52 条公共门槛指令及源哈希。81 条指令身份核验、1212 个入口状态和 12 个公共门槛局部状态均通过。独立字节码探针枚举全部 101 个结果，检查 0/11/12/100；入口验证无技能、零等级、持有 N086、仅有 T325，以及 attack 为 0/非零时的抽样与调用顺序。公共门槛使用局部片段验证，不声称执行过整个伤害分派器或魔兽客户端。

**Q38 已确认准确12%，并验证100个结果与先查技能的入口边界。** `N086_Action` 的完整物理伤害、范围包/减免、原生 AOcr、控制效果与相关回调不在本批闭合范围；600 范围及“肉山血量”仅用于图鉴与提示身份核对。本题也不决定 T325 的复制技能规则。本批只检查此一组新的 helper，确认差异后停止。
