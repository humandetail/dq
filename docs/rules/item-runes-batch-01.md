# 地面神符的生成与拾取

本批闭合 i718–i722 五枚地面神符。含两种直接挂载 I222/I223、两种脚本载体 I224/I225 和无能力挂载的赏金神符。恢复神符 i723 直接沿 Q64 已核结果。[机器表](item-runes-batch-01.json) · [恢复神符](item-restoration-batch-01.md)

| 神符 | 图鉴 | 拾取效果 |
|---|---|---|
| 赏金 i718 | H238 | 每位参与玩家获得当前主线波次×66金币。原脚本0波兜底66，常规生成随波次。 |
| 力量 i719 | H239 | 参与玩家英雄获得 B052，物理伤害×1.2，10秒。 |
| 奥术 i720 | H240 | 参与玩家英雄获得 B053，魔法伤害×1.2，10秒。 |
| 极速 i721 | H241 | 参与玩家英雄获得 B051，攻速加成+0.5，10秒，含英雄拾取者。 |
| 幻象 i722 | H242 | 在每位参与英雄附近生成其一份幻象，10秒、40%普通攻击输出、受到200%伤害。 |

## 生成与触发

- 主线每次波次刷新入口先掷整数1–100，严格小于50且 Game_Mode=0 才登记15秒计时。到时若无未拾取神符，分别为 X、Y 从参与玩家神符点取随机下标，加10、减220，再从 i718–i723 等概率选一个。单人仍保留两个位置抽样以及随后的类型抽样。ClearRune 将本组追踪表清空。拾取走 L02 powerup 即时入口，针对实例至多成功一次，无须先占槽；本体消耗后没有手动道具操作。脚本在各自分派开头清生成追踪，末尾播报4秒。[刷新 L184114](../../reference/map-6.25/main.disasm#L184114) · [生成和清追踪 L181218–181370](../../reference/map-6.25/main.disasm#L181218) · [实际拾取分派 L145429–145503](../../reference/map-6.25/main.disasm#L145429)
- 赏金读取当时全局 cur_monLv，正值乘66，否则用原兜底66。实际脚本逐个写玩家槽0–3的当前金币；Web 单人按现有参与者模型给实际玩家账户。它是直接金币更新，不进入击杀金、赏金倍率或自动记账统计。[原脚本 L136381–136486](../../reference/map-6.25/main.disasm#L136381)

## 状态与幻象

- 主线图鉴明确所有玩家英雄。效果开始时按参与玩家的有效原生 HERO 实体稳定快照，包含英雄拾取者、排除失效和死亡单位，允许有效无敌英雄。两种直接 AIsa 的源 friend 筛选与地图默认盟友关系一致。Web 施加采用显式参与者资格，保留共用魔免、驱散和形态接口。状态从登记起10秒，成功重复施加刷新同一 Buff，异 ID 可并存，死亡、删除、到时或有效驱散撤回。
- 力量和奥术的 B052/B053 仍分别位于现有伤害分派首两步，实际伤害源幻象继续沿原早退。原代码在 L145736/L145758 写1.1，图鉴和原提示均写20%，Web 更换对应一步的倍率为1.2。两者原挂载 AIsa 的 Ispi=2 是移动速度增加，图鉴未排除速度通道。Q24 采用 +200% 移动速度贡献，两个同族速度卷轴取当前最大值，保留固定单位和现有50–722限幅。I222/I223 的60秒源冷却留证，已提交的独立地面神符各触发一次，不为后续地面拾取设置全局60秒锁。[伤害分派原顺序](item-damage-dispatch.md) · [原版速度卷轴](https://classic.battle.net/war3/basics/heroitemsconsumed.shtml) · [Ispi 元数据](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/AbilityMetaData.slk#L9833)
- 极速源脚本先枚举参与玩家单位，预筛只去掉拾取者，再为各候选在当前位置创建同主 q001，挂 I224 发 bloodlust，由原生 friend/hero 目标字段收窄，载体寿命3秒。按 Q64，Web 在原候选中补入活着且符合条件的英雄拾取者，并保留载体归因。I224 的 Ablo/DataA1=0.5 加入现有攻速通道；未写 DataB1，Q24 选0额外移速。[极速载体与筛选 L136543–136655](../../reference/map-6.25/main.disasm#L136543) · [攻速接口](attack-timing.md)
- 幻象源脚本用 native HERO 枚举；每个本体当前位置创建同主 q001，加 I225 后发 852274，载体寿命3秒。I225 的0.3输出字段按图鉴覆盖到0.4，保留2倍承伤、10秒和一份成功幻象。沿 BIil 既有归属和创建快照接口，以被复制英雄的实际武器伤害及局部已确定继承计算，再应用输出系数。用有效落点接口确定同位置或相邻位置，成功实体寿命从生成起算，旧幻象独立于随后再生成的实例。死亡提前删除，英雄后续换装和死亡不重写旧快照。[幻象载体 L136658–136775](../../reference/map-6.25/main.disasm#L136658) · [BIil 与快照](skill-coup-de-grace.md)
