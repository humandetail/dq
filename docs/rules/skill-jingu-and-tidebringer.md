## A077：三条入口与 60 次边界

计数按 `IsInTable(O,Tower_ALL)` 下标保存。三个入口各自保留，不能改成统一“成功普通攻击次数”：

1. **普通攻击开始**：注册目标为 Player(11) 的 `EVENT_PLAYER_UNIT_ATTACKED`。实际攻击者非幻象，实际 A077>0 且 A078==0 时计一次；前面依次执行 Skill_Auto 等已有分支。取消攻击或最终落空仍已计数，普通伤害回调不再重复计数。[main/f291/f3 PC1–128，L167142](../../reference/map-6.25/main.disasm#L167142)；事件注册沿用 [山崩入口证据](skill-avalanche-proc.json)。
2. **棒击大地 q017 的伤害事件**：先完整调用 `A076_Damage(O,T)`，随后读 O 的实际 A077>0、A078==0 再计一次。按每个已准入伤害事件计数，不按施法一次、唯一目标或最终扣血一次去重。[PC992–1023，L163539](../../reference/map-6.25/main.disasm#L163539)。
3. **猴子猴孙 b117/b118/b139/b140 的伤害事件**：读归属塔 O 的实际 A077>0、A078<=0，再计一次。此分支没有独立攻击标记、最终正伤害或存活检查。[PC1037–1088，L163586](../../reference/map-6.25/main.disasm#L163586)。

后两条仍经过原伤害分派公共门槛：q004/q005 先清零，入口伤害恰为 0 时返回，q039 绕过效果块；`ItemDamageActionBefore` 在前，之后没有重复检查伤害是否变为 0；B177 的攻击分支会在它们之前返回。归属 O 由 `IsTemp/幻象/SAPPER` 条件及 `Tower_ALL[GetUnitUserData(S)]` 解析。q017 与四类猴子在 IsTemp 表中；A076 创建 q017、A079 创建猴子后都写入本体槽位。不能仅用实际伤害来源的拥有者代替这一归属。[公共前缀 L162494](../../reference/map-6.25/main.disasm#L162494)、[临时类型 L30909](../../reference/map-6.25/main.readable.lua#L30909)、[q017 创建 L73818](../../reference/map-6.25/main.disasm#L73818)、[猴子创建与归属 L74572](../../reference/map-6.25/main.disasm#L74572)。

原 `A077_Action` 首次遇到 nil 只置 0 并返回，以后才递增；已有计数 >=59 时触发，因此从 nil 实际要第 **61** 次。4 秒结束又将计数清为 nil，会重复这一边界。按全局图鉴数值优先，Web 只把 nil 初始化后的返回改为继续当前判断/递增：第一次变为 1，第 60 次触发。其余顺序不变。[main/f67/f2，L74110–74302](../../reference/map-6.25/main.disasm#L74110)。

- 未满时加 1，更新十位/个位显示；重新安排 1.5 秒隐藏计时器。**隐藏只将数字动画设为 10，不清计数**。“连续”没有额外失效间隔，不能擅加断连重置。
- 满额时先隐藏数字并清其计时器，计数置 0，创建 4 秒非周期计时器，再添加 A078，并设为此刻实际 A077 等级。
- 三条正常入口在 A078 生效时均不再调用，故不累计下一轮，也不刷新 4 秒。函数本身没有“已激活则返回”的保护；不能把真实直接重入改成幂等。直接重入覆盖计时器引用时，旧计时器并未被取消。
- 到期先由计时器反查槽位、读当时 Tower_ALL 对象，移除 A078，销毁计时器，清活动计时器与计数为 nil。[隐藏 L74041](../../reference/map-6.25/main.disasm#L74041)、[到期 L74303](../../reference/map-6.25/main.disasm#L74303)。

## A078 与棒击大地的伤害

原 A078 倍率直接影响普通攻击。对棒击大地，`A076_Damage` 则另算 `(S18+S19)×(A076等级+1)×神杖系数`；神杖系数仅在 Game_Mode==1 且 `Has_A_Item(O)` 时为 3，否则 1。有实际 A078 时原脚本再乘 `2+0.5×A078等级`，即 2.5/3/3.5/4/4.5/5，与图鉴所引用的 3.5/3.8/4.1/4.4/4.7/5 不符。Web 在合法 1–6 级使用图鉴表，保留其他数值、参数和顺序。[main/f66/f1 PC29–72，L73925–73969](../../reference/map-6.25/main.disasm#L73925)。

顺序不可交换：先将 q017 原伤害事件清零，再请求 T076 一级 thunderbolt 临时施法；读取当时能力/攻击/神杖状态，A078>0 时创建 q019、写本体槽位并用它 `SetRealDamage`，否则直接由本体提交。最后回到分派器才计 A077 次数。因此使计数刚满的**这个波动目标**使用触发前倍率；后续 q017 目标事件可能享受新 A078。q019 不因“归属本体”再次走普通原生暴击，也不是新的 A077 计数来源。[L73897–74007](../../reference/map-6.25/main.disasm#L73897)。

**jingu-mastery-v1 的原生选择（Q24）**：延用已有 [原生暴击组件](native-critical-family.md) 与 [必中区别](item-relic-hit.md)，明确扩展至 A078；不是从 AOcr 字段名证明原客户端行为。

- 在真正普通攻击的合法主目标命中阶段，读取实际生效 A078 的等级、目标掩码与倍率快照。六级统一目标类别 air/ground/enemy/neutral；每次仍消耗一个独立 1–100 抽样，100% 成功。与其他已核暴击按成功倍率取最大，不相乘；同 ID 只计一份。A078 按能力 ID 排序进入既有原生暴击候选序列。
- 成功分支保证不因普通闪避/丢失而落空，仍须满足目标存在、攻击合法性及无敌等检查。原始普通攻击包乘倍率后进入原生减免，再进地图 Before；不直接改最终伤害为未减免数值。
- 普通攻击开始的第 60 次授予发生在命中快照之前，所以这次攻击若继续到命中阶段可享受 A078。快照形成后再到期或换皮不重写已捕获倍率；尚未到命中阶段的攻击按届时状态读取。
- A078 授予时记录的等级不会因随后学习/剥离 A077 自动同步。到期仍按原计时器移除。四类猴子没有 A078，脚本也未向其添加；它们只为本体计数，不自动继承本体暴击。一般幻象不隐式复制此临时授予及计时器，这是本页限定的 Q24 选择，不能推广成所有技能的幻象规则。

[暴雪原生暴击说明](https://classic.battle.net/war3/orc/units/blademaster.shtml)与 [YDWE 字段元数据](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/AbilityMetaData.slk)只支持基础功能/字段识别，未证明本图实际客户端的快照时点、叠加、继承和缺省字段处理。上述细节明确是 Web 基准。

## A081：学习、范围包与回充

学习事件只在实际学习的 ID 为 A081 时调用 `A081_Study`。读实际等级；等于 1 时添加并永久化 T082，然后只要 T082>0，便给**当前 S19 加 400**。不取消冷却、不记录或归一化旧加成。[学习分派 L169032–169112](../../reference/map-6.25/main.disasm#L169032)、[学习函数 L75507–75578](../../reference/map-6.25/main.disasm#L75507)。

1. 查 `IsInTable(S,Tower_ALL)`、读当前 A081 等级 L；槽位 -1 或此槽已有计时器则直接返回。其余情况立即创建/保存 `4+0.5×(6-L)` 秒冷却，先于任何子伤害，防止嵌套事件再次触发。
