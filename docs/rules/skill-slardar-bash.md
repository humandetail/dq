# 鱼人守卫与深海暴徒：重击 A032

局部基准 `slardar-bash-v1` 核对两本图鉴的塔技能第412、601行全部A–J列、原生能力与五六级增量、实际挂载和武器。没有找到原字节码中 `A032` 的字面引用，当前效果由原生 AHbh 承载；这不是整条攻击流水线没有其他脚本的结论。[机器证据](skill-slardar-bash.json)与[可重复核查工具](../../tools/audit-slardar-bash.py)保存原值和来源哈希。

图鉴H412/H601明确 **10%**，原能力[DataA1–4](../../reference/map-6.25/units_abilitydata.json#L14385)为8，五六级未写，W3A也没有概率增量。按用户全局授权，六级均采用准确10%，不再提问。额外物理伤害为 **220/460/700/1040/1300/1600**；后两级由[W3A Hbh3](../../reference/map-6.25/war3map.w3a.json#L555)补齐，和图鉴一致。[实际提示](../../reference/map-6.25/units_campaignabilitystrings.txt#L415)亦写10%。J列为空。

图鉴普通眩晕为1秒。源 Dur1–4=1、HeroDur1–4=.4，Buff=BPSE；图鉴没有单列原生英雄时长，保留源的英雄差别。五六级缺失的英雄时长在本地Q24规则明确延续.4秒，不伪称原字段已经存在。有效抗性皮肤复用已定英雄时长接口。普通模式、无尽、深渊没有本技能独立系数；其他地图控制提前解除仍在原事件位置执行。

这项接入[普通塔重击既有规则](creep-skill-family-001-053.md)，只替换本项参数和地空目标掩码：

- 每次成功普通武器命中，读取当前实际启用的A032等级；来源不是幻象、目标是合法敌方单位时抽一次均匀整数1–100，≤10成功。未命中、无技能、非普通攻击、虚无、隐藏、Aloc或无敌目标不为本技能抽样。魔免不阻挡重击。伪随机没有来源证明，此处是独立概率的Web选择。
- 成功把固定加伤放在原普通物理包里，排在原生暴击倍率之后：例如基础100、倍率3、一级重击得到520，然后走一次原生减免和B03；不把220也乘3，不另发一笔伤害或额外施法事件。保留原武器攻击类别、实际来源和攻击标记。缺失DataB/DataD/DataE采用已定局部缺省1/0/false，不附送额外倍率、闪避或必中。
- 伤害提交前给可控制目标加BPSE。建筑/机械可承合法普通攻击的加伤，但不眩晕。BPSE共用已定义槽，截止时间取 `max(旧截止,当前时间+本次时长)`，不叠时长；普通驱散不解除，显式移除、死亡、删除、到期解除。打断未提交的攻击/施法/引导，已发弹道继续；本被动不消耗N535法术护盾。移除A032只阻止后续触发，不回收目标已有眩晕。
- 本被动不扣蓝、不设独立冷却。上述命中通知和目标筛选是明确的Web接口；不把任意脚本 `attack=true` 事件视作又一次普攻。
