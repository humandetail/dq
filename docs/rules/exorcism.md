# A066 驱使恶灵

## 规则

- **施放。** H020 死亡先知与 G022 冥灵之影使用无目标 ANcl `robogoblin`，单位前摇 .3，DataA .5 为可打断恢复窗。等级 1–6 耗蓝 120/150/180/210/240/270，基础冷却20秒。自动按 B04 从800内找到活 P11 后发同一无目标命令。提交只扣一次，公用 FINISH 的 i327/B164/B167 和玲珑路径在各自成立时仍有冷却最小16秒，保留共享消费顺序。这个下限和恶灵持续时间各自独立。[外壳与前摇](hero-spells-batch-01.md) · [冷却修正](dragon-transformation.md) · [玲珑](divine-books.md)
- **生成。** 提交时先终止同塔槽的旧批，移除旧恶灵并销毁旧生成、控制、结束和回收 timer。按提交时 A066 档取 5/7/9/11/13/15 只，`Has_A_Item` 当时成立额外8只。开始每 .1 秒依次造一只，首只在 +.1，目标数量达到即停。每只出生读动态 `Tower_ALL[index]` 当前 O 的坐标、所有者和当前造型，G022 为 q012，其余为 q011。出生朝0，Avul/Aloc，飞行高度380，BHwe 20 秒兜底生命，设置当次主塔槽 UserData，并挂一级 T057。再次读取 O 当时的神杖，为真的这一只独立添加一级 T061；已授予的单位保留到该单位移除，期间取下或重新装备只影响后续出生。T061 一级 100% 且 DataE1=1，Web 用共用武器必中，缺失的暴击倍率不另补。
- **控制。** 生成、控制、计时、在途投射物按实例及真实载体 ID 保存。每次提交另起每秒一次的命令周期。按动态 O 当前 XY 枚举闭圆900、可见、仍活的 P11 候选，B04 排序。按恶灵出生顺序处理，每只离 O 严格大于900时都向 O 此刻位置发 `move`。900内、候选池为空就给 `stop`，有候选且该恶灵当前命令是 `move` 时均匀抽一个候选并发 `attack`。每只独立抽样，可撞到同一目标。900内已在 `attack` 或其它命令时不强换目标，原生武器普通索敌另走自身 acquire=900 和敌我、能见准入。控制循环约束群体位置，不把每秒一次命令误作一次伤害。[目标控制](../../reference/map-6.25/main.disasm#L71225)
- **飞行和漫游。** 常速350，使用现有飞行层路径和转向接口。T057 是 Atwa，保存对象的 Area/Rng4000、普通Dur5和HeroDur2。Q24 局部 Web 原生空闲适配以每只的出生点为锚，出生起每5秒有一次空闲漫游机会。允许在空闲或仍执行自主漫游时从出生点4000内按本局可重放 RNG 取均匀圆内地点并下内部 `move`，用现有飞行合法目标修正。正在脚本强制回塔或显式攻击时跳过该机会；脚本 `move`、`stop`、`attack` 可立即覆盖漫游。进入回收后不再调度自主漫游或索敌。Area/Rng 字段不进入伤害判定或新增无来源的碰撞伤害。原生 T057 精确选点和停留分布无相同版本实测，采用上述局部演算。[地图移动](pathing-and-placement.md) · [原始T057](../../reference/map-6.25/units_abilitydata.json#L33451) · [公开同类作者实现及其未验证边界](https://corepunch.github.io/open-realm/games/warcraft-3/tornado/)
- **真实攻击。** 每只使用第一武器，cool1=1、射程80、RngBuff250，目标掩码 ground/debris/air/item，关系和射程缓冲按已核武器准入，不因飞行姿态把攻击从合法地面目标移开。第二武器未开。对象未配 dmgpt/backSw，Web 这两项选0，保留独立攻击冷却。普通追踪武器投射物速度500、弧度 .15 为表现，无定向 N535 法术盾消耗；普通攻击失败按共享规则不派发成功碰撞。授予 T061 的该只拥有武器必中。返回、`move`／`stop` 只取消尚未提交的普通攻击，已发弹按既定在途条件；载体删除则取消未到达弹。[武器时序](attack-timing.md) · [武器字段](weapon-field-source-notes.md) · [必中](native-critical-family.md)
- **伤害和返蓝。** q011/q012 原伤害事件抵达 B03 PC859 时先把该母包置 0，无额外伤害正值、攻击标志或目标筛选。然后用载体 UserData 查当时 O。O 无效时结束此分支。O 有效时读当时 A066 等级和有效智力。按档以 O 为实际来源发 `false,false,NORMAL,MAGIC,WHOKNOWS` 子包，金额为 200/250/300/350/400/500 加有效智力×.8/.9/1/1.1/1.2/1.4。原生武器原值和 T061 均不乘入子包。 O 留有效句柄但当前不再有 A066 时，Web 无公式子包，仍按原命中回蓝入口。子包及其嵌套回调返回后，在同一个 O 上读当前魔法、最大魔法。未满则增加 `min(13,缺值)`。已满不做写入，无治疗与重复返蓝。返蓝以来自 q011/q012 的已接纳事件为门槛，不额外要求子包最终扣正生命。只查实际 O 是否存在，不为已死亡但仍有效的句柄新增存活条件。[满蓝截断](../../reference/map-6.25/main.disasm#L71693) · [实际来源](damage-pipeline.md)
- **结束。** +15秒结束战斗分派，先撤每秒控制，取消未提交攻击并停自主漫游，给每只设700移动速度并向当时 O 坐标发 `move`，位置是这次回收下令的固定点。B05 保证预先入队的15秒结束早于每秒控制后续重排的同刻回调。已发武器弹若在载体移除前到达，照既定在途命中与返蓝。+16秒统一移除该组，提前到达不提前回收，也不持续跟随塔的再次移动。传统槽当前单位缺失时，在下一生成/控制/结束回调立即清理该组及四计时器，不在 nil 上继续发单。明确重施可在活跃阶段或回收阶段提前清理。存档保存塔槽、实例、每只真实 ID/神杖快照/路径和命令、生成计数、剩余计时和在途弹，恢复不重新付费、抽样或生成已存在单位。[计时](web-baseline.md)

## 差异

- 图鉴基础数量 5/7/9/11/13/15 覆盖原 8/10/12/14/16/18；明文活动15秒覆盖原16秒控制周期。原1秒回收活动是终止后的飞行与回收，继续保留。神杖 +8/必中来自明确主提示与对应脚本。
- 原重施显式清除旧组及所有子 timer、载体，保留替换。每个旧回调只对自己的实例有效，避免 B05 排队中旧结束清理新组。
- 槽失效时源函数清理后仍可能触碰 nil/native，Web 清理后立即结束本轮。原等级为0时 f58/f7 返回 nil，Web 使用无金额子包的安全边界并保留有效拥有者的已接纳事件回蓝。
