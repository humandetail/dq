# 山崩原生效果：avalanche-native-v1

本页补齐 A067/A148 所调用 **T059/T162** 的施法接受、地点目标、命中时序、伤害类型和控制生命周期。沿用 [Q39 概率与2秒共享锁](skill-avalanche-proc.md)、[Q40 六级整次单笔伤害与300范围](skill-avalanche-effect.md)，不再修改这两项裁决。原图字段与查证后仍未知的客户端行为分开记录；后者按 Q24 制定仅适用于本次山崩的 `avalanche-native-v1`。无新增确定图鉴冲突。[JSON](avalanche-native-effect.json)保存原始对象、物编增量、字节码时点和验证案例。

## 1. 原图已经证明的参数与顺序

T059/T162 均为 `code=ANcs`，命令 `clusterrockets`；字段在 [能力表 L33503](../../reference/map-6.25/units_abilitydata.json#L33503)、[L35608](../../reference/map-6.25/units_abilitydata.json#L35608)。四级以内显式字段为：

| 字段 | 原记录 |
| --- | --- |
| Area | 一级300，二至四级200；Q40 的 Web 全六级固定300 |
| DataA | 150/275/420/650；五、六级由 w3a 写860/1120 |
| DataB / C / D / E / F | .25 / 12 / 1000000 / 1 / 1.01 |
| Dur | .4/.6/.8/1；五、六级增量为1.2000000476837158/1.5 |
| HeroDur | .1/.3/.4/.5；五、六级增量为.6000000238418579/.800000011920929 |
| Rng / targs | 1500 / `enemies` |
| Buff / Effect | BNcs / XNcs |
| Cost、Cool | 未显式提供，不能径直视为已证实的 native 0 |

五、六级增量只补 DataA/Dur/HeroDur，不能把其他缺失字段称作显式数据；完整增量见 [T059 L6932](../../reference/map-6.25/war3map.w3a.json#L6932)、[T162 L9996](../../reference/map-6.25/war3map.w3a.json#L9996)。`Ncs1…6` 对应 DataA…F：[原元数据](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/Units/AbilityMetaData.slk#L15164)、[字段名 L6476–6481](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/UI/WorldEditStrings.txt#L6476)。DataB是伤害间隔，DataC是弹体数，DataD是最大伤害，DataE是建筑伤害系数，DataF是效果持续；**1.01 不等于已证明的施法前摇/引导时间/首次命中延迟**。

两项 [profile](../../reference/map-6.25/units_campaignabilitystrings.txt#L20021) L20021–20036、L21325–21340 的 MissileSpeed=700、MissileArc=.2、MissileHoming=1。T059 用地震模型，T162 用 `AZ_silingfashi02_attack.mdx`；内部模板提示仍写35/65/100和地面火箭群，不覆盖主技能及明确数据。BNcs 的 [buff profile L1516](../../reference/map-6.25/units_commonabilitystrings.txt#L1516)只有名称、图标和眩晕视觉；XNcs 的 profile L2555 只有空图标，不能单靠视觉资源推算逻辑命中时钟。

`A067_Action` / `main/f59/f1` 的关键顺序为 [L71941–71975](../../reference/map-6.25/main.disasm#L71941)：

```text
PC66  创建 q001（位置=此刻攻击者位置，朝向=此前查询等级，原实际能力等级=1，生命3秒）
PC71  IssuePointOrderLoc(q001,"clusterrockets",目标位置L)
PC75  SetUnitUserData(q001,先前取得的Tower_ALL索引)
PC78  RemoveLocation(L)
PC80  CreateTimer()
PC87  TimerStart(...,原2.4秒；Q39改为2秒,...)
PC88  将timer写入私有锁表
PC89  return
```

L 在 Action 成功抽样后取得，是受攻击目标**当时的位置副本**，不是延迟追踪目标的句柄。原发令不检查返回值；命令失败也执行写归属、释放位置、上锁。`CreateTempAndSetAbilityLv` 完整 helper 在 [L51457–51509](../../reference/map-6.25/main.disasm#L51457)：先创建、加能力、设级，再调用 `UnitApplyTimedLife(BHwe,3)`。q001 初始能力只有 Avul/Aloc（[挂载 L6555](../../reference/map-6.25/units_unitabilities.json#L6555)），初始/最大魔法1000（[balance L37578](../../reference/map-6.25/units_unitbalance.json#L37578)），其 [武器表 L34183](../../reference/map-6.25/units_unitweapons.json#L34183)没有显式 castpt/castbsw；不能拿英雄自身施法点替代。

上述发令在 UserData 写入**之前**。所以不能直接套 [T039 的同步链条选择](skill-lightning-attack-effect.md)；那条链在发令前已经写入归属。也不能为山崩方便而把原源码步骤重排成“先写UserData再发令”。

## 2. 一手资料与原生证据边界

[暴雪 Cluster Rockets 说明](https://classic.battle.net/war3/neutral/goblintinker.shtml)将原技能描述为地面范围伤害/眩晕，目标表包含地面、敌人、中立、建筑；并明确建筑受完整伤害，眩晕可打断吟唱。它支持这些类别的参考意义，**没有证明本图自定义 `enemies` 的完整掩码语义、逐目标执行顺序、重叠刷新或分波算法**。同一官方页面的机械形态说明提到机械单位的眩晕限制；本页仍将机械/建筑是否受此次控制单独标为 Web 选择。

[官方法术基础](https://classic.battle.net/war3/basics/spellbasics.shtml)说明魔免、负面法术护盾和抗性皮肤缩短负面效果；`adur/ahdu` 的 [原编辑器标签](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/share/en-US/mpq/UI/WorldEditStrings.txt#L5838)区分普通/英雄时长。这些资料未给出本图 N534 抗性皮肤对 ANcs 的精确时长，因此下节使用 HeroDur 是 Q24 选择，而不是原客户端实测。没有用其他引擎的实现代替 Warcraft 证据。

同图 stock ANcs（[能力表 L5922](../../reference/map-6.25/units_abilitydata.json#L5922)）含70魔法、6秒冷却、800施法距离及不同伤害字段，不自动并入 T059/T162。缺省加载、q001实际施法点和弹体命中native尚无匹配客户端证据；[YDWE 的缺省数值转换](https://github.com/actboy168/YDWE/blob/a69c315ebf2886ec54d66200707ab6e38bd3484d/Development/Component/plugin/w3x2lni/script/core/slk/frontend_slk.lua#L19)只是工具处理规则。本页不再求“12×伤害”或“.25间隔内反复伤害”，因为 Q40 已决定 Web 整次名义伤害语义。

## 3. Q24：接受命令与队列命中

以下全部是明确的本技能 Web 合同。有效逻辑等级从 Q40 配置传入，限1–6；原固定一级只留作来源对照。G059 查询 A148、其余查询 A067 的原路由、选 T162/T059、朝向及目标地点的取值时点保留，不添加“缺 A148 就改读 A067”的隐含后备。若得不到合法等级，仍保留原创建/发令尝试与共享锁步骤，但效果接受失败并记录数据问题，不擅自取一级。

1. q001必须存在、存活、持有选定临时能力且可施法；没有眩晕、沉默、暂停、妖术等禁止主动施法的锁。自身 Avul/Aloc 不妨碍发令。此次专用命令零前摇、零费用、无额外原生冷却，不借用 stock 的70魔法/6秒；六级施法距离都明确选1500，二维中心到地点距离≤1500，无碰撞扩张。地点须是有限坐标；不要求原目标仍活着、仍敌对、在原位，或地点此刻有可受术者，也不要求视野/路径可达。
2. 接受时复制地点、Q40逻辑等级、临时能力ID和 q001 句柄，发一次 q001 的 SPELL_EFFECT，再登记 **B05 的零时效果事件**。该临时施法在 [AnySkillStart L170040–170066](../../reference/map-6.25/main.disasm#L170040)早退，不递归触发原塔装备施法响应。无目标命令的 targetUnit 不被改成原受击单位。
3. 零时效果在当前攻击事件及同步脚本调用栈结束之后，依 B05 同刻入队序号执行；没有新增伤害间隔或正时间前摇。原 Action 继续按“发令→写UserData→启动Q39计时器→写锁表”的顺序完成。**这只选择命中调度，不移动2秒锁起算点。** 命令拒绝、效果为空或之后取消都不撤销共享锁。
4. 命中事件开始时 q001 已死或移除，则整次效果取消；原英雄的移动/死亡不单独取消仍有效的 q001 请求。请求独立于之后的 stop/移动命令，不另维持1.01秒引导。3秒限时生命沿共享死亡生命周期执行，是临时单位生命周期而非伤害/眩晕时长；已施加的眩晕不会因临时单位随后死亡而提前清除。

地点在发令接受时固定。原目标在队列执行前走开，可能不受山崩；其他单位此时走入可受术。该时刻才形成下一节的范围快照。700弹道速度、12枚弹体、.25秒间隔和1.01秒效果字段仅供本适配的表现层参考，不产生额外逻辑命中、等待或伤害。这里不是对原 ANcs 的分波实测结论。

## 4. Q24：目标、伤害和控制分别判断

**本技能的目标选择：**依据原生 ANcs 官方类别，在结算时于固定地点300半径内选择存在、存活、相对 q001 为敌方或非同盟中立方的**地面单位，含建筑和机械**；空中单位不入选。本图自定义仅写 `enemies`，所以这一地面限制明确属于本适配选择，不能说它已由原图掩码证明。物品、可破坏物和尸体不属于本次单位集合；Aloc、无敌、魔免对象排除。英雄、召唤物、幻象、名字带Boss和 SAPPER 标签本身不排除伤害。

几何为二维单位中心闭圆，不计碰撞尺寸、高差、路径和视野。按 [B04](web-baseline.md)创建序号形成一次快照；之后不重新查询位置或阵营，不补进子事件新建的单位。逐成员处理前再次检查存在、生命、地面类型、Aloc、无敌与魔免；先前子事件使后一个成员死亡、变飞行或获得免疫时跳过它。该规则借用既定范围基准的稳定快照方式，但不是把 T059 改成调用原脚本不存在的 `UnitDamagePoint`。

每个合资格目标只提交**一笔** Q40 本级原始名义金额 `150/275/420/650/860/1120`；不乘12、不按间隔重复、不跨目标均分，也不把 DataD=1000000 改成共享总伤害池。建筑系数取1，与本图 DataE 及官方建筑说明一致。实际包选择 `attack=false,ranged=false,ATTACK_TYPE_NORMAL,DAMAGE_TYPE_MAGIC,WEAPON_TYPE_WHOKNOWS`，沿用地图法术包的组合；这是本适配对隐藏 native 包类型的定义。ATTACK_TYPE_NORMAL 在这里对应 spells 攻击类别，不是 DAMAGE_TYPE_NORMAL 的物理伤害。

**实际来源始终是 q001。** 每击经 B03 原生减免、完整伤害分派及最终扣血，再恢复上下文；归属 O 由主流程当次 `Tower_ALL[q001.userData]` 解析，不把原英雄直接替换为伤害源，也不对整次山崩缓存归属 O。若处理某成员的子事件杀死或移除 q001，已完成效果保留，后续成员停止。原普通攻击不因山崩触发而被本适配直接取消；眩晕/死亡对随后攻击的影响交给实际状态与既定攻击流程。

**控制顺序：**对每个合资格成员，先决定并应用本次眩晕，再提交这一笔伤害；子伤害回调因此能观察到已经生效的控制。建筑、机械或有效显式眩晕免疫的目标只受伤、不眩晕。其余地面单位按施加时的有效类别选时长：

| 等级 | 普通眩晕（Q40） | 原生 HERO 或有效 `code=Arsk` 抗性皮肤 |
| --- | ---: | ---: |
| 1 | 0.4秒 | 0.1秒 |
| 2 | 0.6秒 | 0.3秒 |
| 3 | 0.8秒 | 0.4秒 |
| 4 | 1秒 | 0.5秒 |
| 5 | 1.2秒 | 0.6秒 |
| 6 | 1.5秒 | 0.8秒 |

右列取原 HeroDur 六档；五六级浮点原值经 B05 换算仍分别为600000/800000微秒。有效 N534 是 Arsk（[L27010](../../reference/map-6.25/units_abilitydata.json#L27010)），但这不是自定义 `UnitIsHero=N534&&SAPPER`：HERO与Arsk任一成立即用右列，同时有二者也不再折半；只有 SAPPER、名字Boss或Boss列表成员不缩短。时长在施加时固定，中途类型/抗性改变不重算旧实例。N535定向法术护盾不拦截或消耗于本次地点范围效果；这也是本技能的局部选择，不能推广全部范围法术。

**控制生命周期：**T059/T162 在同一目标上共用一份本山崩 BNcs 控制实例；再命中设到期为 `max(原本山崩到期, now+本次时长)`，不累加，不由较短的新眩晕缩短旧控制。实例代号与来源信息在延长时更新，旧到期回调失效；不删除其他技能独立控制锁。眩晕阻止位移、普通攻击和主动施法，并打断未提交的攻击前摇及正在施放/吟唱的技能；已提交弹道、独立计时任务继续。移动意图可保留或更新，解除后才可继续执行，解除本锁不解除其他控制锁。

BNcs到期、显式移除本效果、死亡或移除单位会清除本控制；本适配选择**普通魔法驱散不移除此眩晕**，不把所有负面Buff统一视为可驱散。伤害本身不解除，获得魔免也不自动轮询清除旧实例；具体技能已核的显式清除仍生效。原客户端这一刷新/驱散顺序尚未证明，属于 Q24。零最终伤害、被模式回调改零或物理护甲修正本身不回滚已施加的眩晕；死亡会按生命周期清掉它。

## 5. 验收与完成边界

必须覆盖：命令范围1500端点；所有等级300范围；队列前移动/死亡；发令时UserData未写与结算时已写；命令失败仍上2秒锁；q001在结算前及成员间被移除；普通/HERO/Arsk/SAPPER/建筑/机械/空中与魔免；六级只一笔名义伤害；短眩晕不截短长眩晕；控制先于子伤害；同刻 B05 到期与新命中的入队顺序；续局不重复扣血或再次加控制。具体输入/期望见 JSON。

已重新核68条源指令（调用顺序片段35条、helper33条）、1个条件、16处调用、3条返回；28组源码参数/顺序探针通过。机器表保留16条来源案例，42条局部 Web 案例通过，其中包括900目标每个1120、总名义输入1008000且不套跨目标上限的边界。11条对象记录、4组profile、2项w3a对象的12条增量、12份有效等级配置、2行图鉴和19个本地链接均已校验。使用原生桩及局部状态模型；存档规则是应满足的合同，并未运行完整游戏存档系统。

本批闭合的是上述两个临时能力在已决 Q39/Q40 方案中的原生剩余接口。原 Action/概率/helper 及其上游调用由已有审计负责；本页只重新核必要的调用顺序片段与临时单位 helper，不声称复查全部伤害被调函数。没有扩写其他 ANcs 技能、A067/A148 的 AOcr 隐含效果、ANeg 换皮或通用所有眩晕系统。缺省加载、引导/弹道、完整 target 掩码、眩晕免疫/抗性/刷新及驱散的原客户端行为仍未知，已用清楚标记的局部 Web 规则关闭实现缺口，不能把这些选择称作实机还原。
