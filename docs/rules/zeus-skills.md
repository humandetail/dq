## 3. A105 静电场

A105 的 AOcr 外壳只作被动标记，按既定规则没有额外原生暴击、必中、闪避或回蓝贡献。原分派先排工人、箱子、`IsUseless` 能力；此前已检查 B083–B088 六类 A084 标记、i134、i202/i325 与 P217，之后查当时 A105>0 并触发。i318–i320 和 i279 的英雄物品分支仍在静电场之后。由此入口可响应合格的主动能力或道具施法生效，普通攻击、学习/拾取本身、被取消的前摇和临时 q001 的早退均未进入它。神杖保留 A105，自身施放 A106 也先触发静电场一次；雷云每秒的 T100 载体不重复触发。 [原施法物品分派](../../reference/map-6.25/main.disasm#L146437) · [AOcr 标记规则](native-critical-family.md)

`main/f85/f0` 在模块入口读取源坐标、当前等级 L、`GetHeroInt(source,true)`。B04 处理以源为圆心的 1000 范围快照，逐个复查 owner 是 Player(11) 且生命 >0。对每个当时合格者依次调用：

1. `divine = target.currentLife × min(INT/16000, cap[L])`，对正值且 `UnitIsHero(target)` 再除 2，`Game_Mode=2` 再除 2。地图 Boss 谓词是 N534>0 且 SAPPER，独立于原生 HERO 分类。随后 `SetRealDamage(source,target,divine)`。
2. 无条件继续调用 `SetMagicDamage(source,target,300×L)`。Boss/深渊系数只在前一包使用。前一包导致死亡时第二次 Lua 调用仍保留，原生伤害入口对已死目标不提交有效包；同时不追加任何对新目标的替代攻击。每个单位先神圣后法术，各走完整伤害事件，前一包及嵌套回调结束后才继续。

CHAOS/DIVINE 与 NORMAL/MAGIC 均采用实际宙斯、`false,false`，不消耗 N535。直接伤害复用 B03，Web 对无敌、Aloc、无效/死亡目标及非正金额拒绝提交；魔免拦 MAGIC，DIVINE 仍服从管线其他减免。记录 Lua 传参的位置保留可达零值及脚本自身的先后，不能用“任一包无伤害”跳过整个目标分支。普通宙斯显示 T578/head，G048 显示 T562/orign，脚本保留资源与附着点拼写。 [静电场模块](../../reference/map-6.25/main.disasm#L78952) · [Boss 谓词](../../reference/map-6.25/main.disasm#L52443) · [两种原包类型](../../reference/map-6.25/main.disasm#L52062)
