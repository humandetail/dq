# A173 致命连接

## 规则

术士手动在600施法距离选合法敌方单位，B012 自动从500的现有 P11 分支下目标命令。前摇.5秒，六档耗蓝50/60/70/80/90/100点，冷却12秒。生效时先把所选敌人纳入组，再按 B04 在所选目标当刻位置300/350/400/450/500/550闭圆内依次选其他存活P11单位，总人数最多3/4/5/6/7/8。目标不足时保留已有成员，不因移动脱离原圈。各次绑定6秒，T188 是目标至少仍有一个活动组的派生标记，独立到期。每次另生成6秒标志和0.5秒初始连线，第一线由施法塔到主目标，其后按本组名单连相邻成员。[施法入口](hero-spells-batch-04.md) · [自动施法第86项](autocast.md) · [筛选与标记](../../reference/map-6.25/main.disasm#L94521)

来源玩家拥有原生 q039 槽。施法在塔位置新建一只7秒 Avul/Aloc 的同方载体、写塔索引并覆盖该玩家当前槽引用。旧载体仍沿自身寿命。原路由在 B03 PC3868，晚于 P03 前置修正、N579 与 A231，早于濒死保护和活动统计。来自 q025 或 q039 的事件绕过。进入时以该时点父事件的 D 为单一快照，查实际 B03 已解析归属 O 的所属玩家最新存活 q039，无该载体则原分发不进入。取当前 O 的塔索引写载体，使后续原生尾段能按当前伤害来路记账。[q039 创建](../../reference/map-6.25/main.disasm#L94804) · [事件入口](../../reference/map-6.25/main.disasm#L166558) · [原归属闸门](../../reference/map-6.25/main.disasm#L94878)

按入队序号取含受伤目标的仍活动组，每组各取同一 D×0.25，依次对本组其他成员通过 q039 发同步子事件。一个目标同时和受击者同属两个活动组，就各收一笔。子事件不反向改写父伤害或重抽自己的名单。保留目标实际存在和 B03 普通伤害提交条件，实际来源仍为 q039，均 `attack=false,ranged=false`。根据原事件类型分别用 NORMAL/MAGIC、HERO/NORMAL、CHAOS/DIVINE，其他类型不制造包。子事件走 B03 的 q039 旁路，跳过技能和属性主段，仍进入原生类型减免及活动、金币、商店、面板统计尾段。一个组到期只撤自己成员关系；存档保存组ID、成员序列、活动截止时刻和 q039 槽，不重选成员。[转发与类型](../../reference/map-6.25/main.disasm#L94843) · [q039 旁路](damage-pipeline.md#L53) · [B04/B05](web-baseline.md)

## 差异

- 原脚本复用一个 D 寄存器，重叠组依次给25%、6.25%等。脚本任意组到期直接移除 T188，也会使其他仍有效组暂失触发。按 Q54/Q64 以每次施法为独立组，派生 T188 并对每组使用同一个原事件 D。图鉴明确的“6秒”和“25%”均可独立实现。
- 施法者阵营与受伤来源玩家的 q039 资格、已存在同组重叠形成多笔命中及类型交给源接口。此处保留原玩家载体限制和 PC3868 上游条件。
