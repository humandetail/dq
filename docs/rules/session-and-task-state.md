## 单人开局与平台值

新局只保留一个真实 HUMAN/PLAYING 玩家，其个人商店、入口和阵营身份按原单人个人模式处理；原服务器接口由本机档案提供。比赛模式关闭，已决付费/历史权益和地图等级门槛适配照 Q18–Q22，不把所有 `Requires` 一并删除。玩家初始金币2000、人口30由原 `main/f306/f45` 明确设置。初始木材没有源设置，Q24 将新局基础木材明确设0，之后的礼包/任务/技能原收入照常；这不是把原表缺项改成已证实的0。[初始化 L201012](../../reference/map-6.25/main.disasm#L201012) · [完整初始化顺序 L200615](../../reference/map-6.25/main.disasm#L200615)

保留工人w001、能量圈w000、W001天赋书、i004开局包及非比赛新手包的源交付。礼包使用、四选一、钥匙/箱子与每局防重使用已核物品合同；重新载入不能重跑初始化。工人选择/升级另见[工人天赋](worker-talents.md)，实际建造/回收见[塔生命周期](tower-lifecycle.md)。

Web没有线上 `WeekSSR`、`TaskItem15/25/35` 配置，采用原代码的缺失分支：轮换SSR回退i506；三个可配置波次奖励池不追加远端值，沿原基础池。不存在自行生成的周轮换、真实节日日历或联网账号条件。非可达旧 `ActivityTask` 定义不新增为活跃任务；两条实际已初始化的季节任务保持开放。

单人 Web 已取消原图 BAN 设置。M2 直接显示四名入选 SR，选择结果随当前局保存，已领取的开局卡读档后只恢复一次领取记录。Q18/Q19/Q20/Q21已直接开放的永久项目不再扣积分/碎片或要求历史名单；Q22明确保留的任务链奖励仍按进度解锁。局内SSR兑换、SR消耗和每局次数保持原规则。

## 本机持久化与商店关闭

档案与当前局分别建模、共同提交同一保存修订：档案保存下局起始积分所用的跨局提交余额、碎片、任务计数与已领奖节点、永久解锁及原战绩；当前局保存资源、实体/物品、技能、波次、原任务局内令牌、五槽奖励、PRNG、全部B05事件及阶段。已有状态必须可直接恢复，不通过“再执行一次开局/施法/领取”重建。

原 `scoreN` 是当局可用积分，`scoreNewN` 是本局按击杀计算的检查点收益。按原保存写 `scoreN+scoreNewN` 的**替换值**，不是每次保存累加。续当前局仍恢复它的原可用余额与独立收益字段；开始新局才以已提交档案余额作为新的可用起点。任务/礼盒即时积分与兑换扣分仍即时更新可用余额，再与本局收益合成下次保存值。碎片、任务完成和节点奖励与对应物品/科技同修订提交，避免读档发两次。

本机自动保存包括定期检查点及已提交的重要玩家动作/阶段切换；页面关闭或刷新恢复最近成功保存的完整修订，关闭期间不推进。前台/后台仍使用同一B05模拟队列，浏览器仅挂起后恢复按已选策略补算，补算到终局便停；页面被系统回收后读档不补算。全局暂停冻结战斗时间；界面偏好操作不依赖1–4倍速。具体保存介质和频率属实现选择，必须满足已定恢复和不重复交易验收。

神秘商店最后120秒回调只隐藏Fshop主入口，源未隐藏四个个人子商店。Q24将“选择可见商店”和“已打开个人店的交易”分开：已选且仍存在/可交互的个人店继续按实际库存和费用交易；主入口隐藏后不可通过它重新打开。真正隐藏/删除个人店或阶段明确关闭该店才撤交易资格；恢复保留当前所选店和真实可见状态，不凭主入口隐藏清空个人库存。[原区别](economy-and-progression.md#商店价格与刷新) · [交易提交](item-lifecycle.md)
